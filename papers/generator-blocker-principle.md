# Sparse Generators and Representation Blockers

## A local-global principle for finite images

**Sven Hardy Benson**  
12 September 2026

## Abstract

Let \(V\) be a finite set and let \(f:V^k\to Y\) be any \(k\)-ary map. Write \(\Omega=f(V^k)\). A subset \(B\subseteq V\) is an **image generator** if \(f(B^k)=\Omega\). For an output \(y\in\Omega\), a **representation blocker** is a set \(T\subseteq V\) that meets the support of every tuple \((v_1,\ldots,v_k)\in V^k\) with \(f(v_1,\ldots,v_k)=y\).

This note proves a quantitative local-global principle. If every output has many pairwise support-disjoint representations, then the entire image is generated by a sparse subset of the domain. More generally, if \(b\) is the smallest blocker size of any output and

\[
q=\left\lceil \frac{b}{k}\right\rceil,
\]

then for every \(0\le \theta\le 1\) there is an image generator \(B\) with

\[
|B|\le \theta |V|+k|\Omega|(1-\theta^k)^q.
\]

The proof is an alteration argument: retain each domain point independently with probability \(\theta\); a value with \(q\) disjoint representations is missed with probability at most \((1-\theta^k)^q\); then repair each missing value by adding one representation. The nontrivial deterministic input is the matching-to-blocker lemma: a maximal family of pairwise disjoint representations has a union meeting every representation.

The inequality has an inverse form. Put \(n=|V|\), \(M=|\Omega|\), and let \(g\) be the minimum size of an image generator. If \(1\le s<g\), then some output has a blocker of size

\[
<k\left(\frac{2n}{s}\right)^k
  \log\!\left(\frac{2kM}{s}\right).
\]

Thus failure of global compression cannot remain diffuse: it forces a single locally fragile output. For the sum map \(f(a_1,\ldots,a_k)=a_1+\cdots+a_k\), this says that if no \(s\)-element subset \(B\subseteq A\) satisfies \(kB=kA\), then one sum in \(kA\) has a small set of elements meeting every one of its \(k\)-term representations.

The theorem is unconditional under the stated hypotheses. The ingredients—probabilistic alteration, disjoint representation families, and the elementary matching/transversal bound—are classical. A targeted literature search located closely related work on small subsets generating large or saturated sumsets, especially Fox, Luo, Pham and Zhou (2024), and the older disjoint-representation tradition in additive number theory. I did not locate the abstract generator/blocker inequality or the inverse finite-image formulation above. That is a provisional novelty claim, not proof of priority.

A Lean 4 / Mathlib companion formalizes the deterministic blocker spine and the finite witness-system definitions used by the paper. The current authoring environment does not contain a Lean toolchain, so the accurate status is **formalized, compiler check pending** until the pinned project is built independently.

## 1. The object that survives deletion

A finite set can have a large image for two very different reasons. One is structural breadth: many different inputs produce genuinely different values. The other is redundancy: the same value can be produced in many mutually independent ways.

Those two situations are easy to conflate if one looks only at the cardinality of an image. A sum \(x\in A+A\) may have a hundred representations and still depend on one indispensable element of \(A\). Conversely, ten representations that use disjoint parts of \(A\) make the sum hard to destroy by thinning the set.

The distinction suggests a question that is slightly different from the usual sumset problem. Do not ask only how large \(f(B^k)\) can be when \(B\) is small. Ask when a small \(B\) can preserve **all** of \(f(V^k)\).

There is a natural obstruction. If one output \(y\) can only be represented through a small collection of domain points, then every image generator must retain enough of that local bottleneck to keep \(y\). The theorem below says that, up to an explicit quantitative loss, this is the only obstruction visible at this level of generality.

The statement is more transparent if the map is temporarily replaced by an abstract system of witnesses.

## 2. Finite witness systems

Let \(V\) be a finite ground set and let \(\Omega\) be a finite set of outputs. A **rank-\(k\) witness system** consists of a nonempty family

\[
\mathcal W(y)\subseteq 2^V\setminus\{\varnothing\}
\]

for every \(y\in\Omega\), with

\[
|W|\le k
\qquad
(W\in\mathcal W(y)).
\]

A subset \(B\subseteq V\) **realizes** \(y\) if it contains at least one witness:

\[
y\in R(B)
\quad\Longleftrightarrow\quad
\exists W\in\mathcal W(y),\; W\subseteq B.
\]

Thus

\[
R(B)=\{y\in\Omega:B\text{ realizes }y\}.
\]

A set \(B\) is a **generator** if \(R(B)=\Omega\). Define

\[
g(\mathcal W)=\min\{|B|:R(B)=\Omega\}.
\]

For a fixed output \(y\), a **blocker** is a set \(T\subseteq V\) meeting every witness:

\[
T\cap W\ne\varnothing
\qquad
\text{for every }W\in\mathcal W(y).
\]

Write \(\tau(y)\) for the minimum blocker size and

\[
b(\mathcal W)=\min_{y\in\Omega}\tau(y).
\]

Finally let \(\nu(y)\) be the maximum number of pairwise disjoint witnesses in \(\mathcal W(y)\).

The relation between \(\tau\) and \(\nu\) is the elementary hypergraph inequality

\[
\tau(y)\le k\nu(y).
\]

It is worth proving because this one line is where local obstruction enters the global theorem.

### Lemma 2.1 — Matching union is a blocker

For every \(y\in\Omega\),

\[
\tau(y)\le k\nu(y).
\]

### Proof

Choose a maximal pairwise disjoint family

\[
W_1,\ldots,W_r\in\mathcal W(y).
\]

Its size \(r\) is at most \(\nu(y)\). Put

\[
T=W_1\cup\cdots\cup W_r.
\]

If some witness \(W\in\mathcal W(y)\) were disjoint from \(T\), then \(W\) could be added to the family, contradicting maximality. Hence \(T\) meets every witness and is a blocker. Since every \(W_i\) has size at most \(k\),

\[
|T|\le kr\le k\nu(y).
\]

**QED.**

A useful contrapositive is

\[
\tau(y)>k(q-1)
\quad\Longrightarrow\quad
\nu(y)\ge q.
\]

Large blocker number therefore guarantees many disjoint witnesses.

## 3. The sparsification theorem

The main direct theorem keeps the matching numbers visible. It is slightly stronger than the blocker formulation because different outputs may have very different amounts of redundancy.

### Theorem 3.1 — Sparse generator from disjoint witnesses

Let \((V,\Omega,\mathcal W)\) be a finite rank-\(k\) witness system. For every \(y\in\Omega\), let \(\nu(y)\) be its witness matching number. Then for every \(0\le\theta\le1\) there exists a generator \(B\subseteq V\) satisfying

\[
|B|
\le
\theta |V|
+k\sum_{y\in\Omega}(1-\theta^k)^{\nu(y)}.
\tag{3.1}
\]

In particular, if \(\nu(y)\ge q\) for every output, then

\[
|B|
\le
\theta |V|+k|\Omega|(1-\theta^k)^q.
\tag{3.2}
\]

### Proof in Lamport style

The proof is short, but the hierarchy exposes exactly where independence is used and exactly where repair costs enter.

**〈1〉1.** For each \(y\in\Omega\), choose a maximum pairwise disjoint family

\[
W_{y,1},\ldots,W_{y,\nu(y)}\in\mathcal W(y).
\]

**〈1〉2.** Form a random set \(S\subseteq V\) by retaining every element of \(V\) independently with probability \(\theta\).

**〈1〉3.** Fix \(y\in\Omega\). For each \(i\), let \(E_{y,i}\) be the event

\[
W_{y,i}\subseteq S.
\]

**〈2〉1.** Since each element of \(W_{y,i}\) is retained independently,

\[
\Pr(E_{y,i})=\theta^{|W_{y,i}|}.
\]

**〈2〉2.** Since \(|W_{y,i}|\le k\) and \(0\le\theta\le1\),

\[
\Pr(E_{y,i})\ge\theta^k.
\]

**〈1〉4.** For fixed \(y\), the events \(E_{y,1},\ldots,E_{y,\nu(y)}\) are mutually independent.

**〈2〉1.** The witnesses \(W_{y,i}\) are pairwise disjoint by **〈1〉1**.

**〈2〉2.** Each event \(E_{y,i}\) depends only on the independent retention variables indexed by elements of \(W_{y,i}\).

**〈2〉3.** Events depending on disjoint collections of independent variables are independent.

**〈1〉5.** The probability that \(S\) fails to realize \(y\) is at most

\[
(1-\theta^k)^{\nu(y)}.
\tag{3.3}
\]

**〈2〉1.** If any \(E_{y,i}\) occurs, then \(S\) contains a witness for \(y\), hence realizes \(y\).

**〈2〉2.** Therefore failure to realize \(y\) implies that none of the events \(E_{y,i}\) occurs.

**〈2〉3.** By **〈1〉4**,

\[
\Pr\left(\bigcap_i E_{y,i}^{c}\right)
=
\prod_i(1-\Pr(E_{y,i})).
\]

**〈2〉4.** Apply **〈2〉2** of **〈1〉3** to every factor to obtain (3.3).

**〈1〉6.** For every \(y\in\Omega\), fix one repair witness \(U_y\in\mathcal W(y)\).

**〈1〉7.** After sampling \(S\), define

\[
B
=
S\cup
\bigcup_{y\notin R(S)} U_y.
\]

**〈1〉8.** \(B\) is a generator.

**〈2〉1.** If \(y\in R(S)\), then a witness for \(y\) already lies in \(S\subseteq B\).

**〈2〉2.** If \(y\notin R(S)\), then \(U_y\subseteq B\) by construction.

**〈2〉3.** Hence every \(y\in\Omega\) belongs to \(R(B)\).

**〈1〉9.** Pointwise,

\[
|B|
\le
|S|+k\,|\Omega\setminus R(S)|.
\tag{3.4}
\]

**〈2〉1.** Each repair witness has at most \(k\) elements.

**〈2〉2.** Overlap among repair witnesses can only make the union smaller, so counting \(k\) new elements for every missed output is an upper bound.

**〈1〉10.** Taking expectations in (3.4) gives

\[
\mathbb E|B|
\le
\theta|V|
+k\sum_{y\in\Omega}\Pr(y\notin R(S)).
\]

**〈2〉1.** \(\mathbb E|S|=\theta|V|\) by linearity of expectation.

**〈2〉2.** The number of missed outputs is a sum of indicator variables, so its expectation is the sum of the miss probabilities. No independence between different outputs is needed.

**〈1〉11.** Substituting (3.3),

\[
\mathbb E|B|
\le
\theta |V|
+k\sum_{y\in\Omega}(1-\theta^k)^{\nu(y)}.
\]

**〈1〉12.** Some outcome of the experiment has \(|B|\) no larger than its expectation.

**〈1〉13.** That outcome is a generator by **〈1〉8**, proving (3.1). If every \(\nu(y)\ge q\), then each summand is at most \((1-\theta^k)^q\), giving (3.2). **QED.**

The argument is an alteration proof in the classical probabilistic-method sense: sample an imperfect object, then repair its defects. The point here is the quantity controlling the defect probability. Raw representation count does not appear. Pairwise disjointness does.

## 4. Generator-blocker uncertainty

The direct theorem converts redundancy into compression. Lemma 2.1 converts the absence of a small blocker into redundancy. Combining the two gives the local-global statement.

### Theorem 4.1 — Generator-blocker inequality

Let \((V,\Omega,\mathcal W)\) be a rank-\(k\) witness system. Write

\[
n=|V|,
\qquad
M=|\Omega|,
\qquad
b=b(\mathcal W),
\qquad
q=\left\lceil\frac bk\right\rceil.
\]

Then for every \(0\le\theta\le1\),

\[
g(\mathcal W)
\le
\theta n+kM(1-\theta^k)^q.
\tag{4.1}
\]

### Proof

For every \(y\), \(\tau(y)\ge b\). Lemma 2.1 gives

\[
b\le\tau(y)\le k\nu(y),
\]

hence

\[
\nu(y)\ge\left\lceil\frac bk\right\rceil=q.
\]

Apply Theorem 3.1. **QED.**

This already gives a compact compression law. If

\[
q\ge \log(2kM),
\]

choose

\[
\theta=\left(\frac{\log(2kM)}q\right)^{1/k}.
\]

Then \(\theta\le1\), and

\[
(1-\theta^k)^q
\le
\exp(-q\theta^k)
=
\frac1{2kM}.
\]

Therefore

\[
g(\mathcal W)
\le
n\left(\frac{\log(2kM)}q\right)^{1/k}+rac12.
\tag{4.2}
\]

Since \(g\) is an integer, (4.2) may be rounded in the obvious direction. The scale is the more important point: once each output is protected by \(q\) disjoint witnesses, the entire image can be generated using roughly

\[
n\left(\frac{\log M}{q}\right)^{1/k}
\]

ground elements.

The logarithm appears because every output must survive simultaneously. The exponent \(1/k\) comes from the probability \(\theta^k\) of capturing a \(k\)-element witness.

## 5. The inverse theorem

The generator-blocker inequality can be read backwards. If a sparse generator does not exist, then the minimum blocker cannot be large.

### Theorem 5.1 — Global incompressibility forces a local blocker

Let \((V,\Omega,\mathcal W)\) be a rank-\(k\) witness system with

\[
n=|V|,
\qquad
M=|\Omega|,
\qquad
k\ge1.
\]

Let \(g=g(\mathcal W)\). If

\[
1\le s<g,
\]

then there exists \(y\in\Omega\) with a blocker \(T\subseteq V\) satisfying

\[
|T|
<
k\left(\frac{2n}{s}\right)^k
\log\!\left(\frac{2kM}{s}\right).
\tag{5.1}
\]

### Lamport-style proof

**〈1〉1.** Let

\[
b=\min_{y\in\Omega}\tau(y),
\qquad
q=\left\lceil\frac bk\right\rceil.
\]

**〈1〉2.** There is always a generator of size at most \(kM\).

**〈2〉1.** For each \(y\in\Omega\), choose one witness \(U_y\).

**〈2〉2.** The union \(\bigcup_y U_y\) realizes every output.

**〈2〉3.** Its size is at most \(kM\).

**〈1〉3.** Since \(s<g\), **〈1〉2** implies \(s<kM\). In particular,

\[
\log\!\left(\frac{2kM}{s}\right)>0.
\]

**〈1〉4.** Since \(V\) itself is a generator, \(g\le n\). Thus \(s<n\), and

\[
\theta:=\frac{s}{2n}
\]

lies in \((0,1)\).

**〈1〉5.** Theorem 4.1 gives

\[
g
\le
\frac s2+kM(1-\theta^k)^q.
\]

**〈1〉6.** Use \(1-x\le e^{-x}\) for \(x\ge0\):

\[
g
\le
\frac s2+kM e^{-q\theta^k}.
\tag{5.2}
\]

**〈1〉7.** Because \(g>s\), (5.2) forces

\[
kM e^{-q\theta^k}>\frac s2.
\]

**〈2〉1.** If the second term were at most \(s/2\), the right side of (5.2) would be at most \(s\), contradicting \(g>s\).

**〈1〉8.** Rearranging **〈1〉7** gives

\[
q\theta^k
<
\log\!\left(\frac{2kM}{s}\right).
\]

**〈1〉9.** Substituting \(\theta=s/(2n)\),

\[
q
<
\left(\frac{2n}{s}\right)^k
\log\!\left(\frac{2kM}{s}\right).
\tag{5.3}
\]

**〈1〉10.** Since \(q=\lceil b/k\rceil\),

\[
\frac bk\le q.
\]

Combining with (5.3),

\[
b
<
k\left(\frac{2n}{s}\right)^k
\log\!\left(\frac{2kM}{s}\right).
\]

**〈1〉11.** By the definition of \(b\), some output \(y\) has a blocker of size \(b\). This is (5.1). **QED.**

The conclusion has the flavor of an inverse theorem. The hypothesis is global: no small part of the domain preserves the whole image. The conclusion is local: one value carries a bounded obstruction shared by all of its representations.

Nothing in the statement assumes that \(f\) is additive, algebraic, symmetric, or even structured. All structure enters through the supports of representations.

## 6. Maps are witness systems

Let \(f:V^k\to Y\) and set

\[
\Omega=f(V^k).
\]

For a tuple

\[
\mathbf v=(v_1,\ldots,v_k),
\]

define its support

\[
\operatorname{supp}(\mathbf v)=\{v_1,\ldots,v_k\}\subseteq V.
\]

For \(y\in\Omega\), let

\[
\mathcal W_f(y)
=
\{\operatorname{supp}(\mathbf v):f(\mathbf v)=y\}.
\]

This is a rank-\(k\) witness system. Moreover,

\[
y\in f(B^k)
\quad\Longleftrightarrow\quad
B\text{ contains a witness in }\mathcal W_f(y).
\]

Thus the witness-system generator number is exactly

\[
g(f)
:=
\min\{|B|:B\subseteq V,\ f(B^k)=f(V^k)\}.
\]

A blocker for \(y\) is a set meeting the support of every preimage tuple of \(y\).

Theorems 4.1 and 5.1 therefore transfer word for word.

### Corollary 6.1 — Finite-image generator-blocker principle

Let \(f:V^k\to Y\), let \(n=|V|\), and let

\[
M=|f(V^k)|.
\]

If no subset \(B\subseteq V\) of size at most \(s\) satisfies

\[
f(B^k)=f(V^k),
\]

then some \(y\in f(V^k)\) has a set \(T\subseteq V\) meeting the support of every representation of \(y\), with

\[
|T|
<
k\left(\frac{2n}{s}\right)^k
\log\!\left(\frac{2kM}{s}\right).
\]

The theorem distinguishes multiplicity from robustness. A value may have a huge preimage and still have a blocker of size one if every representation passes through the same domain point. Conversely, many support-disjoint preimages are exactly the form of redundancy that permits aggressive sparsification.

## 7. Additive corollary

Let \(A\) be a finite subset of an abelian group and let

\[
kA=\{a_1+\cdots+a_k:a_i\in A\}.
\]

Take

\[
f(a_1,\ldots,a_k)=a_1+\cdots+a_k.
\]

Then an image generator is precisely a subset \(B\subseteq A\) with

\[
kB=kA.
\]

For \(x\in kA\), a blocker is a set \(T\subseteq A\) such that every representation

\[
x=a_1+\cdots+a_k
\]

uses at least one element of \(T\).

### Corollary 7.1 — Sumset compression or a fragile sum

Let \(A\) be finite, \(|A|=n\), and put \(M=|kA|\). If no \(B\subseteq A\) with \(|B|\le s\) satisfies \(kB=kA\), then there is a sum \(x\in kA\) and a set \(T\subseteq A\) such that every \(k\)-term representation of \(x\) uses an element of \(T\), while

\[
|T|
<
k\left(\frac{2n}{s}\right)^k
\log\!\left(\frac{2k|kA|}{s}\right).
\]

There is also a direct redundancy statement. If every \(x\in kA\) has at least \(q\) representations whose supports are pairwise disjoint, then for every \(0\le\theta\le1\) there exists \(B\subseteq A\) with \(kB=kA\) and

\[
|B|
\le
\theta n+k|kA|(1-\theta^k)^q.
\]

This is deliberately not phrased in terms of the ordinary representation function. Pairwise support-disjointness is stronger than having many representations, and the distinction is necessary. If every representation of a sum contains one common element, deleting that element destroys the sum regardless of how large the raw representation count is.

## 8. A small example

Take \(k=2\). Suppose \(A\) has \(n\) elements and every sum in \(2A\) has \(q\) representations

\[
x=a_i+b_i
\qquad (1\le i\le q)
\]

whose two-element supports \(\{a_i,b_i\}\) are pairwise disjoint. The theorem says that for every \(\theta\), there is \(B\subseteq A\) with \(2B=2A\) and

\[
|B|\le \theta n+2|2A|(1-\theta^2)^q.
\]

The mechanism is easy to see. A random \(\theta\)-fraction of \(A\) captures each prescribed pair with probability \(\theta^2\). Because the pairs for a fixed sum are disjoint, failure across all \(q\) pairs decays like \((1-\theta^2)^q\). Only the sums missed by the random sample need repair.

The repair step is what converts an approximate preservation statement into exact equality \(2B=2A\).

## 9. What the theorem does not say

The theorem does not claim that every set has a very small image generator. The bound becomes useful only when representations are robust enough, or equivalently when all representation blockers are large.

It does not say that a small blocker consists of elements individually essential to the output. A blocker of size \(t\) may work collectively even though no single element belongs to every representation.

It does not turn raw multiplicity into disjoint multiplicity for free. Extracting a large pairwise disjoint representation family from a large representation count requires information about overlaps. That is often where the hard arithmetic or geometric work lies.

It also does not replace structural inverse theorems such as Freiman-type results. The conclusion describes representation fragility, not progression structure, approximate groups, or small doubling.

Those limitations are useful. They identify exactly what the theorem contributes: a general conversion between **robust representation multiplicity**, **exact image sparsification**, and **small local blockers**.

## 10. Relation to nearby work

The closest additive-combinatorics work I found is Jacob Fox, Sammy Luo, Huy Tuan Pham and Yunkun Zhou, *Small subsets with large sumset: Beyond the Cauchy–Davenport bound*, Combinatorics, Probability and Computing 33 (2024), 411–431, DOI [10.1017/S0963548324000014](https://doi.org/10.1017/S0963548324000014), preprint [arXiv:2210.07196](https://arxiv.org/abs/2210.07196). Among other results, they study how small a subset \(A'\subseteq A\) can be while making \(A+A'\) large, and prove saturation results of the form \(A+A'=A+A\) under bounded-doubling hypotheses. Their problem is therefore genuinely adjacent. The present theorem uses a different hypothesis and mechanism: it sparsifies all coordinates of a general \(k\)-ary image simultaneously, with the quantitative input supplied by support-disjoint representations or representation blockers.

Disjoint representation families have a long history in additive number theory. Paul Erdős and Prasad Tetali, *Representations of integers as the sum of k terms*, Random Structures & Algorithms 1 (1990), 245–261, DOI [10.1002/rsa.3240010302](https://doi.org/10.1002/rsa.3240010302), is a classical landmark. The broader additive-combinatorics background is developed in Terence Tao and Van Vu, *Additive Combinatorics*, Cambridge University Press (2006), DOI [10.1017/CBO9780511755149](https://doi.org/10.1017/CBO9780511755149).

The proof of Theorem 3.1 is an alteration argument. The method itself is standard; see, for example, Noga Alon and Joel Spencer, *The Probabilistic Method*, especially the chapter on alterations, DOI [10.1002/9780470277331.ch3](https://doi.org/10.1002/9780470277331.ch3). What matters here is the choice of defect variable and the matching-to-blocker conversion, not the invention of alteration as a method.

One can also sample a fixed-size subset instead of Bernoulli sampling. Then the relevant containment events are governed by sampling without replacement and negative dependence; a classical reference is Kumar Joag-Dev and Frank Proschan, *Negative Association of Random Variables with Applications*, Annals of Statistics 11 (1983), 286–295, DOI [10.1214/aos/1176346079](https://doi.org/10.1214/aos/1176346079). The independent Bernoulli formulation above is cleaner because disjoint witnesses give literal independence.

### Novelty posture

The proof ingredients are classical. The literature search was aimed at the **package and statement**, not at claiming new probability technology. In the sources and searches reviewed on 12 September 2026, I did not locate the following exact formulation:

* an arbitrary finite rank-\(k\) witness system;
* an exact generator bound controlled by the full vector of disjoint-witness matching numbers;
* the conversion of minimum blocker size into the generator bound; and
* the explicit inverse conclusion that failure of \(s\)-point image generation forces one output with a blocker of size \(O_k((n/s)^k\log(kM/s))\).

That is a provisional priority claim. Search is not proof that nobody has written an equivalent lemma in another language. The right next check is specialist review and a deeper bibliographic pass through MathSciNet, zbMATH, citation chains around finite sumset saturation, hypergraph covering, monotone DNF sparsification, and alteration arguments.

In particular, no claim is made here about what any individual mathematician has or has not privately considered.

## 11. Why the inverse direction is the interesting one

The forward statement has a familiar probabilistic silhouette. Many independent chances to realize each output make random thinning effective, and repair handles the failures.

The inverse statement changes the interpretation. Suppose a set resists every attempt to shrink its domain while preserving the image. It would be natural to imagine the obstruction distributed thinly over many outputs, with no single value especially responsible. The theorem rules out that picture quantitatively. Enough diffuse robustness everywhere would itself produce a sparse generator. Therefore resistance to compression must become visible somewhere as a bounded transversal through all representations of one value.

For additive problems, that produces a concrete target. If \(kA\) cannot be saturated by a small \(B\subseteq A\), search for a sum whose representation hypergraph has a small transversal. Conversely, if arithmetic information rules out such transversals for every sum, sparsification follows automatically.

That interface may be more useful than the inequality itself. It separates a general combinatorial mechanism from the domain-specific work. The general theorem says what must be shown. Number theory, geometry, algebra, or computer science can then supply lower bounds on representation blockers.

## 13. Conclusion

A finite image can be large because its values are numerous, but its resistance to thinning comes from something more specific: how independently those values can be represented.

The theorem makes that distinction quantitative. Disjoint witnesses buy compression. Large blockers force disjoint witnesses. If compression fails anyway, the failure has to concentrate in a value with a small transversal through every representation.

That is the local-global principle: **global incompressibility leaves a local certificate.**
