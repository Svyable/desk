# Book Incubator

These are book seeds, not active Desk books. They are deliberately kept outside `books/` so the Reader catalog and feedback surfaces do not fill with titles that have not earned manuscript status yet.

Each seed has a working title, a hard factual core, an evidence boundary, and a possible chapter spine. The test is simple: the premise should sound invented at dinner and become harder to dismiss the longer the primary record stays open.

Current strange-but-true seeds:

1. [The Pigeon Computer](the-pigeon-computer.md) — Project Pigeon / ORCON and biological guidance.
2. [The Listening Cat](the-listening-cat.md) — CIA trained-cat surveillance experiments and the limits of animal tradecraft.
3. [The Copper Sky](the-copper-sky.md) — Project West Ford and the attempt to build an artificial radio reflector around Earth.
4. [The Glacier Fortress](the-glacier-fortress.md) — Camp Century, Project Iceworm, and the idea of hiding strategic infrastructure inside moving ice.
5. [The Men the Airplane Stole](the-men-the-airplane-stole.md) — Operation COLDFEET and the Fulton Skyhook extraction system.
6. [The Radio Under Wisconsin](the-radio-under-wisconsin.md) — Project Sanguine / ELF and using the Earth itself as part of a submarine communications system.
7. [The Hurricane Laboratory](the-hurricane-laboratory.md) — Project STORMFURY and the difficulty of distinguishing intervention from a storm's natural behavior.
8. [The Bat Factory](the-bat-factory.md) — Project X-Ray and the wartime attempt to turn hibernating bats into a distributed incendiary system.
9. [The Mechanical Dragonfly](the-mechanical-dragonfly.md) — CIA's Insectothopter and the first serious insect-scale flying surveillance machine.
10. [The Army on the Moon](the-army-on-the-moon.md) — Project HORIZON and the 1959 plan for a twelve-man military lunar outpost.

Promote one by creating a normal `books/<slug>/` book from `_TEMPLATE`, then follow the repository's catalog and validation rules.
