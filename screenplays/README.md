# Screenplays

Home for **movie and show scripts** and **adaptations** of Sven Hardy Benson works on this Desk.

This tree is managed by **ScriptBot**. It is separate from `scripts/` (Desk Python tooling) and from `books/` (manuscript prose).

## Layout

```text
screenplays/
  <slug>/           One film or series
    README.md       Logline, format, source book(s), status
    bible.md        Optional series bible
    treatment.md    Optional adaptation treatment
    script/         Screenplay files (film) or episodes/
```

## Rules

- Adaptations cite the source book slug under `books/`.
- Do not rewrite `books/` prose from here unless a human asked.
- Follow root `AGENTS.md` and voice guidance for Sven’s material.
- Rights and Shelf release stay human-gated.
