# Desk Factory

Svyable's evidence-led B2B opportunity development workflow.

## Purpose
Identify a real, publicly observable problem; create a tailored technical proof asset; package a scoped paid engagement; track outcomes instead of email volume.

## Operating sequence
1. Check the private prospect ledger for duplicates and prior pitches.
2. Cite public evidence for a specific problem and record observation date.
3. Build a minimal, reproducible technical asset with explicit limitations.
4. Define deliverables, proof gates, scope, pricing hypothesis, and next step.
5. Prepare outreach as an unsent draft only; sending requires explicit authorization.
6. Update private pipeline metrics: qualified prospects, proposals, replies, calls, contracts, booked revenue.
7. Commit non-sensitive reusable code and templates; keep private commercial records outside public repositories.

## Confidentiality
This repository is public. Do **not** commit prospect contact details, private communications, Gmail drafts, CRM exports, credentials, nonpublic pricing negotiations, customer data, or unapproved confidential material. Publicly sourced prospect names alone may be public, but the default is to keep deal-specific work private.
