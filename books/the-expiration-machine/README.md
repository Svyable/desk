# The Expiration Machine

The central thesis is that expiration is one of civilization's hidden control primitives. A passport, patent, drug, cryptographic key, discharge permit, domain registration, lease, warranty, debt instrument, and cloud access token can all remain physically unchanged while crossing a date that changes what the world is willing to believe about them. Expiration makes trust temporary. It forces systems to recheck identity, safety, ownership, authority, solvency, freshness, and permission when the cost of stale trust becomes too high.

The book follows that mechanism across law, medicine, food, finance, cybersecurity, infrastructure, property, the internet, and autonomous software. It also follows the failure cases: food discarded because a quality date is mistaken for a safety date; passwords weakened by arbitrary forced rotation; people losing access because renewal systems impose more friction than the underlying risk justifies; and automated authority that persists simply because nobody remembered to turn it off.

The question is not whether everything should expire. It is **how long trust should last before reality gets another vote**.
