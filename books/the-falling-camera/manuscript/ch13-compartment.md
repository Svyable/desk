# Compartment

Compartmentalization solves one problem by creating another.

It reduces how many people can assemble the whole program in their heads. It also reduces how freely engineers can exchange information when the machine misbehaves.

CORONA, GAMBIT and HEXAGON survived this trade because their organizations developed interfaces between compartments. Requirements moved. Hardware moved. Film moved. Failure reports moved in controlled form. The secret was not preserved by freezing information but by routing it.

This is why the popular image of a black program as a sealed room is misleading. A sealed room containing a complex machine eventually becomes a dead room. Parts wear. Experts are needed. New instruments appear. Procurement rules change. People retire.

Long-lived secrecy depends on controlled permeability.

That fact has consequences for disputed claims about programs lasting many decades. The longer the claimed duration, the more generational turnover must be explained. Knowledge has to transfer from one cohort to another. Documentation must exist or expertise must be recreated. Facilities need renovation. Security procedures change. Contractors merge. Old computer systems become unsupported. A program that survives all of this has an institutional metabolism.

Metabolism creates records.

Records can remain classified. They can be hidden in special-access channels. They can be mislabeled or retained under controlled archives. But they must do work. Maintenance manuals are not optional because Congress prefers secrecy. Configuration control is not a cultural preference. If a system changes, somebody needs to know which version exists.

This gives the logistics-shadow method a temporal dimension. Short programs can hide in improvisation. Long programs need institutions.

The distinction matters especially in stories of inherited secret technology. If a program began in the 1940s and continues in the 2020s, nearly everyone from the founding generation is gone. What replaced personal memory? How were technical uncertainties preserved? How were failed experiments recorded? How did classification authorities teach successors what they were protecting?

Those are not skeptical gotchas. They are design questions.

CORONA’s own history became recoverable partly because institutions had created histories, records, artifacts and program documentation robust enough to declassify decades later. The secrecy was strong without being archival annihilation.

There is an irony here. A secret program that destroys all internal memory to avoid future exposure also destroys its ability to compound knowledge. Security can become an attack on technical progress.

Good compartmentalization therefore does not minimize information. It minimizes unnecessary connectivity while preserving the connections the work requires.

That is a much harder thing to sustain than silence.
