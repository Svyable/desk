# Unencrypted

*Operation Ivy Bells and the Dangerous Belief That Distance Is Security*

| | |
|---|---|

This book reconstructs a documented Cold War intelligence episode and its implications for communications security. It uses only public historical sources and does not provide operational guidance for intercepting modern communications.
