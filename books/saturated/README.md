# Saturated

*Too Smart To Meter*

| | |
|---|---|
| **Authors** | Sven Hardy Benson |
| **Status** | Drafting |
| **Chapters** | 1 of 20 drafted |

A meter is useful only while it can still tell two different things apart.

Artificial intelligence is beginning to outrun some of the instruments built to measure it. Benchmarks that once separated weak systems from strong ones hit their ceilings. Public test sets leak into training data and search indexes. Agents learn the shape of the examination. Automated graders reward patches a maintainer would reject. A score of 95 can mean genuine competence, contamination, a forgiving harness, or simply that the test has become too easy.

*Saturated* is a book about that measurement failure.

The working thesis is not that machines have become infinitely intelligent, or even that a single quantity called intelligence can be measured cleanly. It is that many institutions still make consequential decisions using meters calibrated for a slower, narrower world: exams, credentials, leaderboards, benchmark percentages, billable hours, headcount, task-completion rates, productivity statistics, safety thresholds, and pass/fail gates. When capability moves outside the useful range of those instruments, the number can become more confident precisely as it becomes less informative.

The commercial and civic stakes are larger than model leaderboards. Employers need to know what a system can reliably do, not whether it can ace an academic test. Regulators need measurements that survive gaming. Schools need signals of learning when competent answers can be generated on demand. Buyers need to distinguish demos from dependable systems. Insurers, auditors, scientists, security teams, and boards need evidence tied to consequence.

The book follows a simple question through AI, economics, education, software, science, and risk: **what do we measure after the old meter pegs at the top?**
