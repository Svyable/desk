# Release fact-check — 2026-09-10

This note records the final current-source refresh for the Desk revision being prepared for Shelf release. It supplements the chapter research notes and source trail; it is not a claim that every forward-looking inference has become established fact.

## Agentic commerce / machine customers

The key time-sensitive sequence in Chapter 8 remains supported by primary sources.

- OpenAI launched Instant Checkout on September 29, 2025 and described it as an early agentic-commerce flow in which users explicitly confirm purchases while merchants remain responsible for payment, fulfillment, returns, and support: https://openai.com/index/buy-it-in-chatgpt/
- OpenAI expanded the Agentic Commerce Protocol to product discovery on March 24, 2026, explicitly adding richer structured product information and merchant connectivity for product comparison and discovery: https://openai.com/index/powering-product-discovery-in-chatgpt/
- Visa’s July 14, 2026 agentic-payments report says live onchain data shows AI agents booking travel, reordering inventory, querying data providers, and buying compute. This supports the manuscript’s narrow claim that agent-initiated payment is no longer merely hypothetical; it does **not** establish that autonomous buying is already a large share of commerce: https://www.visa.com/en-us/thought-leadership/innovation/agentic-payments-from-the-ground-up

### Boundary preserved

Do not promote these examples into a stronger adoption claim. The OpenAI checkout flow described above still keeps users in control of purchase confirmation. Visa’s evidence establishes observed agentic transactions, not economy-wide prevalence.

## Long-running agentic work

Recent primary reporting supports the book’s distinction between conversational assistance and persistent delegated work.

- Anthropic’s June 26, 2026 Economic Index report says Claude usage increasingly consists of long-running agentic tasks as Claude Code and Cowork have grown: https://www.anthropic.com/research/economic-index-june-2026-report
- Anthropic’s April 8, 2026 engineering note describes Managed Agents as infrastructure for long-horizon agent work and explicitly discusses the need to revise harness assumptions as model capabilities improve: https://www.anthropic.com/engineering/managed-agents

### Boundary preserved

These sources show real long-running agent use and product infrastructure. They do not prove the book’s broader economic forecasts about firm boundaries, employment, wages, or ownership. Those remain arguments with explicit falsification conditions in the publication pass.

## Release judgment

No checked primary source requires a material correction to the manuscript’s current agentic-commerce or persistent-delegation framing. The release should retain the manuscript’s existing caution that capability, permission, adoption, verification cost, and economic transformation are separate questions.
