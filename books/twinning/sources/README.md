# Sources

This directory is reserved for source artifacts and chapter-specific source packets that belong in the repository.

The working bibliography and reporting map currently live in `../research/source-map.md` so that vendor claims, primary institutional sources, peer-reviewed literature, and open source gaps can be annotated before they are promoted into chapter notes.

## Source rules

- Prefer primary documents, standards bodies, peer-reviewed research, public records, and direct interviews.
- Treat vendor case studies as claims by the vendor, not independent validation.
- Preserve URLs and publication dates whenever available.
- Record the exact claim a source supports rather than adding a source to a generic bibliography.
- For controversial performance claims, find independent corroboration before manuscript publication.
- Never turn a research ambition into a present-tense fact merely because the phrase `digital twin` appears in a paper or product page.
