# Ordinary Memory

The adjective ordinary is unfair to the phenomenon.

Ordinary gravitational-wave memory is the name given to a class of lasting effects associated with changes in the asymptotic motion of massive bodies. The mathematics can be developed in a linearized gravitational field, which is why “linear memory” is another common name. Nothing about the physical picture feels ordinary the first time it lands: objects that scatter, explode, or escape can send a gravitational signal whose net effect leaves distant freely falling bodies displaced relative to one another.

Start with a collision that does not bind everything into one final object. Two masses approach, interact gravitationally, and depart with velocities different from the velocities they had on arrival. Far away, the gravitational field before the encounter is associated with one set of moving sources. Far after, it is associated with another. The transition radiates. Because the initial and final source motions differ, the radiative metric perturbation need not average back to the same baseline.

The detector does not need to know the biography of the masses. It responds to the change in the field.

This is an important discipline. Memory is sometimes explained as though the universe stores a description of the event. The actual observable is much poorer and therefore much more believable. A displacement pattern can encode information about integrated energy and momentum flow and source geometry, but it is not a lossless recording. Many different source histories can produce similar integrated effects. The memory is a consequence, not a replay.

That distinction will matter later when we talk about the human urge to turn “memory” into metaphysics. A burn mark remembers a fire only in the loose sense that the fire changed the material. From the mark alone you may infer temperature ranges, direction, duration, fuel, or sequence if other evidence survives. You cannot reconstruct every eddy of hot gas. Gravitational memory is closer to a burn mark than a video.

The early gravitational-memory literature grew from thinking about unbound motions and astrophysical events capable of ejecting matter. A supernova, for example, can produce memory if mass-energy is expelled anisotropically. Neutrinos carry enormous energy from core collapse, and anisotropic neutrino emission can contribute a gravitational-wave memory signal. Matter ejection can contribute as well. Compact-binary mergers can have ordinary memory associated with changes in massive components, though for binary black-hole systems the nonlinear gravitational-wave contribution is especially important in modern discussions.

The word anisotropic is doing work. Perfect spherical symmetry is a ruthless eraser of many radiative observables. If equal amounts of energy fly in every direction, directional contributions can cancel in the quadrupolar patterns relevant for gravitational radiation. Memory becomes informative when the flux has structure.

Nature has structure.

Jets choose axes. Supernovae are messy. Binary systems define orbital planes. Black-hole mergers can radiate more momentum in one direction than another and kick the remnant. Neutron-star mergers throw matter into tidal tails and winds. The universe rarely consults our desire for perfect symmetry before exploding.

Yet asymmetry alone is not enough for an easy detection. The signal scales with distance and source energetics, and the slowly varying component sits in difficult frequency territory. A nearby core-collapse supernova would be scientifically extravagant: neutrinos, electromagnetic light, perhaps gravitational waves, nucleosynthesis clues, and memory-related signatures could all be brought to bear. The rarity of a Galactic supernova makes the opportunity precious precisely because no instrument team can schedule it.

This exposes another human role in aftermath science: preparedness.

A transient does not care whether the detector is commissioned, the data-quality channel is healthy, the archive metadata is correct, or the graduate student responsible for the pipeline is awake. The event happens once. If an observable is a persistent aftermath, there may be more time to infer it than for a millisecond flash, but the relevant before-state still has to exist. You cannot measure a change from a baseline you never characterized.

Gravitational memory is therefore a science of the before as much as the after.

This is a deeper point than it looks. Modern measurement culture is obsessed with the latest data point. Dashboards refresh. Telescopes trigger. alerts propagate. Memory reverses the priority. To know that a state has shifted, old information must remain commensurable with new information. Calibration histories matter. Reference frames matter. Clock models matter. Detector configuration matters. A permanent effect without a trustworthy prior state is indistinguishable from ignorance about where you started.

The same logic applies in pulsar timing. Millisecond pulsars serve as extraordinarily stable celestial clocks after their spin behavior, orbital parameters, propagation effects, astrometry, and other contributions are modeled. A burst with memory would not simply appear as a pretty pulse in the radio telescope. It could create a characteristic change in timing residual behavior across an array of pulsars. Detecting it depends on years of preexisting timing models and correlated geometry across the sky.

The event might be brief. The evidence is longitudinal.

This mismatch between cause duration and evidentiary duration is easy to miss. A court case may turn on a transaction that took seconds but requires years of records. A volcanic eruption may last days but leave deposits read thousands of years later. A market crash may occur in hours but permanently change institutions, regulation, and capital structure. None is mathematically analogous to gravitational memory, but all punish the same cognitive shortcut: event duration does not determine consequence duration.

Ordinary memory makes that shortcut physically explicit.

Suppose a massive object is accelerated from one constant velocity to another. In the far zone, the gravitational field associated with the moving mass differs between the early and late states. The transition generates radiation. A distant array feels a net effect. One can express the memory in terms of source momenta and directions. The details depend on approximation and setup, but the qualitative principle is the asymptotic change in motion.

There is something aesthetically satisfying about this because velocity itself is relational. The memory is not a cosmic speedometer filing a report. It is the gravitational field carrying the consequence of changed momentum to other systems.

Conservation laws close the loop. If matter is ejected, momentum and energy go somewhere. If radiation carries momentum, the source recoils. If the asymptotic state changes, flux-balance laws relate that change to what crossed the boundary. Memory is one of the ways the ledger becomes geometric.

I hesitate over the word ledger because it can suggest exact accounting. Physics conservation laws are exact within the theory, but measurement is not. Astrophysical inference deals with incomplete sky coverage, detector noise, model uncertainty, cosmological distances, source populations, and selection effects. The theoretical balance equation does not hand an observer perfect knowledge of every term.

This difference between ontological accounting and epistemic accounting will return throughout the book.

The universe can obey a conservation law that we cannot fully verify for a particular event. A permanent memory contribution can exist below our detection threshold. A signal can be present in the metric while absent from the catalog. Reality is not obligated to become data.

That is a useful corrective to an age increasingly confused by instrumented systems. We have built enough sensors that people casually equate what happened with what was logged. The equivalence fails in both directions. Sensors can hallucinate events through noise and artifact. Events can leave no usable sensor record. Memory physics dramatizes the middle territory: an effect may be real, predicted, structured, and still extraordinarily hard to recover.

The first direct detection of gravitational waves was possible because theory, numerical relativity, laser interferometry, vibration isolation, vacuum engineering, computing, statistics, and decades of institutional patience all converged. The waves had crossed Earth long before 2015. Nature did not begin radiating when we learned to measure it.

Memory is likely the same kind of insult to chronology. If general relativity is right in the relevant regime, gravitational-wave memory has been washing through the solar system whenever suitable distant events occurred. The fact that no individual compact-binary memory signal has yet been established at high confidence does not mean the effect was absent. It means we have not yet built an observational case strong enough to separate it from noise and competing explanations.

That distinction is not a loophole. It is falsifiability's working environment.

A theory predicts amplitude distributions and waveform structures. Detectors acquire data. Searches produce limits, candidates, or non-detections. Future instruments move the threshold. Population observations make statistical tests possible. If increasingly sensitive experiments fail where robust predictions say memory should appear, the theory, waveform models, astrophysical assumptions, or analysis must give.

A claim that cannot lose is not physics. Memory can lose.

This is another reason to prefer ordinary memory before the more glamorous asymptotic-symmetry story. It keeps the phenomenon tied to sources that throw things around. A star explodes asymmetrically. Mass leaves. Momentum changes. Gravity tells distant matter about the change. The telling has a residue.

No cosmic consciousness is required.

Only an event that fails to put everything back.
