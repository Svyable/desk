# An Experiment Designed to Kill the Idea

The best experiment for an exotic hypothesis should be designed by someone hoping to make it disappear.

Not because hostility is virtuous. Because a hypothesis that has survived mainly by living in inaccessible territory needs an analysis architecture that cannot quietly move the goalposts after the data arrive.

A serious georeactor test would begin with preregistered source families. One family at Earth's center. Several at the core-mantle boundary. A range of thermal powers. Plausible fast-reactor fuel compositions rather than a single commercial-reactor template. Fixed oscillation parameters with stated uncertainties. Detector energy response established from calibration data, not tuned to an excess.

Then define the null world carefully. Known commercial reactors enter with time-dependent thermal powers and fuel evolution. Crustal and mantle uranium-thorium geoneutrinos enter with geological uncertainty. Cosmogenic and radioactive detector backgrounds enter from sidebands and control samples. Spent-fuel contributions are included where relevant.

Before looking at the final signal region, the collaboration should inject synthetic deep sources into scrambled or simulated data. Can the pipeline recover a 3 TW central reactor? One terawatt? Five hundred gigawatts? How often does an incorrect reactor-power history create a fake source? How much do alternate crust models move the answer?

The result should be reported as an exclusion surface, not merely a binary discovery statement: allowable fission power as a function of source position and assumed spectrum. If the best fit is nonzero, require consistency across independent detectors before using the word georeactor.

A true central source has a useful prediction: every surface detector is nearly the same distance from it. Flux differences should therefore be driven mainly by detector size and efficiency, not geography, while known reactor and crustal backgrounds vary strongly by location. A core-mantle-boundary source would create a geographic gradient. That distinction can be exploited even before event-level directionality becomes excellent.

The analysis should also publish what would falsify the more ambitious consequences. If helium models require at least some fission power, state that threshold. If a geomagnetic model requires more, state it. Then an upper limit can kill those claims even if it cannot exclude every microscopic reactor.

There is one more safeguard: publish the null.

Anomalous fields are damaged when only suggestive episodes survive. A multi-year neutrino exposure that finds no central fission component is not a failed project. It is a measurement of what Earth is not doing.

That is enough. Science does not owe every strange idea a discovery. It owes a sufficiently precise strange idea a chance to fail.
