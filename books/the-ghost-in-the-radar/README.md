## Thesis

PALLADIUM turns an old epistemic problem into an engineering problem: a state can manufacture a convincing detection of an object that does not exist, then learn from the adversary's very real reaction to the nonexistent thing. The useful collision is between Cold War radar deception, ELINT, stealth development, and modern arguments that treat sensor corroboration as though it automatically establishes a physical craft.

This book does **not** argue that PALLADIUM explains modern UAP cases. It asks the harder and more useful question: once deception systems can deliberately manufacture tracks, what evidence is required to move from signal to object, from object to performance, and from performance to agency?

## Defeat condition

The central thesis weakens if the historical record shows PALLADIUM could not generate operationally convincing false tracks, or if modern independently calibrated multi-sensor systems can be shown to make deliberate signal-level deception irrelevant to object inference. Conversely, proving that radar deception exists does not establish that any particular unexplained modern case was deception. Case-level attribution requires case-level evidence.
