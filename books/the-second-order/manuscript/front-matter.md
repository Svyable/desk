# Front Matter

A forecast is usually presented as an answer.

Rain tomorrow. Inflation next quarter. A patient's risk of deterioration. A student's likelihood of graduating. The probability that a transaction is fraudulent. The chance that a neighborhood will produce crime. The expected value of a trade.

The number arrives with the quiet authority of something already observed.

Then somebody acts on it.

The umbrella comes out. The central bank changes policy. The patient receives treatment. The student gets tutoring or is denied admission. The transaction is blocked. Patrols are moved. The trade is crowded.

The forecast has crossed a boundary.

It is no longer only a description of the world. It has become one of the causes operating inside the world.

That boundary is the subject of this book.

Modern prediction has become very good at the first-order problem: estimate what is likely to happen given the data we have. The harder problem begins after deployment. People learn rules. Institutions reorganize around measures. Adversaries probe boundaries. Markets absorb forecasts. Algorithms determine which examples will be observed next. Successful interventions prevent the outcomes that made the intervention look necessary in the first place.

The data-generating process moves.

Sometimes this is exactly what we want.

A clinical risk model should change care if it identifies a patient in danger. A weather warning should change behavior if a storm is coming. A quality metric should direct attention toward neglected failures. A fraud detector should make fraud less attractive. A recommendation system should help users find material they would otherwise miss.

The difficulty is that useful intervention complicates later interpretation.

If the patient survives because the model triggered treatment, the model's original prediction can appear wrong. If a high ranking attracts stronger applicants, the next year's data partly reflect the ranking itself. If a test determines funding, schools learn the test. If police go where prior police activity generated more records, the next round of records reflects both underlying behavior and where police looked.

This is not a book against prediction, measurement, rankings, tests, algorithms, or models.

It is a book about what happens when they matter.

The chapters move through economics, markets, education, medicine, policing, recommendation systems, experiments, benchmarks, adversaries, public forecasts, policy, and autonomous agents. The cases differ because the response mechanisms differ. A market reacts through price and position. A school reacts through time and curriculum. A hospital reacts through treatment. An adversary reacts strategically. A platform changes exposure. A bureaucracy changes classification and effort.

The common mistake is to treat the pre-deployment relationship as though it were guaranteed to survive those responses.

It often does not.

That does not mean every social parameter is unstable or every metric is doomed. Some systems barely react. Some adaptations improve the objective. Some rules remain robust under sustained pressure. Some measurements are hard to game because the measured quantity is close to the thing we actually care about. Some interventions create better data rather than worse data.

The interesting question is conditional.

When does the act of measuring, predicting, ranking, or deciding become important enough to change what will be measured next?

Once that happens, accuracy is still necessary. It is no longer sufficient.

The relevant unit of analysis becomes the loop: model, decision, response, observation, update.

A good system has to survive contact with that loop.

It needs ways to distinguish genuine improvement from proxy optimization. It needs evidence channels that are not selected entirely by the model being evaluated. It needs enough institutional memory to remember why a rule was adopted and enough flexibility to revise the rule when the environment changes. It needs to understand that people are not noise around the prediction. Their response is part of the mechanism.

This sounds abstract until the first case makes it concrete.

A forecast enters the world.

The world reacts.

The next observation is already different because the forecast existed.
