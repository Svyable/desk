# 16 — How an Anomaly Hardens

The phrase “extraordinary claims require extraordinary evidence” is too vague to run a telescope.

FRBs suggest a more operational sequence.

First, preserve the event well enough that someone else can interrogate it. Second, characterize the instrument and interference environment. Third, find another event under conditions that do not share the same obvious failure modes. Fourth, turn look-alikes into measured contaminant classes. Fifth, predict distinctions between contaminant and candidate. Sixth, localize. Seventh, connect the transient to an independent astrophysical environment. Eighth, find a nearby source class capable of producing relevant emission. Ninth, use the growing sample for predictions that were not required to establish the phenomenon in the first place.

That sequence is not a universal recipe. It is what happened, approximately, to FRBs.

The important feature is that mystery decreases while scientific value increases.

At the beginning, the Lorimer burst was compelling partly because it was strange. Today, no serious FRB paper needs strangeness as evidence. The class has independent detections, repeaters, host galaxies, population catalogs, a Galactic magnetar analog, and cosmological applications.

This is what I mean by anomaly hardening.

A hard anomaly is not one that remains unexplained forever. It is one whose reality becomes increasingly independent of the explanation currently favored.

The perytons are central to this definition. If astronomers had ignored them, the class would have remained softer. If perytons had reproduced the key FRB properties under the relevant conditions, the class might have died. Instead the contaminant became specific and separable.

The scientific virtue here is not credulity. It is adversarial curiosity.

Ask the signal to survive.
