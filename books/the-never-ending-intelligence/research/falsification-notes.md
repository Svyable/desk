# Falsification Notes

These notes pressure-test the manuscript chapter by chapter. They are not rhetorical disclaimers; later evidence should change the book when one of these conditions becomes true.

## Ch 1 — The Invocation Was a Historical Accident
**Claim under pressure:** Session-bound invocation is transitional for work containing waiting, delayed outcomes, or changing evidence.  
**What would weaken it:** If humans consistently prefer explicit re-invocation, or if security/privacy costs make event-triggered continuation uneconomic outside narrow workflows.

## Ch 2 — The Intelligence That Dies Every Minute
**Claim under pressure:** Durable agency can survive replaceable, stateless reasoning workers.  
**What would weaken it:** If future model-native recurrent state becomes so valuable that replacing the active cognitive substrate reliably destroys essential capability that cannot be externalized.

## Ch 3 — State Is Somewhere Else
**Claim under pressure:** Mature agents will externalize most durable state into typed systems rather than one undifferentiated model memory.  
**What would weaken it:** If model-native memory becomes cheaper, safer, more inspectable, and more reliable than external state composition across most important domains.

## Ch 4 — Memory Is Not a Transcript
**Claim under pressure:** Long-lived systems need transformed, typed, scoped, decaying memory rather than transcript accumulation.  
**What would weaken it:** If near-perfect retrieval over complete histories becomes cheap enough and context discrimination reliable enough that explicit memory curation adds more errors than it prevents.

## Ch 5 — The Loop Persists
**Claim under pressure:** Sleep/wake cycles and durable workflow state are core primitives of economical persistent agents.  
**What would weaken it:** If continuous low-cost inference becomes so cheap that maintaining wake conditions and reconstructing state costs more than simply keeping cognition active.

## Ch 6 — Identity Without a Process
**Claim under pressure:** Operational identity will attach to a durable principal rather than a model invocation.  
**What would weaken it:** If agent actions remain legally and operationally attributable only to the initiating human and no practical need emerges for persistent machine principals.

## Ch 7 — The Event-Sourced Mind
**Claim under pressure:** Consequential event histories will be central to reconstructability and evaluation.  
**What would weaken it:** If event sourcing proves too complex or privacy-intensive and simpler snapshots plus external audit logs provide equivalent accountability and recovery.

## Ch 8 — Goals That Survive Their Thinkers
**Claim under pressure:** Persistent goals require ownership, versioning, review, termination and authority rules.  
**What would weaken it:** If durable agents remain so tightly bounded and short-lived that goals rarely outlast the human session in which they were created.

## Ch 9 — Agents That Wake Up
**Claim under pressure:** Autonomy over attention—knowing when to think—will be a major capability.  
**What would weaken it:** If event filtering and false wakeups remain too unreliable, causing organizations to keep wake decisions deterministic or human-initiated.

## Ch 10 — The World Is the Context Window
**Claim under pressure:** Navigation of authoritative external state will matter more than maximizing loaded context.  
**What would weaken it:** If context windows and retrieval become effectively unlimited at negligible cost and models remain equally accurate despite enormous heterogeneous context.

## Ch 11 — Repositories as Long-Term Memory
**Claim under pressure:** Durable learning will migrate into artifacts, tests, tools and structured environments.  
**What would weaken it:** If agents fail to create reliable executable improvements or if self-produced infrastructure introduces more brittle complexity than remembered procedure.

## Ch 12 — The Harness Becomes the Organism
**Claim under pressure:** Effective agent capability will increasingly be a property of the whole harness rather than the base model alone.  
**What would weaken it:** If frontier models become sufficiently self-contained that routing, memory, context engineering, workflow machinery and specialized tools add little value.

## Ch 13 — Evolution by Evaluation
**Claim under pressure:** Agent systems can improve materially through harness changes selected by evaluations without weight updates.  
**What would weaken it:** If evaluations are too gameable or local to produce durable improvements, or if most improvement continues to come from base-model upgrades.

## Ch 14 — Forking the Self
**Claim under pressure:** Cheap parallel cognitive branches will become a useful default for difficult reasoning.  
**What would weaken it:** If correlated errors dominate, integration costs exceed gains, or single-agent internal search becomes more efficient than explicit forks.

## Ch 15 — A Society of Temporary Minds
**Claim under pressure:** Organizations of temporary machine roles will outperform fixed single-agent topologies for many complex tasks.  
**What would weaken it:** If inter-agent communication overhead and error propagation make multi-agent structures consistently inferior to one well-equipped model.

## Ch 16 — The Supervisor That Never Sleeps
**Claim under pressure:** Persistent supervisory agents will discover cross-episode patterns invisible to temporary workers.  
**What would weaken it:** If ordinary observability and deterministic analytics catch the same patterns more reliably, or if machine supervision creates unacceptable surveillance and governance costs.

## Ch 17 — Continuous Science
**Claim under pressure:** Persistent agents can cheaply maintain dormant hypotheses and living evidence maps.  
**What would weaken it:** If scientific novelty depends too strongly on embodied laboratory skill, tacit knowledge, or conceptual reframing for persistent monitoring to add meaningful value.

## Ch 18 — Continuous Companies
**Claim under pressure:** Firms will acquire durable synthetic responsibilities that summon temporary cognition on demand.  
**What would weaken it:** If organizations retain AI mainly as employee-invoked assistance and do not delegate standing responsibility because liability and integration costs dominate.

## Ch 19 — Continuous Government
**Claim under pressure:** Public institutions can gain useful continuity from persistent agents while preserving lawful human authority.  
**What would weaken it:** If democratic accountability, procurement constraints, privacy, vendor dependence, or legal due-process requirements make long-lived administrative agents untenable.

## Ch 20 — The Security Problem of Persistent Intent
**Claim under pressure:** Persistence creates security risks qualitatively different from one-shot model failures because compromised intent can survive invocations.  
**What would weaken it:** If systems keep durable goals, triggers and authority entirely outside model-writable surfaces, reducing persistent-intent attacks to ordinary infrastructure compromise.

## Ch 21 — When the Goal Outlives the Operator
**Claim under pressure:** Agent succession will become a practical governance category.  
**What would weaken it:** If long-lived personal and institutional agents remain rare, or if policy defaults simply terminate all authority whenever the initiating owner disappears.

## Ch 22 — Forgetting on Purpose
**Claim under pressure:** Deliberate forgetting is necessary for accuracy, privacy, security and social renewal.  
**What would weaken it:** If perfect provenance and relevance scoring make retained history harmless while deletion creates greater audit and learning costs.

## Ch 23 — Death Becomes an Implementation Detail
**Claim under pressure:** Model-process death can become routine while agent continuity persists.  
**What would weaken it:** If essential learned state remains irreducibly embedded in the active model process or future architectures make live migration preferable to reconstruction.

## Ch 24 — Intelligence as Infrastructure
**Claim under pressure:** Persistent intelligence will disappear into projects, institutions and objects rather than remain a conspicuous destination product.  
**What would weaken it:** If conversational interfaces remain the dominant locus of value and users resist background agency or shared institutional agents.

## Ch 25 — The Never Ending Intelligence
**Claim under pressure:** The durable future of agents is continuity separated from survival of any one reasoning process.  
**What would weaken it:** A future dominated by monolithic continuously running minds whose unique internal state cannot be reconstructed or ported would make the book's central architectural forecast substantially wrong.
