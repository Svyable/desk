# Searching for Absence

Most telescopes are built to detect something.

A disappearance experiment is built to trust nothing.

The measurement is a comparison between expected presence and observed absence. That means the experiment has to model every reason expectation can fail. Position changes. brightness changes. bandpass differences. saturation. blending. survey holes. detector defects. bad astrometry. bad catalog associations. bad assumptions about what the source was in the first place.

This makes disappearance a surprisingly demanding technosignature.

Radio SETI can look for a narrowband signal with properties difficult for known astrophysics to produce. An optical laser search can look for short bright pulses. A transit search can look for geometric shapes. A missing-star search lacks a positive waveform. It asks whether the universe failed to provide a photon budget it had previously provided.

Absence becomes strong evidence only when detection should have been nearly certain.

The phrase nearly certain is where all the work lives.

A modern survey can fail to detect an object because it did not observe that exact location deeply enough. Clouds, seeing and moonlight affect depth. Chip gaps create holes. bright-star masks remove regions. crowded fields reduce completeness. A catalogue may exclude sources that appear in images because quality flags are conservative. Cross-match pipelines can reject unusual colors.

Therefore a serious candidate should be tested against images, not only catalogues.

Then independent instruments should be used. If Pan-STARRS lacks the source, inspect SDSS where available, Gaia, ZTF stacks, DESI Legacy Imaging, infrared surveys and targeted telescope data. If the object persists in the infrared, disappearance has become spectral rather than total. If a source appears in a later optical epoch with large displacement, proper motion wins.

The strongest search would also require multiple pre-disappearance detections. A star seen once is a transient candidate. A star seen repeatedly for decades and then gone is a disappearance candidate.

This sounds like semantics. It changes the prior probability by orders of magnitude.

VASCO's one-epoch red sources are scientifically interesting precisely because they are not yet the strongest vanishing-star class. They may be fast transients. The project name includes appearing sources for a reason. An archive comparison discovers temporal exceptions in both directions.

A future survey pipeline should therefore classify temporal topology before physical cause. Was the object persistent then absent? absent then persistent? single-epoch only? recurrent? periodic? moving? clustered with other transients? Each topology has different natural explanations.

The method can also borrow from medicine. Screening tests are judged by false-positive rate, sensitivity and prevalence. When the target condition is extremely rare, even a highly specific test can produce mostly false positives. Technosignatures are the ultimate low-prevalence screening problem because we do not know whether the condition exists in the searchable population at all.

This makes base rates impossible to ignore.

If one searches six hundred million catalogue entries, a false-positive rate of one in a million still produces six hundred apparent anomalies. If a processing artifact occurs once per ten thousand plate detections, the archive will manufacture a civilization's worth of mysteries.

The correct response is not despair. It is layered specificity.

Require independent detections. Require multiwavelength inconsistency with known sources. Require repeatable anomaly classes. Use control samples. Blind the classification when testing correlations. Separate discovery data from confirmation data. Preregister the strangest statistical tests after the first exploratory pass.

Most importantly, build the search so ordinary explanations can win decisively.

An anomaly program that cannot close cases is not a scientific instrument. It is a collection hobby.

Searching for absence therefore has an ethical dimension inside science. Candidates will attract attention disproportionate to their certainty. Coordinates can become internet mythology. Researchers may feel pressure to defend the interestingness of an object they discovered. Skeptics may feel pressure to dismiss the entire field because the word extraterrestrial appeared in the abstract.

The only stable position is procedural.

Define what would make the candidate boring.

Then go look for it.
