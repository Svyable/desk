# Secrecy Has a Half-Life

Project Iceworm's secrecy did not make it permanent.

Documents were declassified. Historians reconstructed policy. Scientists modeled the waste. The base itself became an observable subsurface target. A program once compartmented by military necessity now exists as a public interdisciplinary object shared by glaciologists, political scientists, engineers and environmental researchers.

This does not mean secrecy always fails quickly. Some programs remain obscure for decades. Nor does it mean declassification produces a complete record. Missing files, ambiguous chains of approval and institutional memory leave genuine uncertainty.

But physical projects have a second archival system outside classification rules.

They leave roads, tunnels, waste, isotopes, contractor records, altered landscapes, pensioners, samples and maintenance histories. Camp Century's most enduring disclosure mechanism may not have been FOIA. It may have been ice flow.

That observation should discipline modern claims about enormous hidden technological programs. The question is not whether secrecy can hide a project. Clearly it can. The question is what physical dependencies accumulate as the project grows, how long those dependencies can remain uncorrelated, and which traces survive the original security boundary.

Camp Century is especially useful because the answer is not simple exposure.

The secret became public in pieces, while the site kept moving beneath everyone.
