# 16 — Friction Is a Weapon System

Military systems are trained to hate friction. Nuclear safety sometimes needs it.

A second authentication step, an independent sensor, a requirement to verbalize contradictory evidence, a survivable retaliatory force that removes urgency—these can look like inefficiencies. They consume seconds. They are also barriers against irreversible error.

Not all friction is good. Confusing procedure, unreliable communications and bureaucratic delay can be lethal. The distinction is between accidental friction and designed epistemic friction: pauses that force independent claims to meet before action.

A useful safety case should identify which barriers exist, which failure modes each addresses, and which dependencies can defeat several barriers at once. It should rehearse false positives as seriously as true attacks. Operators should practice saying 'the data are inconsistent' without that sentence being treated as weakness.

This is where the historical cases stop being anecdotes. The 1979 system recovered through checks. The 1980 system recovered through sensor contradiction. The Able Archer story suggests reciprocal restraint can matter when signals are ambiguous. Each is a different form of friction.

The weapon system nobody parades is the mechanism that keeps a correctable mistake correctable.
