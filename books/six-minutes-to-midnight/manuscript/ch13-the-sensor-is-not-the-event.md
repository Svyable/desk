# 13 — The Sensor Is Not the Event

A sensor measures interaction. An event is an inference.

Infrared detectors measure radiation. Radars measure returned electromagnetic energy. Human observers measure experience through attention and expectation. None directly measures 'enemy nuclear attack.' That phrase is assembled downstream.

This sounds elementary until systems become good. High-performing systems encourage semantic collapse: detection becomes object, object becomes intent. The better the classifier, the easier it is to forget the distance between layers.

The remedy is not philosophical modesty. It is operational bookkeeping. Preserve raw measurements. Preserve transformations. Preserve alternative hypotheses. Maintain physically independent channels. Test the system with rare environmental conditions and adversarial inputs, not only average cases.

The 1980 false warning was exposed because direct warning sensors did not contain the attack the computer display contained. That disagreement was gold. Modern fusion systems should be designed not merely to reconcile disagreement but to protect it long enough to understand why it exists.

Consensus is useful after error has been ruled out. Before then, disagreement is a sensor.
