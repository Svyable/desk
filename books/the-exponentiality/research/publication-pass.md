# Publication pass — The Exponentiality

Updated: 2026-09-17

## Publication thesis

*The Exponentiality* argues that rapidly improving intelligence does not make society move on one exponential curve. It changes the location of bottlenecks. As some cognitive work becomes cheaper, relatively scarce complements—judgment, verification, trust, physical throughput, institutional absorption, legitimate authority, and adaptation time—can become more important.

The book should be published as a framework for observing changing bottlenecks, not as a date-specific prediction of one singular takeoff moment.

## Whole-book boundaries

A release edit should preserve these distinctions:

- model capability is not the same as economic adoption;
- cognitive abundance is not material abundance;
- faster answer generation is not automatically faster legitimate decision-making;
- human review is only meaningful when reviewers have enough capacity, authority, evidence, and time to intervene;
- protective friction and obsolete friction must not be treated as the same thing;
- exponential improvement is not assumed to persist indefinitely across every relevant capability;
- transition costs are distributed unevenly, especially where people have unequal savings, bargaining power, appeal rights, or reversibility.
