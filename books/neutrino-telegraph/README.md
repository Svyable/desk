This manuscript tests an uncomfortable proposition: some exotic military technologies are not hidden because they are secret; they are absent because the underlying physics imposes an industrial footprint too large to hide. Neutrino communication is the unusually clean case because the extraordinary-sounding part has already been demonstrated.
