# Evidence ledger — The Object That Wasn't There

## Working thesis

Modern UAP evidence is unusually vulnerable to an ontology error: treating a sensor detection as though it already establishes a discrete object with the size, range, velocity, acceleration, temperature, shape and behavior inferred by an observer. The book tests whether disciplined sensor phenomenology collapses a meaningful fraction of extraordinary-performance claims while leaving a smaller, better-defined residue genuinely unresolved.

## Class 1 — verified / documented

- AARO defines UAP partly in terms of anomalous detections and publicly distinguishes unresolved detections from demonstrated extraordinary capability: https://www.aaro.mil/
- AARO public imagery includes cases resolved as balloons and migratory birds, cases where physical objects are judged present but unattributed, and cases where the available record cannot distinguish physical source from sensor/display effects: https://www.aaro.mil/UAP-Cases/Official-UAP-Imagery/
- AARO's 2026 transparency material explicitly says unresolved status can result from insufficient data and publishes cases without asserting their nature: https://www.aaro.mil/Next-AARO-Home-redesign/Next-Parent/Presidential-UAP-Transparency-Initiative/
- AARO's reporting-trends page now covers reports through August 15, 2026 and provides closed-case resolution outcomes. Preserve counts only after page-level capture rather than transcribing dynamic graphics: https://www.aaro.mil/UAP-Cases/UAP-Reporting-Trends/

## Class 2 — credible but incomplete

- Military eyewitness reports can preserve valuable geometry, chronology, display behavior and platform context but must be separated from quantities not independently measured in the public record.
- AARO's released case descriptions sometimes preserve observer language such as reported turns, shapes or behavior while explicitly warning that descriptions are not analytical determinations. Treat report language as report language.
- Classified sensor capability can create a legitimate public-evidence ceiling. Absence of released telemetry is not evidence that telemetry does not exist; it is also not permission to assume that hidden telemetry proves extraordinary performance.

## Class 3 — disputed / unconfirmed

- Claims that specific public cases demonstrate instantaneous acceleration, hypersonic speed, transmedium travel or propulsion beyond known technology unless calibrated range/geometry/telemetry establishes those quantities.
- Claims that unresolved AARO cases establish non-human technology.
- Claims that plasma explains UAP as a class. Atmospheric/plasma phenomena are candidate mechanisms for some luminous observations, not a universal identification.
- Claims that multiple sensors automatically constitute independent corroboration. Independence must be demonstrated from acquisition and processing architecture.

## Class 4 — synthesis / open conjecture

- The UAP controversy may partly be an ontology pipeline: detection → object → craft → performance → agency, with uncertainty silently discarded at each noun change.
- Sensor classification may paradoxically preserve mystery. Protecting platform/sensor details can prevent public reconstruction of range, field of view, processing and geometry, making extraordinary claims harder both to prove and to falsify.
- A useful public UAP science should publish uncertainty budgets, not merely videos.

## Contradiction audit

The thesis fails if strong public cases already contain independent calibrated range, velocity and acceleration measurements that survive platform-motion, optical, processing, atmospheric and conventional-object alternatives. Search for those cases rather than assuming they do not exist.

The thesis also weakens if resolved-case explanations routinely depend on ad hoc possibilities without positive evidence. A skeptical explanation must carry its own burden.

## Incentive audit

- Defense agencies have legitimate reasons to conceal sensor characteristics, collection geometry and platform capability.
- Witnesses can gain or lose status depending on institutional climate; neither ridicule nor prestige validates measurements.
- UAP media has a commercial incentive to promote spectacular interpretations.
- Government offices have reputational incentives to resolve cases conventionally and institutional incentives to avoid exposing collection capabilities. Track both without presuming bad faith.
- Skeptical communities have incentives to close cases; advocacy communities have incentives to preserve anomalies. Neither incentive is itself evidence.

## Defeat condition

A defensible set of public cases with calibrated independent measurements showing genuinely extraordinary kinematics after full sensor/geometry audit requires the book to narrow or abandon the central sensor-ambiguity thesis. Unresolved status alone never satisfies this condition.
