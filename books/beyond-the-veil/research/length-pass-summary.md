# Publication-length editorial pass

This pass strengthens the chapters that were materially shorter than the later manuscript rather than padding the book uniformly.

- **Chapter 1** now distinguishes adaptive network control from passive optimization, makes perturbation and counterfactual response central, and bounds Physarum competence by domain.
- **Chapter 2** ties bacterial temporal memory to receptor-state dynamics, adds functional forgetting/timescale matching, and makes the “scientific redundancy” objection to non-sapient intellect explicit.
- **Chapter 3** deepens positional control, distributed target state, planarian-memory caveats, immune-state distribution, bioelectric pattern regulation, and physiological adaptation under perturbation.
- **Chapter 19** is rebuilt around detector bias across sensory modality, social legibility, speed, scale, system boundary, scientific instrumentation, and search strategy.
- **Chapter 20** now functions as an evidence protocol: reproducibility, causal history dependence, selective correction, information pathways, explicit performance measures, flexibility profiles, serious alternatives, convergent evidence, and prediction.

The canonical local validation remains:

```bash
python3 scripts/check-book-length.py beyond-the-veil
```

The publication process should not substitute byte-size inference or editorial judgment for that executable gate.
