# The Window Onto Everything

The World Wide Web was invented in Europe in 1989.

The 1990s winner was the thing that made millions of Americans want to look at it.

That distinction matters.

Tim Berners-Lee, a British computer scientist working at CERN near Geneva, proposed a linked information system in March 1989. By the end of 1990, working with Robert Cailliau and others, he had defined the basic Web technologies—URLs, HTTP, HTML—built the first server, and written the first browser-editor on a NeXT computer.

The Web existed.

Almost nobody knew what to do with that fact.

Early browsers were useful to researchers and technically inclined users, but the system remained small and visually austere. The internet itself already connected universities, government agencies, companies, and enthusiasts through email, file transfer, discussion groups, remote login, and other services. The Web was one application among many.

Then, in 1993, a group at the National Center for Supercomputing Applications at the University of Illinois released Mosaic.

The Web acquired a window ordinary people could understand.

The graphical web browser wins the 1990s because it transformed a powerful network protocol into a mass human interface.

Marc Andreessen and Eric Bina were central developers of NCSA Mosaic, working inside a publicly funded supercomputing center with a broader team. Mosaic was not the first graphical browser, and the browser itself did not invent the Web. Other graphical browsers existed, including ViolaWWW and Erwise. Berners-Lee’s original WorldWideWeb application had graphics-related capabilities on the NeXT platform and functioned as both browser and editor.

Mosaic’s breakthrough was not chronological purity.

It was usability, portability, and timing.

The software ran on systems that ordinary university and business users could access. It displayed text and images together in a page. Installation and navigation were approachable enough that the Web stopped feeling like a researcher’s information scheme and started feeling like a place.

That psychological shift changed the network.

Before graphical browsing, using networked information often required knowing commands, protocols, addresses, or specialized clients. The user needed to understand which service was being accessed and how.

A browser hid much of this difference behind the link.

Click.

The document arrives.

Click again.

Now you are somewhere else.

The link became a universal gesture for informational movement.

This is a profound interface invention because it changed what users had to know.

The telegraph operator needed code.

The telephone user needed a number.

The personal computer user needed commands or graphical menus.

The Web user increasingly needed only a destination or the curiosity to click.

The network became navigable by recognition rather than memory.

That is one reason Mosaic beats the search engine for the decade even though search would become indispensable. Search solves abundance after abundance exists. The browser helped create the abundance.

The timing in 1993 was extraordinary for another reason. On April 30, CERN placed the Web software into the public domain, and later made it available under an open license. Berners-Lee and CERN chose a path that did not impose a proprietary royalty on the basic Web standards.

That decision may be as important as any line of code.

A universal information system works better when people can implement it without negotiating with a single owner.

The browser and the open protocol stack reinforced each other. Anyone could publish a server. Anyone could build a browser. Anyone could create a page. Links could cross institutional boundaries without asking whether two companies had signed a content agreement.

The Web grew because compatibility was permissionless enough.

This is not a story of the public sector creating a thing and private industry merely harvesting it. It is an interaction among institutions. CERN supplied the core architecture and an open release. NCSA, supported by U.S. public research funding, made a browser that accelerated adoption. Andreessen left NCSA and co-founded Netscape with Jim Clark. Commercial internet service providers connected households. Telecommunications companies built capacity. Media companies, retailers, banks, software firms, and millions of users created websites.

The invention became an economy by changing institutional form repeatedly.

Research protocol.

Public software.

University browser.

Startup browser.

Commercial platform.

Mass medium.

The speed of that transition was startling.

By late 1993, CERN counted more than five hundred known web servers. By the end of 1994, the number had grown past ten thousand. Those figures are tiny compared with what followed, but they show the shape of an exponential adoption curve before the curve became culturally obvious.

The Web’s expansion changed the economics of publishing first.

A printing press makes copies cheaper than handwriting. The Web makes distribution of an additional digital copy nearly free.

This distinction detonated old media business models.

A newspaper had paid for presses, ink, paper, trucks, newsstands, and routes. A website could publish globally without printing one additional page. A small organization could reach readers without owning physical distribution. Individuals could publish without convincing an editor to allocate scarce space.

The cost of speech fell.

The cost of being heard did not.

That difference created the modern attention economy.

When publishing becomes cheap, abundance shifts the bottleneck from production to discovery. Search engines emerge. Portals emerge. Social networks emerge. Recommendation algorithms emerge. Advertising follows attention rather than paper circulation. The scarce resource becomes the user’s willingness to look.

The Web therefore did not abolish gatekeepers.

It changed which gate mattered.

A publisher once controlled access to a printing press and distribution network.

A search engine controls discoverability.

A social platform controls feed ranking.

An app store controls installation.

An AI assistant may increasingly control which information is summarized, cited, or acted upon.

Lowering one gate often raises the value of the next one.

Mosaic’s interface also accelerated commerce. The browser could display catalogs, forms, and eventually secure transactions. Encryption protocols improved. Companies experimented with online sales. Amazon and eBay were founded in 1994 and 1995. Online banking developed. Travel booking moved to the browser. Classified advertising, one of newspapers’ economic pillars, migrated online.

The Web turned information pages into storefronts.

That transition seems obvious now and was conceptually strange at the time. Why would someone enter a credit-card number into a computer? Why buy an object without touching it? Why trust a company with no local shop?

The same trust problem appeared with elevators, anesthesia, electricity, and phones.

Capability arrives first.

Institutions then construct enough trust for ordinary participation.

Secure sockets, certificates, payment processors, fraud systems, shipping logistics, return policies, reputation systems, and consumer expectations made electronic commerce normal.

The browser did not invent any of them.

It became the interface that assembled them into an experience.

That is the same kind of combinatorial invention that made the steamboat commercial and the smartphone transformative.

The interface is where systems become behavior.

The Web also altered the company itself. Internal websites and browser-based applications created intranets. Software could be delivered through network interfaces rather than installed locally in the traditional way. Business processes moved into web applications. Customer-service portals, enterprise tools, dashboards, and databases became accessible through the same browser metaphor used for news and shopping.

The browser became an operating system above operating systems.

That phrase was used aspirationally during the browser wars and became more true over time.

A modern user can write documents, edit images, manage finances, attend video meetings, run code, design products, access databases, and use artificial intelligence through a browser without knowing which local operating-system functions support the experience.

The application moves toward the network.

The endpoint becomes a window.

This created strategic conflict with companies that controlled personal-computer platforms. Netscape’s rapid rise threatened Microsoft, which responded by making Internet Explorer central to Windows. The resulting browser war became part of the U.S. government’s antitrust case against Microsoft.

The legal fight exposed how a seemingly free product can carry enormous strategic value.

A browser cost users nothing.

Control of the browser could influence standards, defaults, developers, and access to the emerging Web.

Zero price did not mean zero power.

This insight would become essential to understanding later internet businesses funded by advertising, data collection, ecosystem control, or strategic complementarity.

A product can be free because the customer is not where the profit is extracted.

The Web made such models scalable.

The 1990s contain other formidable inventions. Search engines developed. The modern lithium-ion battery was commercialized by Sony in 1991 based on scientific work by John Goodenough, Stanley Whittingham, Akira Yoshino, and others; that battery would become essential to laptops, phones, electric vehicles, and energy storage. GPS became fully operational and increasingly available for civilian use. Digital cellular networks expanded. Wi-Fi’s technical foundations emerged late in the decade. Human cloning fears erupted after Dolly the sheep was announced in 1997 from work in Scotland.

Lithium-ion batteries present the strongest challenge.

Without them, modern mobile computing and electric vehicles are much harder. They store enormous practical option value.

The browser wins because it reorganized more institutions immediately and because it turned the existing internet into a universal distribution layer for information, commerce, software, and later media.

The battery powers devices.

The Web connects their purposes.

The choice remains arguable, which is exactly what a forced-decade history should produce.

The Web also changed knowledge architecture. A book has a beginning and end. A library has shelves and catalogs. A website can contain links to documents elsewhere, which link onward indefinitely.

The reader acquires control over sequence.

This changes writing.

An author can cite by linking directly. A news story can connect to source material. A company can publish documentation that updates continuously. A scientist can distribute data. A community can maintain collaborative knowledge.

The page becomes a node rather than a terminal object.

That structure created Wikipedia in the next decade and transformed reference culture. The idea that an encyclopedia might be continuously edited by a global volunteer community would have been far harder without browser-based publishing and linking.

The Web made knowledge revisable in public.

This brought extraordinary benefits and obvious problems. False information could publish as cheaply as true information. A professional-looking page could be created without professional standards. Search ranking could be manipulated. Advertising incentives could reward sensationalism. Conspiracy communities could find one another across geography.

The telegraph lesson returned at larger scale.

Transmission is not judgment.

The Web lowered the cost of access to information and the cost of manufacturing information at the same time.

Society then had to build new methods for credibility.

Domain reputation.

Links.

Search ranking.

Editorial institutions.

Community moderation.

Fact-checking.

Identity systems.

None became universal.

The network increased the supply of evidence and the supply of nonsense.

This abundance is one of the direct ancestors of generative AI’s challenge. Large language models are trained on, retrieve from, and interact with a world whose textual abundance was accelerated by the Web. The open publishing environment created an enormous record of human expression and knowledge in machine-readable form.

The Web accidentally became a training corpus for future machines.

That is not why Berners-Lee invented it.

It is one of the strangest descendants of his decision to make documents linkable and accessible across networks.

The Web also changed surveillance. A visit to a physical bookstore can be private unless someone watches. A visit to a website creates the possibility of logs, cookies, identifiers, analytics, ad targeting, and behavioral profiles.

Digital interaction is recordable by default in a way analog browsing often was not.

The commercial internet discovered that attention could be measured at extraordinary granularity.

Which page?

Which link?

How long?

Which purchase?

Which search?

Which device?

The browser became a window in both directions.

The user looked out at the world.

The system could look back.

This altered advertising and eventually politics. Targeting became more precise. Platforms learned to personalize content. Campaigns used digital data. Recommendation systems optimized engagement. Privacy regulation struggled to catch up with an industry whose economics rewarded observation.

Again the externality emerges from the feature.

The Web is useful because the server knows what resource the user requested.

Personalization is useful because systems remember behavior.

At scale, useful memory becomes surveillance infrastructure unless constrained.

The 1990s did not resolve the bargain.

We still have not.

The browser itself changed from product to commodity. Netscape fell. Internet Explorer dominated and later declined. Firefox, Chrome, Safari, Edge, and others competed. Browser engines became extraordinarily complex software systems that render pages, execute code, manage security boundaries, decode media, store data, and expose hardware capabilities.

What looks like a page viewer became a virtual machine for modern life.

The simplicity of the link hid increasing complexity beneath it.

This is infrastructure’s favorite trick.

The interface gets easier as the stack gets harder.

The counterfactual is revealing because the Web itself already existed. If Mosaic had never been written, another accessible graphical browser would almost certainly have arrived. Viola and other projects show the field was active. Netscape might have emerged through a different lineage. Commercial online services such as AOL, CompuServe, and Prodigy already demonstrated consumer demand for networked information and communication.

Mosaic did not save a world waiting helplessly for graphics.

It crossed the adoption threshold at the right moment.

The Web was open.

The internet was expanding.

Personal computers were widespread enough.

Modems were improving.

A user-friendly graphical client made the stack legible.

Once people saw pages with images and links, the network stopped looking like plumbing.

It looked like somewhere to go.

That psychological shift is the invention.

Every previous network technology connected endpoints.

The browser gave the endpoint a world.

The first web proposal had been made to help physicists manage information.

Within a few years, the same architecture held stores, newspapers, fan pages, banks, pornography, universities, government services, diaries, scams, software, and nearly every other human institution willing to become a page.

The browser did not invent the world.

It taught the world how to fit through a window.
