## Quantitative chapter requirements

16. Model analyst interpretation as a possible source of both utility and overfitting: raw description → feature extraction → target match → operational decision.

## Adversarial replication design

A publication-worthy proposed test should be multisite, preregistered, and jointly designed by proponents and critics. Target generation and storage should be cryptographically committed before sessions; target pools should be large and audited for feature imbalance; viewers, experimenters and judges should be appropriately blinded; all sessions should be retained; judging should include a locked primary automated or independently specified metric; feedback timing should be controlled; exclusions fixed in advance; and the primary analysis reproduced by an independent statistics team. A second phase should test utility with targets drawn from a realistic open-world information problem rather than a small forced-choice pool.

The result must be allowed to fail twice: first as anomaly detection, then—if an anomaly survives—as a useful information channel.
