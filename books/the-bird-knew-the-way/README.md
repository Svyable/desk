# THE BIRD KNEW THE WAY

## How Intelligence Tried to Turn an Animal Sense into a Guidance System

**Author:** Sven Hardy Benson

## Thesis

CIA's pigeon-camera work creates an unusually clean collision between intelligence engineering and a biological faculty science still does not fully reduce to one sensor. The camera worked. The pigeon worked. The mission could still fail because the bird did not fly over the point intelligence officers wanted photographed. The governing object is **borrowed autonomy**: when an engineered system delegates guidance to an evolved organism, capability belongs to the coupled system, not to either component.

This is not a book claiming pigeons possess paranormal navigation. It is a book about something stranger and better documented: intelligence officers attempted to operationalize a natural navigation system whose map is assembled from overlapping visual, solar, olfactory and magnetic information, while later biology kept discovering that the apparently simple word `homing` concealed several separable mechanisms.
