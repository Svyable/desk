# 17 — What Evidence Should Exist

A useful theory risks being wrong.

So let us risk it.

If a large, decades-long, technically serious crash-retrieval and reverse-engineering program exists, then even under aggressive compartmentalization we should predict certain classes of residue.

Not public blueprints. Residue.

There should be acquisition records or references to unusual transfers whose destinations do not fit normal foreign-materiel channels. There should be security architectures whose scope matches the scientific breadth claimed. There should be laboratory pathways: contracts, facilities, unusually restricted test work, unexplained but technically coherent procurement. There should be configuration-control behavior around samples. There should be arguments over destructive testing. There should be safety systems appropriate to whatever hazards the objects present.

There should be failure.

There should also be knowledge transfer if the program has achieved useful replication. The transfer may be indirect. A classified materials insight could migrate into a conventional program under a different provenance story. A sensor discovery could appear as a requirement. But repeated successful exploitation over decades should not be technologically sterile.

This prediction can fail in two directions.

The first is obvious: no such program exists.

The second is subtler: a program exists but has learned little. In that case the secrecy footprint could be real while downstream capability remains absent. This possibility deserves more attention. A retrieval program and a successful reverse-engineering program are separate claims.

One can imagine a government storing baffling debris for seventy years without mastering it.

That would be historically extraordinary, but logically coherent.

The evidence expected for possession would differ from the evidence expected for breakthrough.

Possession predicts chain-of-custody infrastructure, storage, analysis attempts, security and institutional continuity.

Breakthrough predicts reproducible effects, engineering transfer, training, prototypes, manufacturing problems and operational consequences.

Conflating these allows weak evidence for one proposition to smuggle in the other.

The foreign MiG record keeps the two clean. The United States demonstrably possessed aircraft. It demonstrably extracted useful tactical knowledge. It demonstrably ran a training program based on that knowledge. Each step has distinct evidence.

The same standard should apply upward.

There is one more prediction: time should help.

Not necessarily quickly. But historical distance should alter the evidence state. People die and estates release papers. Classification reviews occur. facilities close. lawsuits expose fragments. allied archives open. corporate records migrate. The probability of documentary leakage changes.

If a claim remains forever in the same state—always imminent, always one witness away, always protected by an uncheckable compartment—that stability itself becomes evidence about the ecology of the claim.

Real secrets evolve.

Legends can remain perfectly adapted to secrecy forever because secrecy is the mechanism that protects them from falsification.

The test is not whether a story sounds like intelligence work.

The test is whether it behaves like a program.
