# Sketch Before Marble

A sketch is an agreement with yourself that you are still allowed to be wrong.

That is what makes it powerful.

The line can move. The figure can turn. A bridge can collapse on paper without killing anyone. A mechanism can violate geometry cheaply enough that the mistake becomes useful. An artist can try three hands, four heads, a different angle of light, and an impossible posture before committing pigment to the surface that will carry the mistake.

Leonardo drew constantly for reasons that exceed preparation for paintings. Drawing was a laboratory with almost no entry fee. It allowed an idea to leave the head before it had earned permanence.

Modern software has been reducing the cost of sketches for decades. Computer-aided design makes alternatives cheaper. Digital photography makes exposures almost free. Code can be branched and reverted. A slide can be duplicated before the risky edit. A spreadsheet can carry scenarios across columns.

Generative AI changes the slope.

The cost of producing a plausible candidate falls toward the cost of asking for one.

That sounds like pure abundance until the candidates arrive.

Twenty logos.

Thirty openings.

Ten product strategies.

Five architectures.

Forty names.

Six competing explanations.

A hundred lines of code before the person asking has decided what kind of system should exist.

The old problem was blankness.

The new problem is selection.

This shift is larger than it appears because much of human creative process has been organized around the expense of generating alternatives. Writers learn to tolerate bad first drafts partly because drafting is slow. Designers learn to sketch because rendering a final object is expensive. Engineers model because building is expensive. Investors screen opportunities because due diligence is expensive.

When plausible output becomes cheap, the ratio changes.

We can explore more.

We can also commit less.

A workshop that does not understand the difference will become a museum of drafts.

Leonardo offers an extreme caution here because his appetite for revision was enormous. The physical evidence in unfinished works such as the *Adoration of the Magi* shows a mind willing to alter positions, contours, structures, and relationships as the work developed. Conservators can see layers of decision that a completed painting might have hidden.

The temptation is to call this perfectionism and admire it.

Perfectionism is too flattering a word.

Revision is valuable only while it changes the expected quality of the finished object more than it changes the probability that the object will never be finished.

That trade is cruel.

Every creative person eventually feels it.

The next version could be better.

There is always another version.

Agents make the thought true.

A person working alone eventually reaches biological exhaustion. The machine does not. Ask for ten more and ten more appear. Ask it to criticize the ten and it can. Ask it to synthesize the criticism into a new version and the loop can continue until the human mistakes motion for progress.

The master must therefore know when the sketch phase has done its work.

This is a selection problem before it is a generation problem.

Selection requires a criterion.

The weakest human-agent workflows generate first and invent the criterion afterward. The user asks for ideas, sees something attractive, and decides that attractiveness was what mattered. This is how plausible output trains the goal.

A stronger workflow establishes at least part of the standard before opening the floodgate.

What must this solution preserve?

What tradeoff is acceptable?

What would make a candidate unusable even if it looks good?

Which dimension are we actually exploring?

What evidence will decide among the finalists?

These questions narrow the space enough that variation becomes informative.

This is exactly what sketching is for.

A useful sketch changes one or two uncertain things while holding enough else constant that the artist can learn from the difference. If every candidate changes everything, comparison becomes aesthetic fog.

Agents are superb at creating controlled variation when asked.

Take a product message. Instead of "give me twenty versions," ask for five versions that each change only the assumed customer fear while preserving the factual claim. Now the alternatives expose an uncertainty: which fear is real?

Take a software design. Ask for three architectures under the same load and security assumptions but with different optimization priorities. The differences reveal the cost of each priority.

Take a book chapter. Keep the evidence fixed and create alternate sequences: chronology first, mechanism first, person first. The writer can inspect where attention strengthens or collapses without pretending the agent has written the chapter.

This is the first major principle of the Da Vinci Process:

Variation should expose a decision.

Otherwise it is decoration.

The phrase "Da Vinci Process" is ours, not Leonardo's. I am naming a modern way of working after an older habit: use cheap representations to discover what deserves expensive commitment.

The habit appears everywhere in serious creation.

Architects make models.

Filmmakers storyboard.

Engineers prototype.

Scientists run pilots.

Writers outline, draft, cut, and rearrange.

Musicians rehearse.

Investors paper trade.

Military planners war-game.

The sketch is any representation cheap enough to fail before the real system has to.

Agents dramatically enlarge this pre-commitment space.

A company can simulate customer objections before launch. A lawyer can generate hostile readings of a clause. A security team can ask an agent to search for attack paths. A scientist can test analysis code against synthetic data before touching the real result. A manager can run a proposed policy through several stakeholder perspectives.

This does not make the simulation true.

It makes surprises cheaper.

That distinction is essential because generative systems are especially good at creating coherent worlds. A simulated customer can sound exactly like a customer. A simulated adversary can sound dangerous. A simulated expert can use the vocabulary.

None of those simulations have standing in reality.

They are sketches.

The danger begins when the workshop forgets the material difference between a sketch and the thing.

This is already happening in research and strategy. A model summarizes how customers might react, and the summary quietly substitutes for talking to customers. It predicts objections, and nobody discovers that the real objection is stranger. It produces synthetic data, and a team begins to trust the pattern because the chart looks empirical.

The sketch has crossed the line into evidence.

A master must police that border.

Leonardo could draw a flying machine without proving that it would fly.

The drawing was still useful.

It organized thought. It exposed relationships. It suggested mechanisms. It preserved a question.

The mature user of generative AI needs the same epistemic modesty. A generated scenario can sharpen a question without answering it. A synthetic persona can force a team to notice assumptions without standing in for a human being. A model-generated counterargument can reveal weakness without proving that any real critic would make it.

The sketch should increase the quality of contact with reality.

It should not replace reality.

This makes evaluation the central craft.

Researchers studying human work with advanced language models have repeatedly found that capability is uneven. In the BCG experiment around GPT-4, consultants improved substantially on tasks inside the model's capability frontier and performed worse on a task outside it when they relied on the model. The memorable phrase was the "jagged technological frontier."

A jagged frontier means sketching cannot be delegated blindly.

The machine may generate its most persuasive work precisely where the human is least equipped to detect the failure.

This is a new version of an old workshop problem. A sketch by a talented apprentice can seduce the master.

The better the draft, the sharper the review must become.

One way to solve this is to separate generation from evaluation.

Do not ask the same process to produce, defend, and approve its own answer.

In a human shop this separation may be social. One person drafts, another reviews. In an agentic shop it can be procedural. One agent proposes candidates. Another is asked to attack them with access to different instructions or evidence. A human compares the criticism with the original purpose. Tests arbitrate wherever tests are possible.

This does not magically create independence. Agents can share model blind spots. Two instances of the same model are not two institutions. But procedural separation makes hidden assumptions more visible.

The point is to create disagreement on purpose.

Great workshops contain disagreement.

The romantic image of the master can obscure this because authority seems to flow only downward. In reality, any productive group develops channels through which the work pushes back. The apprentice cannot make the pigment behave differently by obeying harder. The marble has grain. The patron has demands. The deadline arrives. The object itself becomes an argument.

Agents need equivalent resistance.

Tests are one source.

Primary evidence is another.

Independent measurement is another.

A second model can help, but only if we remember that synthetic disagreement is still synthetic.

The strongest critic is often reality.

This leads to the second principle:

Spend cheap intelligence to create candidates. Spend expensive attention to eliminate them.

We have the sequence backward in many organizations. Senior people generate ideas in meetings because idea generation is status work. Junior people evaluate feasibility afterward. The result is an expensive person doing the cheap part and a cheap person discovering the expensive idea cannot survive.

Agents make that arrangement indefensible.

If a machine can generate a hundred plausible strategic options, leadership should not compete with it on volume. Leadership should get better at asking what evidence separates a serious option from an entertaining one.

This is a more demanding use of expertise because selection reveals the selector.

When only one draft exists, criticism can remain vague.

When ten drafts exist, preference has to become a reason.

Why this one?

Why not that one?

What standard are you applying?

What are you trading away?

Taste stops being mystique and begins to show its structure.

This is why abundance can improve humans if the workshop is designed correctly. More candidates create more opportunities to practice discrimination.

A photographer who sees one frame has a memory.

A photographer who shoots a thousand frames and must choose one can develop an eye—provided the choosing is attentive.

The same applies to language, design, code, and strategy.

But quantity alone does not train taste. It can numb it.

Anyone who has clicked through too many generated options knows the sensation. The first five are interesting. By thirty, the differences begin to dissolve. By fifty, the evaluator is choosing to end the experience.

Selection has a cognitive budget.

That budget becomes one of the hidden limits of agentic leverage.

We cannot consume infinite possibility.

The workshop should therefore control branching.

Generate enough alternatives to expose the meaningful uncertainty, then prune.

This resembles search algorithms because it is search, but the human version is messier. Some branches should be kept alive because they feel promising before the reason is articulable. Some should be killed despite high model scores because they violate a constraint the scoring system has not captured.

The master decides when intuition is information and when it is avoidance.

No agent can rescue a person who refuses to know the difference.

A practical workshop might operate in stages.

At the beginning, variation is broad because the problem is still being discovered. Then the field narrows. The agent helps identify dimensions of difference. The human chooses which dimensions matter. Evidence enters. Weak branches die. The remaining candidates receive deeper work. At some point the cost of changing direction rises sharply, and the burden of proof shifts.

Early in the process, change should be easy.

Late in the process, change should have to earn itself.

This is how physical creation already works. Moving a wall in a sketch is trivial. Moving it after concrete is poured is not. Rewriting a paragraph before the chapter is structured is cheap. Rewriting the thesis after the book is typeset is not. Changing an API before release is cheap compared with changing it after customers build on it.

Agent systems can create a dangerous illusion that all changes remain cheap because the digital artifact can always be regenerated.

The surrounding world cannot.

A model can rewrite the policy in seconds. Employees may have already acted on the old one. Code can be refactored quickly. Integrations may have encoded its behavior. A contract can be redrafted. The negotiation history does not rewind.

Commitment creates external state.

A master tracks where the work has crossed from sketch to promise.

This is another place where human responsibility remains important. Machines can track dependencies, but institutions need someone to understand that a revision has social consequences beyond the file.

The person who says "one more version" may be spending someone else's certainty.

That is why the sketch phase needs a closing rule.

Not a rigid number of drafts. A reason to move.

The major uncertainty has been exposed.

The candidate satisfies the known constraints.

The remaining differences are smaller than the cost of delay.

The next information will come only from contact with reality.

At that point, more generation becomes procrastination.

Ship the prototype.

Run the experiment.

Call the customer.

Test the code.

Send the chapter.

Paint.

Leonardo's notebooks can make endless exploration look glorious because history has curated away the hours that did not matter. We see the surviving brilliance and forget that a working life has a finite number of completed objects.

The modern agentic creator faces the inverse problem. The machine removes one finite constraint from exploration.

That makes completion more, not less, a human art.

The best future work will probably contain enormous invisible forests of alternatives. Drafts never shown. Experiments never shipped. Designs killed in review. Counterarguments that strengthened the surviving claim. Agent runs whose only contribution was demonstrating what not to do.

This is healthy.

A masterpiece has always contained discarded work.

The difference is that the discard pile can now become unimaginably large.

There is a reason sketching belongs near the center of the human-agent workshop rather than in a chapter about creativity alone.

A sketch is a risk instrument.

Its job is to move uncertainty earlier.

This is obvious in architecture. The expensive moment to discover that a wall is in the wrong place is after construction begins. A drawing exists partly to make certain classes of mistake cheap.

Software prototypes do the same.

Scientific pilots do the same.

Financial scenario analysis does the same.

The workshop spends a small amount of reality in order to learn before spending a large amount.

Generative systems can lower the price of this risk instrument dramatically.

That changes which uncertainties are worth exploring.

A small company once had to choose which customer segment deserved a serious concept because producing each concept consumed scarce design and engineering time. Now an agent can help create multiple prototypes, draft landing pages, simulate common objections, generate implementation approaches, and construct test data quickly enough that more of the space can be explored before the team commits.

This is not merely faster creativity.

It changes option value.

More options can be carried farther before one has to be selected.

The economic analogy is useful because an option is valuable precisely because it postpones commitment while preserving the right to act.

A sketch is an intellectual option.

Agents create them cheaply.

The danger is that cheap options can become addictive.

If holding another option costs almost nothing, why close it?

Because decisions have carrying costs.

Every live branch consumes attention.

Every alternative creates another comparison.

Every unresolved architecture complicates downstream work.

Every strategic scenario delays coordination.

The price of generating options falls.

The price of carrying them does not fall at the same rate.

This creates an option glut.

The mature workshop needs a pruning discipline.

Kill branches explicitly.

Record why.

Do not let abandoned candidates remain psychologically alive merely because the machine can regenerate them later.

This matters especially in teams. One person may think the decision is settled while another continues exploring because exploration remains so cheap. The group loses a shared sense of commitment.

The workshop should therefore mark transitions.

Exploration.

Selection.

Validation.

Commitment.

These are not rigid phases. Work can move backward when evidence requires it. The labels matter because the burden of proof changes.

During exploration, novelty has low cost.

During validation, claims need evidence.

After commitment, reopening should require new information.

Agents can help enforce this by asking a different question in each state.

Exploration: what plausible alternatives have we not considered?

Selection: what criterion separates them?

Validation: what would make the preferred candidate fail?

Commitment: what evidence is strong enough to justify reopening?

The same intelligence behaves differently because the workshop's state has changed.

This is one reason persistent project context matters. A stateless agent cannot know whether an idea is a fresh sketch or a settled decision unless the user remembers to restate it.

The workshop should know where it is.

There is another subtle benefit to machine-generated sketches: they can make hidden disagreement visible before social status freezes it.

In many meetings, people converge too quickly because producing a concrete alternative is expensive. Someone proposes a plan. The room critiques the plan that exists rather than imagining plans that do not. The first artifact becomes an anchor.

An agent can cheaply instantiate the dissent.

What would this strategy look like if the company optimized for resilience rather than growth?

What if the target customer were the buyer who hates our current product?

What if the architecture assumed a tenfold reduction in budget?

What if the chapter opened with the document rather than the person?

Once the alternative exists, people can argue with an object rather than with the person who first proposed the direction.

This can reduce status friction.

It can also create false equivalence.

The machine can produce a polished artifact for a terrible idea, giving the terrible idea more social weight than it deserves.

Again the sketch needs status.

A generated alternative is not evidence that the alternative is viable.

It is evidence that the alternative can be represented.

That is a much weaker claim.

The distinction becomes important in strategic work because executives are vulnerable to visual coherence. A complete deck creates the feeling that a complete plan exists.

The workshop should sometimes keep early alternatives deliberately ugly.

Low fidelity protects thought.

A rough wireframe invites structural criticism.

A polished interface invites color comments.

A rough argument invites challenge.

A finished paragraph invites editing.

The form of the sketch tells the group what kind of feedback is welcome.

Generative tools make high fidelity so cheap that we may need to choose low fidelity intentionally.

This is counterintuitive.

Why ask the machine for something worse?

Because finish level is a social signal.

The right question is not whether the agent can render beautifully.

It is whether beauty is useful yet.

The same applies to numbers.

A model can generate precise-looking forecasts before the assumptions deserve precision. Two decimal places can appear where the real uncertainty spans a factor of two.

The sketch should carry uncertainty in its form.

Ranges.

Placeholders.

Open questions.

Competing scenarios.

A visible "unknown."

These are marks of intelligence, not incompleteness.

Leonardo's drawings are powerful partly because the exploratory line remains visible. The page does not pretend that every contour has the same status.

Our digital sketches should recover that honesty.

This is especially important as agents become better at multimodal generation. The more realistic the prototype, the easier it becomes for a human observer to mistake representational quality for underlying feasibility.

A photorealistic product does not prove manufacturing.

A convincing interface does not prove the backend.

A simulated scientific result does not prove the measurement.

A persuasive policy scenario does not prove human behavior.

Representation can outrun reality.

The master has to track the gap.

One practical way is to attach a "reality debt" to a sketch.

What part of this candidate exists only because generation made it look easy?

Which external constraint has not been tested?

Which user has not been asked?

Which component has not been built?

Which assumption has no measurement?

The sketch remains useful.

The debt remains visible.

This is better than forbidding high-fidelity generation. The workshop can enjoy the leverage without becoming hypnotized by it.

There is a larger cultural implication.

As generated alternatives become abundant, taste may shift from making to choosing. That does not mean making disappears. It means many people will encounter their own preferences in a field of machine-produced possibility.

This can make taste more explicit.

It can also homogenize it if everyone selects from options generated by similar systems.

The sketch phase should therefore include human-originated moves.

A strange sentence.

A crude drawing.

A hypothesis with no precedent.

A constraint supplied by lived experience.

These can seed regions of the search space the model would not prioritize.

The human does not have to outperform the generator on volume.

The human can perturb the space.

This is another form of mastery.

The master introduces the condition the system would not invent.

Then the workshop explores what follows.

This is how agents can increase originality rather than average it away.

Not by asking the machine to "be creative."

By using human particularity to define a strange commission and machine abundance to explore it seriously.

That relationship has a beautiful asymmetry.

The human may contribute one unlikely constraint.

The agent may contribute a thousand consequences.

The final work belongs to the interaction.

Sketching is where we can see that most clearly because nothing is sacred yet.

The page can still move.

The architecture can still bend.

The thesis can still fail.

This is where intelligence should be cheapest.

Commitment should become expensive only after the workshop has learned enough to deserve it.

Do not measure the workshop by how much it can generate.

Measure it by what it learns before it commits.
