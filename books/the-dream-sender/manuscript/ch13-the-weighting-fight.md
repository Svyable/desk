# The Weighting Fight

A scientific dispute can become very strange when both sides use the same spreadsheet.

Howard’s 2018 reanalysis did not discover a new archive of failed dream experiments. He took the database assembled for the 2017 meta-analysis and asked a different statistical question about how much influence each study should have. The answer changed the apparent size of the anomaly.

This is an important event because it removes one common escape route. Nobody can say the disagreement exists only because one camp counted different studies. At least part of the disagreement is generated by what the same studies mean when weighted differently.

Inverse-variance weighting gives more influence to estimates that are more precise, which usually means larger samples. This is standard meta-analytic practice for a reason. An effect estimate from two hundred observations generally tells us more about a stable population effect than an estimate from eight.

But dream-ESP studies are not identical machines of different sizes. A large home-dream study may differ qualitatively from a small REM-monitored laboratory series. A study using dynamic video targets may not be exchangeable with one using static art prints. A selected high-scoring participant may not represent the same population as anonymous volunteers. If design differences correlate with sample size, precision weighting can partly become design weighting.

This is the defense available to the original meta-analytic approach.

The defense has teeth, but it creates a deeper problem: what exactly is the common effect being estimated?

If every protocol taps the same underlying psi capacity, weighting by precision makes conceptual sense. If protocols evoke different processes, perhaps separate meta-analyses are needed. If we cannot tell, the pooled number is partly a convenience.

The temptation in controversial research is to treat statistical technique as a proxy battle for belief. Proponents prefer the analysis that preserves an anomaly. Skeptics prefer the analysis that shrinks it. This is understandable and scientifically poisonous.

The proper way to decide among models is predictive performance.

Use the competing meta-analytic estimates to forecast a new preregistered study. Before data collection, each model specifies an expected effect distribution. Then run the study. Repeat across sites. A model that repeatedly predicts better earns authority.

That is much stronger than arguing from methodological custom alone.

The sample-size gradient Howard identified is also predictive. If small-study inflation is driving the literature, new large studies should trend toward smaller effects. If the apparent gradient reflects protocol differences and the true phenomenon is stronger under intensive laboratory conditions, then large high-fidelity laboratory studies should recover the larger effect.

Build one.

The cost is the point. A sufficiently large REM laboratory study is expensive. That fact has allowed the field to live with ambiguity because the designs considered most “psi-conducive” are labor-intensive. But a question with century-scale cultural persistence can justify one expensive experiment if the design is capable of collapsing the uncertainty.

There is another approach: distributed smaller laboratories coordinated under one protocol. Instead of a single site running hundreds of nights, twenty sleep labs can each run a manageable number. Site becomes a random effect. Protocol compliance can be audited centrally. Target systems and scoring can be shared without target identity being shared before locks.

This architecture would directly test whether the phenomenon depends on local laboratory culture.

It would also test whether the Maimonides reputation describes tacit competence. If some sites consistently outperform others under identical information controls, investigate why. Maybe sleep quality differs. Maybe report richness differs. Maybe participant recruitment differs. Maybe one site has an ordinary procedural vulnerability. Maybe, if we are being maximally open, an unknown effect is genuinely site-sensitive.

Every possibility produces data.

The weighting fight also forces an uncomfortable admission about effect size. Suppose Howard’s r = .07 estimate survives everything. That is small. It is also not trivial if the endpoint truly measures information from an inaccessible target. Scientific importance depends on what the effect means, not only how large it is.

A tiny reproducible gravitational-wave strain matters because the apparatus and theory establish what is being measured. A tiny psi effect does not receive that privilege because the channel remains undefined and the measurement chain is less secure.

This is why “small but significant” is not enough.

The smaller the effect, the more rigorously we must exclude tiny biases. A slight imbalance in target pools, a subtle judge preference, a modest publication bias, or a few analytic degrees of freedom can produce an effect of similar scale. The extraordinary interpretation is competing with ordinary mechanisms that live in the same decimal place.

One can formalize this as an error budget.

Engineering disciplines ask how much each known source of error contributes to uncertainty. Dream ESP needs the same habit. Estimate the effect size attributable to judge disagreement. Estimate target-pool asymmetry under shuffled data. Estimate laboratory clustering. Estimate publication selection through registered-report simulations. Estimate how much optional exclusion of poor-recall nights can move the result. Estimate randomization imbalance.

Then ask whether the residual anomaly exceeds the combined error budget.

This would move the field away from courtroom rhetoric. Instead of “you have not proven leakage,” the skeptic says, “this known scoring asymmetry can generate r = .03.” Instead of “the effect is significant,” the proponent says, “after locked controls the residual is r = .09 with this uncertainty across five independent sites.”

Now we are talking about the same object.

There is no reason parapsychology cannot operate this way except cost, culture, and history.

The history is particularly important because decades of dispute have trained participants to expect certain argumentative moves. Skeptics demand more controls; proponents add them; the effect shrinks; proponents identify moderators; skeptics call them post hoc; meta-analysts pool; reanalysts reweight. Each move is individually rational. Together they form a machine for producing permanent controversy.

A prospective prediction tournament could break the cycle.

Before the next study, ask leading analysts from both camps to publish code that predicts the distribution of outcomes under the planned protocol. Freeze the code. Run the experiment. Score the forecasts. Repeat.

The question stops being who can explain yesterday’s data.

It becomes who can predict tomorrow’s dreams.
