# Java, 2019

The Java event is where the story stops being archival.

On satellite imagery, the luminous region south of Java had scale, shape and persistence. It emerged in late July 2019 and remained detectable across multiple observing windows into early September. The feature covered an area roughly comparable to Iceland at maximum extent.

That size invites disbelief of the wrong kind. A weak biological light source over 100,000 square kilometres sounds impossible until one remembers that satellites integrate photons across area. The harder question is not whether a dim source can become visible by being huge. It is whether biology can occupy the required state coherently for that long.

The event's persistence helps. A one-night anomaly could be almost anything. A feature that recurs in the same advecting water mass over weeks behaves like a system. It can be compared with currents, temperature, chlorophyll and wind. Its edges can be followed. Its evolution can be reconstructed.

But satellite confidence was still indirect until an accident in human geography supplied the missing link.

A private yacht had sailed through it.
