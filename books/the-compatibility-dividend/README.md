How Standards Turn Strangers Into Systems.

The working thesis is that standards are compressed coordination: shared rules at carefully chosen seams let strangers make complementary decisions without bilateral negotiation. The book follows that compatibility dividend from fire-hose couplings, measurement, machine threads and railroad time through containers, barcodes, electricity, TCP/IP, the Web and Unicode, then into standards governance, lock-in, competition policy and autonomous agents.

The argument is deliberately two-sided. Standards can enlarge markets, portability, resilience and freedom above the interface. They can also freeze weak designs, hide private power inside technical requirements, create common-mode failure and turn an installed base into a quiet sovereign. The design problem is not whether to standardize everything. It is where shared constraints create more freedom than they remove.
