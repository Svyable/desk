# THE WIND WON
## How a Robotic Dragonfly Became an Intelligence Failure

By Sven Hardy Benson

**Status:** active development

**Thesis:** CIA's 1970s Insectothopter is a documented miniature flying intelligence platform whose failure is more revealing than its novelty. The machine reportedly achieved insect-scale powered flight and a laser-guided/data-link concept, but crosswind defeated useful control. This book uses that tiny failure to investigate a larger rule across anomalous aerospace, biomimetic systems, covert sensors, and claims of hidden technology: laboratory capability is not environmental capability. The world gets a vote.

Evidence classes are maintained explicitly in `research/evidence-ledger.md`. Claims about operational use, successor systems, biological equivalence, or modern covert micro-UAV capability require independent evidence and are not inferred from the prototype.
