# The Weight of Voltage

*Townsend Brown, Electrogravitics, and the Force That Would Not Behave*

| | |

A high-voltage asymmetric capacitor really moves in air. Townsend Brown thought the effect reached into gravity. Later electrohydrodynamic theory and vacuum testing point strongly toward charged-particle momentum transfer for the familiar effect. The interesting question is what, if anything, remains after the air and the legend are removed.
