## Thesis

The microwave auditory effect is real. That does not prove a microwave weapon caused the illnesses called Havana syndrome. The scientific and intelligence failure begins when a demonstrated bioeffect is promoted across missing causal links into a device, an attack, an adversary and a global campaign. This book reconstructs each promotion separately.
