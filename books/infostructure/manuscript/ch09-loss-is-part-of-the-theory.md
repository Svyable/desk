# Loss Is Part of the Theory

A serious theory of cumulative culture has to explain subtraction.

Technologies disappear. Languages die. Archives burn. Software becomes unreadable. Skills become uneconomic and then, when conditions change, expensive to recover. The arrow of cultural accumulation is real at large scales and jagged almost everywhere else.

Archaeology makes this impossible to ignore. Researchers have debated demographic and ecological explanations for changes in tool complexity because populations can lose practices without losing the biological capacity to learn them. Cultural inheritance is volatile.

Modern societies are not exempt. We have mistaken cheap digital copying for immortality. A million identical files stored behind one obsolete dependency are not a million independent survivals. Cloud concentration, proprietary formats, link rot, authentication systems and abandoned software create new ways for information to remain physically encoded while functionally disappearing.

Loss can also be rational. Maintaining every technique would consume the society doing the maintaining. Horse-collar expertise declines when tractors dominate. Obsolete programming languages lose practitioners. The problem appears when future option value is large and current maintenance value is small.

This produces a peculiar asymmetry. We can estimate the cost of keeping an archive. We cannot easily price the future discovery that depends on it.

Resilience therefore requires deliberate redundancy across forms. A written description, physical specimen, trained practitioner and executable simulation fail differently. Preservation improves when the copies are not merely copies.

There is another kind of loss: stigma. Ideas can become socially unretrievable before they become evidentially false. Sometimes stigma is a useful immune response to fraud and low-quality work. Sometimes it causes adjacent legitimate questions to be abandoned. The solution is not indiscriminate openness. It is keeping rejection reasons legible so later investigators can distinguish 'tested and failed' from 'associated with people we stopped inviting.'

A civilization that cannot remember why it forgot something has lost twice.
