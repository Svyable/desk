# 6. SAGE Repeats the Trouble

SAGE mattered because repetition is more valuable when it changes the nuisance model.

The experiment sat beneath the Caucasus at Baksan and used metallic gallium rather than the gallium chloride solution of GALLEX. It had different chemistry and operating history. Its 51Cr source test and later 37Ar source run again produced fewer 71Ge atoms than conventional expectation.

The 37Ar run was especially useful because the source isotope changed. If a problem attached specifically to chromium activity determination or line structure, argon should have broken the pattern. It did not simply restore unity.

This did not prove oscillations. It made one class of mundane explanations smaller.

A common nuclear cross section, however, follows both source isotopes because both are detected by the same 71Ga reaction. A common radiochemical bias could also follow both. Repetition across sources therefore rotated the uncertainty rather than eliminating it.

That is a recurring motif in anomaly physics. New experiments do not merely increase N. They reshape the nuisance space. A good replication is one whose errors do not rhyme with the original.
