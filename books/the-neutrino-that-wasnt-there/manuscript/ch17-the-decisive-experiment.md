# 17. The Decisive Experiment

The next experiment should be designed so that cross-section normalization and oscillation cannot impersonate each other.

One route is geometry. Use a sufficiently compact, well-characterized source and a segmented target or detector with spatial resolution fine enough to resolve an L/E wave rather than only an overall deficit. A sterile oscillation predicts position dependence. A uniform cross-section revision does not.

Another route is source energy. Multiple monoenergetic or narrowly distributed neutrino sources probe different combinations of ground- and excited-state nuclear transitions. If the anomaly changes with energy exactly as revised nuclear/electronic calculations predict, that is a fingerprint. If it follows L/E instead, sterile oscillation gains force.

A third route is direct nuclear information. Improve constraints on the relevant 71Ge transition densities with complementary reactions and theory, while testing the electron-wave-function treatment independently. The nuclear calculation should be preregistered against data it did not tune.

And the experiment should publish observables before interpretation: atoms produced per exposure, spatial zone, source line, extraction history. Do not make future theorists reverse-engineer the numerator from an oscillation plot.

The decisive experiment is not the one with the smallest error bar. It is the one in which the leading explanations are geometrically incapable of hiding in the same parameter.
