# The Neutrino That Wasn't There

## Gallium, BEST, and the Calibration Anomaly That Will Not Go Away

By Sven Hardy Benson

### Thesis

A deficit first found while calibrating gallium solar-neutrino detectors has survived GALLEX, SAGE, and BEST, but the most important question in 2026 is no longer simply whether a sterile neutrino exists. It is whether a >5σ anomaly can be generated by the interface between nuclear structure, electron wave functions, radiochemistry, geometry, and oscillation theory while each local piece looks reasonable. The book treats that interface as the experiment.
