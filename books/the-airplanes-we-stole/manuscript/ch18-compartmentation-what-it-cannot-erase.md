# Compartmentation: What It Cannot Erase

A compartment can restrict information. It cannot repeal conservation laws, payroll, fatigue, corrosion, real estate, or organizational succession.

This is the limit that matters most.

If a program studies one inert fragment, the physical burden may be tiny. If it stores several vehicles, runs them, copies components, tests propulsion, and maintains the effort across eighty years, the burden becomes large.

Large burdens create interfaces. Secure facilities need power and maintenance. Specialists need careers. Contractors need tasking. Samples move between laboratories. Security incidents occur. Technical disputes require adjudication. Program managers retire and are replaced. Equipment becomes obsolete. Storage standards change. Scientific instruments are upgraded. Waste is disposed of.

Compartmentation can make each interface look ordinary from the outside. It cannot make the interfaces unnecessary.

This observation gives the retrieval-signature method its strongest prediction: the longer and more successful the alleged program, the more independent lanes should exist even if no single lane reveals the whole mission.

A program that has produced no reproducible technology may remain exceptionally quiet because it does little. A program that has transformed physics while leaving no industrial, scientific, operational, adversary, or archival discontinuity is harder to reconcile.

Secrecy scales badly with success.
