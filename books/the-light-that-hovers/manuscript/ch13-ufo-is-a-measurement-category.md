# UFO Is a Measurement Category

`Unidentified` is not a material.

That sounds trivial until one reads enough UAP argument. Unknown cases slowly acquire shared properties simply because they share a folder. A radar track, a luminous sphere, a metallic-looking object, a pilot's geometric shape, a thermal blob and a satellite flare can become examples of one hidden technology.

Hessdalen makes this mistake visible because the archive is geographically unified. Everything unusual seen over one valley is tempted into one phenomenon.

The better approach is to classify by observables before origin.

Luminous point source. extended glow. structured multiple lights. radar-only target. optical/radar coincidence. transient flash. long-duration stationary source. Each class can then be compared against known sources and physical models.

This removes some romance and adds scientific leverage. A plasma model need not explain a dark radar target. A headlight model need not explain an overhead flash. An aircraft model can be excellent for one class and irrelevant to another.

The same ontology should be applied to military UAP data. `UAP` should remain a workflow status until a stable phenomenological class emerges.

That is not semantic fussiness. It protects causal inference.

If ten unrelated processes are mixed, no average behavior has to correspond to anything real. The mean speed of birds, balloons and sensor artifacts is not the speed of a hidden species.

Hessdalen can teach us how to let a famous category dissolve without losing the interesting cases inside it.
