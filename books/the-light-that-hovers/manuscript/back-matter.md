# Back Matter

## Evidence note

This book distinguishes four classes throughout: documented program history and measurements; credible but incomplete observations or interpretations; disputed claims lacking independent closure; and speculative synthesis. `Unidentified` is not promoted into a physical category.

## Chronology

- **1981–1984** — Reports of unusual luminous phenomena in Hessdalen rise sharply.
- **June 1983** — Project Hessdalen is organized.
- **January 21–February 26, 1984** — First major instrumented field campaign; the technical report records 53 observations classified as Hessdalen phenomena.
- **Late 1980s–1990s** — Activity falls from the early-1980s peak; intermittent observation continues.
- **1998** — Automated monitoring begins with the Hessdalen Automatic Measurement Station / Blue Box lineage.
- **2000–2004** — Norwegian–Italian EMBLA campaigns add optical, radio, radar and spectroscopic work.
- **2004** — Massimo Teodorani publishes a long-term survey arguing that several observations are consistent with an atmospheric luminous phenomenon while no complete model exists.
- **2005 onward** — Critical analyses challenge specific radio and optical interpretations, including anthropogenic-source explanations.
- **2023** — Project Hessdalen becomes a registered nonprofit organization.
- **2026** — Continuous monitoring and public-data efforts remain active.

## What would defeat the book's thesis

The central thesis would need revision if a careful reanalysis showed that all instrumentally interesting Hessdalen events reduce to known traffic, astronomical sources, imaging artifacts or instrument faults with no residual atmospheric class; or, in the opposite direction, if synchronized calibrated observations established a repeatable manufactured object with unambiguous structure, propulsion signatures and independent range.

The methodological thesis would fail if persistent hotspot instrumentation proved unable to discriminate mundane sources despite adequate calibration, geometry and metadata. That would be an important result too.
