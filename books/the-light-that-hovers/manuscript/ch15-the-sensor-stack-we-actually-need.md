# The Sensor Stack We Actually Need

The ideal anomaly observatory is offensively boring.

Three optical stations separated enough for parallax. calibrated visible cameras with raw frames. narrow-field tracking cameras. thermal infrared. low-resolution wide-field spectroscopy plus a steerable higher-resolution spectrometer. passive radar. perhaps a modest active radar with raw data retention. broadband radio receivers. electric-field mills. magnetometers. weather stations. aerosol counters. lightning data. precise GNSS timing. aircraft transponder feeds. satellite ephemerides. road cameras.

Nothing on that list requires secret technology.

The difficulty is integration.

Every sensor must agree on time. A detection in one channel should trigger buffered retention in the others. Calibration states must be recorded automatically. Software should preserve version history. Raw data should remain available so that later analysts can challenge the pipeline.

The event classifier should be built around elimination. Satellite? aircraft? road vehicle? astronomical source? meteor? lightning? insect near camera? lens flare? compression artifact? If a known-source match is strong, keep the event anyway as training data.

The residuals deserve more expensive attention.

Two-station parallax is decisive. If a light is near enough for measurable parallax, distance becomes available. If no parallax is seen within precision, the source is farther away than a calculable bound. This alone would improve most luminous-anomaly cases by an order of magnitude.

Polarization could constrain scattering versus intrinsic emission. Thermal imaging could reveal whether visible brightness corresponds to substantial heat. Spectroscopy could classify emission. Radar could test free-electron or solid-target interpretations.

The point is not to build a machine that proves UAP.

It is to build a machine that makes ignorance smaller in public.
