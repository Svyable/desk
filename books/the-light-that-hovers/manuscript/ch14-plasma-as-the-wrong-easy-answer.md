# Plasma as the Wrong Easy Answer

There is a skeptical failure mode that sounds scientific because it uses a physics noun.

`Probably plasma.`

The phrase can be as lazy as `probably aliens`.

Plasma is real, common and astonishingly varied. The Sun is plasma. lightning channels are plasma. aurora involves plasma processes. fluorescent lamps use weakly ionized gas. industrial reactors sustain non-equilibrium plasmas at room-compatible gas temperatures. The category is too broad to explain a specific hovering light.

A real plasma hypothesis must be narrow enough to fail.

Specify density. electron temperature. gas temperature. composition. size. lifetime. energy source. confinement or replenishment. emission spectrum. expected radio behavior. motion. If the source scatters radar, predict the radar response. If it emits infrared, predict it. If it is cold enough not to convect violently, explain the non-equilibrium state.

This standard matters politically because plasma has often been offered as a catch-all explanation for anomalous aerial phenomena. Some UAP reports probably are atmospheric or propagation effects. But one cannot reduce a tracked object with calibrated range to plasma merely because plasma exists in air.

The same caution runs the other direction. If an atmospheric model struggles, that does not promote a technological hypothesis automatically. Failure of one conventional mechanism is information about that mechanism.

The mature position is slower.

An event can remain unidentified while multiple specific plasma models are rejected.

That is a scientific result.
