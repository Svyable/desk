# Chapter 14 — Return the Rock

There is a persistent fantasy that sufficiently clever remote instruments can make sample return obsolete. Sometimes they can. Cheyava Falls is an example of why they cannot always.

Perseverance carries extraordinary instruments under brutal constraints of mass, power, sterility, reliability and autonomy. Earth laboratories can bring synchrotrons, atom probes, secondary-ion mass spectrometers, ultrahigh-resolution mass spectrometry, electron microscopy, destructive chemistry and techniques that do not yet exist.

A returned sample also allows replication. One laboratory can be wrong without the planet being wrong.

The Sapphire Canyon core is therefore not merely cargo. It preserves optionality. A good sample can outlive the mission that collected it and answer questions invented decades later, as ALH84001 itself demonstrates.

But sample return is expensive, politically fragile and technologically complex. By 2025 the architecture and cost of Mars Sample Return had become uncertain enough that the very rock most capable of resolving a biosignature controversy might remain stored on Mars for years.

This creates a strange mismatch in priorities. Civilization can identify a potentially historic specimen and still fail to retrieve it because institutional time moves differently from scientific time.

The scientific case for return should be stated without melodrama: current in-situ data do not uniquely discriminate biological from abiotic formation. Earth analysis can access classes of measurement that directly bear on that discrimination. Therefore return has unusually high information value.

The question is not whether the sample is 'worth it' because it contains life. We do not know that. It is worth it because it can tell us whether the most interesting life-like chemistry yet seen by Perseverance is life-like for a good reason.
