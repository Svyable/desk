# Chapter 6 — One Cause, Four Clues

Imagine four witnesses enter a courtroom. Each tells the same story. Confidence rises. Then you learn all four copied the same anonymous memo.

That is the problem of correlated biosignatures.

ALH84001 was persuasive because several lines of evidence seemed to converge: carbonates, magnetite, sulfides, organic molecules, morphology. Later abiotic scenarios showed that impact heating, carbonate decomposition and water-rock chemistry could connect several of those observations causally. The evidence did not vanish. Its effective sample size shrank.

Astrobiology rarely writes the effective sample size down.

A useful biosignature framework should therefore include a causal graph. Nodes are observations: organic carbon, mineral species, isotope ratios, textures, crystal defects, redox gradients. Upstream nodes are candidate processes: biology, hydrothermal alteration, impact shock, serpentinization, photochemistry, contamination, instrumental artifact. If several observed nodes descend from one abiotic process, they cannot be treated as independent multipliers of biological odds.

This is not merely Bayesian etiquette. It changes mission design. A rover should seek measurements that cut across causal families. Morphology plus chemistry is better than morphology alone only if mineral growth does not explain both. Isotopic fractionation is better than bulk organic abundance only if the relevant abiotic pathway predicts a distinguishable isotopic range. Chirality is useful only if racemization, meteoritic inheritance and nonbiological asymmetric chemistry are quantified.

Cheyava Falls is a beautiful test case. The Bright Angel mudstones contain organic carbon, sulfur, oxidized iron and phosphorus. The leopard spots include likely vivianite and greigite and appear to record post-depositional redox reactions. A microbial metabolism could couple these ingredients. So could a sufficiently specific abiotic redox history.

The number of observations matters less than the number of independent causal constraints.

This may be the most important lesson ALH84001 offers the current search for life: convergence is not a count. It is a structure.
