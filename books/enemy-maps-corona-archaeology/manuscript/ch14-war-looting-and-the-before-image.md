# War, Looting, and the Before Image

Heritage destruction produces an argument about time. What did the place look like before damage, and how confidently can we say what changed?

Modern commercial satellites are now used to document looting pits, demolition, construction, and other damage to archaeological sites. CORONA can extend the baseline backward, sometimes by decades. It may show a site before modern expansion, before large-scale earthmoving, and before the recent disturbances that dominate present-day imagery.

The temptation is to make the old image perform more than it can. A CORONA frame cannot tell us every event that occurred between its acquisition date and a later image. Nor can it establish motive. It can document visible state. The chronology between observations still has to be built from other images, reports, field records, testimony, and administrative evidence.

That distinction becomes especially important in places affected by political conflict. Archaeological damage can be folded quickly into propaganda, accusation, or sensational reporting. A dated image is valuable precisely because it is stubborn about what it actually shows. It can support a bounded claim: this feature was present then; this area looked different; this disturbance did not yet appear at that spatial scale.

The strongest use of declassified imagery is therefore forensic without pretending to be omniscient. It supplies before conditions. It can reveal older damage that might otherwise be attributed to a recent period. It can show that a supposedly untouched site was already altered decades earlier. It can also prove that features now gone were once visible.

An archive created for one form of state observation has become useful for holding later narratives accountable to dates. That is not absolution for surveillance. It is a second life for evidence.
