# What Would Count

The field does not need one more extraordinary case.

It needs a boring system that can be left alone.

Imagine a global precursor experiment designed by people who disagree about whether the effect exists. The network ingests ground electric fields, magnetometers, radon where available, GNSS total electron content, ionosonde data, weather, lightning, space-weather indices and satellite plasma measurements. The earthquake catalog is hidden from the real-time classifier until each forecast window closes.

The algorithm issues a probability surface every day.

No human gets to circle the interesting anomaly after the earthquake.

The forecast contains location cells, magnitude thresholds and time windows. Every cell every day receives a score. False alarms remain in the permanent record. Sensor outages remain. Solar storms remain. If the system abstains during disturbed geomagnetic conditions, abstention is scored as part of availability.

Now make the experiment adversarial.

One team builds the best seismo-electromagnetic model. Another builds null models from space weather, meteorology, instrument state and ordinary seismicity. A third team controls data integrity. The statistical analysis is preregistered. Code is archived. Thresholds are frozen for a test period measured in years, not weeks.

The primary endpoint is not a p-value around earthquakes.

It is incremental forecasting skill above established seismic hazard and clustering models.

That comparison is essential. Earthquakes already cluster in time and space. Aftershocks are predictable probabilistically because one earthquake changes the chance of another. Fault zones have known long-term hazard. A fancy electromagnetic system that merely rediscovers where earthquakes usually happen adds nothing.

The experiment should therefore ask whether electromagnetic variables improve out-of-sample forecasts after conventional seismological information is included.

This is a much harsher standard than demonstrating correlation.

It is also the only standard that matters if the goal is warning.

Mechanism work can proceed separately. Laboratory groups can test stress-activated current, electrokinetics and fracture electrification under specified lithologies and fluid conditions. Atmospheric physicists can test whether plausible surface currents can perturb the lower atmosphere enough to influence the ionosphere. Satellite teams can test spatial geometry.

The point is to prevent one weak link from borrowing certainty from another.

If the field survives this experiment, it changes category.

If it fails, the failure will still tell us which couplings were real but operationally useless.

That is what would count.
