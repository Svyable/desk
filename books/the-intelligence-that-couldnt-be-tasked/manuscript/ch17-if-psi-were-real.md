# If Psi Were Real

The cleanest way to take remote viewing seriously is to design an experiment that would be inconvenient for everyone.

Not a demonstration. Not a conference performance. Not another retrospective scoring fight over files from 1984.

A prospective trial.

The first requirement would be adversarial authorship. The protocol should be built by researchers who think anomalous cognition is plausible, researchers who think the historical effect is probably artifact, statisticians, information-security specialists and people who have actually operated intelligence collection systems. No faction gets to own the loopholes.

The second requirement would be to separate the scientific and operational questions from the beginning.

The scientific arm asks whether target-specific information appears under conditions that exclude known information channels. The operational arm asks whether that information can improve decisions before feedback. A positive scientific result does not automatically pass the operational arm, and an operational failure does not erase a laboratory anomaly.

Target generation would be cryptographically committed before each session. The entire target pool would be frozen and published after data collection. Randomization code would be open to audit. Every session would receive a timestamped record before anyone with target knowledge could inspect the response. Exclusions, stopping rules and primary analyses would be preregistered.

The viewers would not be selected after a lucky run.

If proponents believe experienced practitioners outperform novices, the study should include a prospectively identified expert cohort and a comparison cohort. If they believe training helps, training should be tested separately rather than inferred from cross-sectional differences. Dropouts remain in the denominator.

The interviewer, if one is used, should be blind not merely to the specific target but to target class whenever practical. Transcripts should be preserved in complete form. No one who knows the target should edit them before judging.

Judging deserves its own firewall.

Multiple independent judges would rank responses against candidate targets using a scoring method fixed in advance. The study would include an automated similarity analysis only as a secondary measure, because an opaque language model should not become the new psychic judge. Human and machine scoring could be compared, but neither should be tuned on the test set.

Then comes the important part: replication would be simultaneous.

Several laboratories would run the same protocol without sharing interim results. At least one would have no historical relationship with the principal remote-viewing research community. The analysis code would be locked before unblinding. Results from every site would be released whether positive, null or embarrassing.

This would answer only the constrained scientific question.

The operational test would be harsher.

Create a simulated intelligence environment in which analysts must choose among costly actions. They might allocate a limited set of reconnaissance resources across hidden locations. Conventional data would be incomplete. In some trials, analysts receive remote-viewing reports; in matched trials, they do not. In other trials they receive control reports generated from the same descriptive base rates but unrelated to the target.

The analysts would not know which condition they are in.

The endpoint would not be “how accurate did the report look?” It would be mission score: targets found, false leads pursued, resources consumed, time to correct decision, confidence calibration and outcomes relative to the no-remote-viewing baseline.

Now the phenomenon has somewhere to fail honestly.

If viewers produce above-chance target matches but analysts gain no advantage, we have recreated the STAR GATE paradox under modern controls. The scientific anomaly remains interesting; the capability claim fails.

If analysts improve only when reports are scored retrospectively, the prospective-recognizability problem remains.

If expert viewers outperform novices but the effect vanishes in independent laboratories, social or methodological inheritance becomes a leading explanation.

If the effect survives independent sites, fixed scoring and secure target generation, the skeptical burden changes substantially.

And if the operational arm shows reproducible decision advantage after false leads and verification costs are counted, then intelligence agencies would have a reason to revisit the subject regardless of whether anyone can explain the mechanism yet.

This is what a real reopening would require.

Not another declassified file.

Not another witness saying the program succeeded.

Not a patent. Not a security clearance. Not a story about what the Soviets supposedly achieved. Not a meta-analysis assembled from the same historical literature.

A result that predicts its own future.

The test should also attack the most provocative claimed boundary conditions. If distance is irrelevant, randomize target distance over orders of magnitude. If electromagnetic shielding is irrelevant, specify shielding conditions prospectively. If temporal displacement is claimed, preregister trials in which the target is randomly selected after the response has been irreversibly committed.

Those experiments would be scientifically extraordinary because they would discriminate among classes of explanation.

They would also be easy to misuse.

A failed shielding interaction does not prove nonlocal consciousness. A successful presentiment-style protocol would not establish that information traveled backward in time. The experiment would establish the statistical structure it was designed to test. Mechanism would remain another layer.

The same discipline should govern negative results.

One failed replication would not erase every prior study. It would update the evidence. Multiple high-powered preregistered failures across independent laboratories would update it more. If proponents respond by narrowing the phenomenon to special experimenters, special emotional states, special targets or special historical conditions, those moderators need their own prospective tests.

A phenomenon that survives only by acquiring a new exception after each failure is ceasing to be a phenomenon we can use.

There should also be an explicit defeat condition for the book's thesis.

The thesis is that the historical record is compatible with, but does not establish, a weak anomalous signal whose operational conversion failed. That synthesis should be abandoned if a careful reconstruction shows that the positive laboratory evidence is fully accounted for by identifiable artifacts, selective reporting or dependencies; or, in the opposite direction, if a modern independent program demonstrates calibrated, prospectively recognizable remote-viewing information with reproducible decision value.

Either result would be progress.

The worst outcome is the one the subject has occupied for decades: enough anomaly to sustain belief, enough ambiguity to sustain disbelief, and no shared experiment capable of making either side lose something.

Remote viewing deserves a better failure mode.

If psi is real, it should be allowed to become boring.

It should acquire error bars, operating conditions, calibration curves, negative results and ugly engineering compromises. It should stop needing famous anecdotes because a technician can reproduce it on Wednesday.

If it cannot survive that transition, the inability is part of the evidence.

The government spent twenty years trying, imperfectly, to make the extraordinary bureaucratic.

A modern test should finish the job.
