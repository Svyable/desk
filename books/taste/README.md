# Taste

| | |
|---|---|
| **Author**    | Sven Hardy Benson |
| **Status**    | Complete draft |
| **Chapters**  | 20 of 20 drafted |

The central thesis is that generative AI has collapsed the cost of producing content, art, and goods, which leaves human curatorial judgment as the only scarce resource left standing, and that taste itself is a trainable, fallible, socially shaped human faculty rather than a synonym for either elitism or mere preference.
