# MAKE A BELT

**Subtitle:** How America Secretly Changed the Space Around Earth

**Author:** Sven Hardy Benson

## Reader promise

A history of Operation ARGUS and the larger problem it makes measurable: what happens when a classified program changes a physical environment that nobody's security clearance can contain?

The book uses a documented extraordinary experiment as a control rather than beginning with an allegation. From ARGUS it moves through STARFISH PRIME, Soviet high-altitude tests, weather modification, ionospheric heating, directed energy and modern hidden-technology claims, forcing each case to pay a quantitative `detection debt`.
