# The Anti-Atom in the Sky

## Antihelium, Antistars, and the Matter Universe's Missing Half

**Sven Hardy Benson**

### Thesis

The most consequential cosmic-ray result of the next few years may not be a new elementary particle at all. It may be a small composite nucleus moving the wrong way through a magnetic field. Several antihelium-like events have been discussed publicly from AMS-02, while a June 2026 doctoral analysis using multiple machine-learning selections found as many as twelve candidates but only a 1–2 sigma excess above its modeled background. At the same time GAPS has completed its first 25-day Antarctic science flight with an orthogonal antinucleus-identification method. If a robust cosmic antihelium population appears, physicists will have to distinguish among badly underestimated secondary production, dark-matter annihilation or decay, exotic high-multiplicity events, primordial antimatter domains, or nearby antistars. If it does not, the episode will still be a case study in how frontier physics should handle candidate events that escape peer-reviewed confirmation for years.

The book is not an argument that antistars exist. It is an argument that antihelium is an unusually discriminating messenger because producing a bound anti-nucleus is much harder than producing an antiproton, and because the proposed explanations make different predictions across energy, isotope, direction, accompanying antiprotons, gamma rays, and detector architecture.
