# 10. Atoms Fall Differently Only If They Do

An atom interferometer measures acceleration by turning a single atom cloud into a phase comparison.

Laser pulses split and redirect matter waves. The two paths accumulate phase differently. Recombine them and the interference pattern carries information about acceleration.

This makes atoms useful fifth-force probes for an almost embarrassing reason: they are small test masses whose quantum state can be controlled better than the position of a macroscopic torsion pendulum.

In 2015, two atom-interferometry experiments reported strong new constraints on chameleon models. One used freely falling cesium atoms near a source mass in an ultrahigh-vacuum chamber. The setup exploited a regime in which the chamber could support a chameleon field while the atoms remained unscreened.

The result was null.

That null cut deeply into parameter space that had survived macroscopic tests. It also demonstrated the central proposition of this book experimentally: changing the nature and scale of the test body changes what screening models can hide.

A skeptic should notice the asymmetry. If the atom experiment had found an extra acceleration, the chameleon interpretation would still have had to beat electrostatic fields, magnetic gradients, optical forces, wavefront systematics, source-mass gravity, and analysis bias. A null does not need to identify all alternatives because there is no anomaly to explain; it needs only a valid sensitivity calculation.

This is why the frontier advances mostly by exclusion. New probes attack old hiding places.

The next step was to make the source mass itself small enough and close enough that ordinary gravity could be measured in nearly the same geometry.
