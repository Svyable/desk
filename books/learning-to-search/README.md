# Learning To Search

*Optimizing Agentic Discovery*

A model can know a great deal and still look in the wrong place.

That is the problem at the center of *Learning To Search*. Agentic systems do not merely produce answers. They choose queries, tools, files, experiments, branches, witnesses, measurements, and stopping points. Every one of those choices changes what evidence becomes available next.

The working thesis is that the next large capability gain in agents will come partly from treating **search itself as a learned policy**. The important question is not only whether a model can reason over evidence already in context, but whether an agent can decide which evidence is worth acquiring, what it costs, how one observation should change the next action, and when further search is no longer worth the delay.

The book develops that idea from sequential experimental design, controlled sensing, active hypothesis testing, adaptive submodularity, search trees, tool-using language agents, software agents, web agents, and automated scientific discovery. It also establishes a deliberately boring baseline: when search actions have fixed independent discovery hazards and failures teach nothing, adaptivity cannot beat repeatedly taking the best cost-adjusted action. Interesting agents begin where that baseline breaks.

This book is narrower than *Search Frontier*. That book asks how people, firms, institutions, markets, and civilizations explore possibility spaces. *Learning To Search* asks how an **agent** should acquire evidence under partial observability, limited budgets, changing beliefs, tool constraints, verification costs, and environments that may react to the search itself.

The commercial promise is practical and technical at once: a reader should finish able to look at an agent and ask not only whether its model is intelligent, but whether its **search policy** is.
