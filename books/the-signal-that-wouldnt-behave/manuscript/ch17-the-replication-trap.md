# 17 — The Replication Trap

Remote viewing sits in an awkward place in the history of replication because it was forced to confront methodological suspicion long before mainstream psychology made replication anxiety fashionable.

That does not mean parapsychology solved the problem. It means the field provides an unusually concentrated version of it.

A fragile effect creates a trap for both sides. Proponents say replication requires expertise, selected participants, careful targets, particular feedback conditions and a laboratory culture sensitive to the phenomenon. Skeptics hear an expanding set of escape clauses. Skeptics design a simpler test, obtain null results, and declare the phenomenon dead. Proponents reply that the test removed the necessary conditions. Both sides can continue indefinitely unless the necessary conditions are specified before the replication begins.

This is why preregistration matters.

It is not paperwork worship. It is a way to move interpretation forward in time. Before data exist, investigators specify recruitment, exclusions, target selection, scoring, primary outcomes and analysis. A skeptical lab and a proponent lab can negotiate the design together. If the effect depends on expert viewers, define expert prospectively. If feedback matters, specify it. If target entropy matters, quantify it. If geomagnetic conditions matter, say which measure and threshold. Then freeze the plan.

The older remote-viewing literature rarely enjoyed this infrastructure. It relied on conventional publication, laboratory notebooks, government reports and later meta-analysis. That leaves room for arguments about unpublished nulls, analytic flexibility and changing protocols.

Meta-analysis can help and mislead.

Pooling many experiments increases precision. But if the underlying studies share biases, the pooled estimate can become a very precise estimate of the bias. Publication selection matters. Small-study effects matter. Researcher allegiance matters. Nonindependence matters. In a field with a small network of investigators, nominal study count can exaggerate effective evidentiary independence.

On the other hand, invoking publication bias as a magic eraser is not enough. A skeptic should quantify how severe the missing-study process would have to be to generate the observed pattern. If later experiments were commissioned, archived and not selected through ordinary journals, some familiar publication mechanisms may be weaker. Government archives can preserve failures that academic literature loses.

This is why the STAR GATE collection remains scientifically interesting. It is not a clean dataset, but it contains negative session evaluations alongside positive material. The archive weakens the cartoon that only spectacular hits survived.

The better modern test would ignore most of the historical argument and start fresh.

Recruit multiple laboratories, including committed skeptics and experienced remote-viewing researchers. Use a centrally generated target pool whose content is cryptographically committed before sessions. Conceal target mappings from all local experimenters. Timestamp every response. Automate judging where possible, but preserve human scoring as a separately preregistered outcome. Publish every trial. Use independent statisticians who do not know laboratory identity until analysis is complete.

Most importantly, define the engineering outcome alongside the statistical one.

Can a blinded evaluator use the output to choose the correct target from a large set? Can confidence predict accuracy? Can performance replicate across sites? Can a viewer's calibration survive six months? Can novel target properties be recovered prospectively rather than matched afterward?

A field that passes only the first test has an anomaly.

A field that passes the full set has the beginning of a technology.

Remote viewing has spent half a century mostly arguing about the first.

The replication trap persists because a small positive effect is enough to prevent closure but not enough to force consensus. Skeptics can always suspect a hidden artifact. Proponents can always point to the residual. Mechanism-free effects have few independent axes on which to break the tie.

The way out is not another retrospective meta-analysis.

It is an experiment designed so that the losing side helped write the rules.
