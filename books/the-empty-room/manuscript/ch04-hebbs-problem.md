# Hebb's Problem

Donald Hebb is remembered for a phrase about neurons that fire together, but the deprivation work asks a less slogan-friendly question: how much patterned world does a functioning mind need?

A person performing a vigilance task does not fail only because the signal is faint. The operator's state changes while waiting. Time itself becomes part of the apparatus. A display that rarely changes asks the nervous system to remain ready for an event while supplying almost no events capable of sustaining readiness.

This is why radar appears in the same historical paragraph as brainwashing. The military problem was not exclusively how to break a person. It was how to keep a person from drifting when nothing happened for hours and then something mattered for seconds.

The engineering answer is not heroic discipline. It includes shift design, feedback, stimulation, automation, task rotation, sleep, and interfaces that acknowledge biological attention instead of treating it as a defective relay.
