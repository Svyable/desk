# Navigation Without a Map

Homing pigeons do something intelligence engineers wanted long before small autonomous aircraft were practical: leave an unfamiliar release point and return to a known home. The temptation is to describe that as a navigation algorithm. It is safer to call it a biological competence whose mechanisms are plural, context-dependent, and still scientifically interesting.

A handler can exploit the output without possessing the source code. That is the essential asymmetry. Human engineering normally proceeds from mechanism toward function. Biological exploitation can proceed backward: first notice that the organism reliably does something, then build a mission around it while understanding only part of how it succeeds.

This creates a peculiar kind of technical debt. If the animal fails, diagnosis is difficult. Was the cue environment wrong? Was training weak? Was motivation displaced? Did weather matter? Did the animal choose a route invisible to the planner's model?

The pigeon program turned this into an operational problem. Getting home was not equivalent to passing over a coordinate. A competence can be genuine and still be unusable under the constraints that made it attractive.
