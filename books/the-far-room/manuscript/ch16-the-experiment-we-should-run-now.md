# The Experiment We Should Run Now

The decisive remote-viewing experiment should be boring enough to disappoint television.

No celebrity viewers. No haunted military bases. No secret coordinates. No after-the-fact judging session with everyone leaning over the drawings.

The experiment should begin with a public protocol negotiated by researchers who expect different outcomes.

Recruit several independent laboratories. At least one should have experienced psi researchers. At least one should be led by methodological skeptics. A third should specialize in behavioral experimentation or statistics without a strong public identity on parapsychology. All sites use the same software and target library but never share session information before database lock.

Participant recruitment should have two strata. One is a general population sample. The other contains people who claim or have previously demonstrated remote-viewing ability. The talented group must qualify on a preregistered screening dataset and then be tested on entirely new trials. This prevents selecting lucky performers and counting the selection data as confirmation.

The strongest design would generate the target only after the participant response is irreversibly committed.

A participant sits alone with an interface and produces drawings and descriptions. When the session ends, the system hashes and timestamps the response into a public append-only record or trusted independent repository. Only then does a cryptographically verifiable random process select the target from a large curated pool.

This turns an ordinary leakage explanation into a very specific claim about compromised randomization, file tampering, or protocol failure. The target did not exist as the selected target when the response was written.

The metaphysical claim becomes stranger—precognition rather than remote perception—but the information-security problem becomes cleaner.

Judging should use multiple methods fixed in advance. One primary outcome might be blind rank-order matching among five candidate targets. Secondary outcomes could include machine-coded semantic similarity, independent human feature coding, and participant confidence. The target pool must be designed to avoid obvious category imbalances and made available for external audit.

All raw responses remain public after target revelation.

Misses should be as easy to browse as hits.

Trial count should be set by power analysis based on a conservative effect size substantially smaller than those claimed in favorable meta-analyses. The study should be large enough that a null result meaningfully constrains those claims rather than generating another ambiguous small sample.

The analysis code should be executable by anyone. Every exclusion should be logged. No session disappears because the participant felt off. If proponents believe certain states predict success, those states can be measured prospectively and analyzed as preregistered moderators.

The key feature is a belief-updating contract.

Before data collection, prominent proponents should state what result would make them reduce confidence in a robust remote-viewing effect. Prominent skeptics should state what result would make them increase confidence. Those thresholds should not be rhetorical. They should be numbers attached to agreed analyses.

Science rarely does this because human beings dislike binding their future selves.

Anomalous science needs it precisely because the debates are old enough to have grooves.

If multiple independent laboratories reproduce a preregistered above-chance effect under post-response target selection, with no data-integrity failure and with performance stable across replication waves, the result should be treated as a major scientific anomaly. Not proof of spirits, quantum consciousness, nonlocal mind, or any other mechanism. Evidence of information appearing where ordinary models say it should not.

If the effect collapses toward chance, especially among prospectively selected high performers, proponents should not rescue it by inventing new moderators after the fact. They can propose a new theory, but it must face new data.

A second phase would test operational value. Analysts receive real versus sham remote-viewing products in blinded decision tasks with known later outcomes. The measure is not resemblance. It is decision improvement.

This two-stage architecture finally separates the questions STAR GATE blurred.

Does an anomalous information effect exist under controlled conditions?

Can it improve decisions in an open world?

One can be yes while the other is no.

The experiment is affordable. The software is ordinary. The statistical methods are ordinary. The target images are ordinary. The only extraordinary thing is the claim.

That is exactly how it should be.
