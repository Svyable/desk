# A Signal Too Small for a War

Statistical significance is one of those phrases that changes meaning when it crosses a hallway.

In a laboratory, a small but repeatable effect can be important. If a protocol reliably produces performance a few percentage points above chance, the result may force a serious methodological argument. Tiny effects have transformed medicine and physics when measured over enough observations with tight controls.

An intelligence officer has a different problem.

Suppose remote viewing produces a genuine weak effect. Not a cinematic image arriving intact, but a subtle bias in descriptive information: slightly more correct spatial features than chance, slightly better target ranking, a small improvement in identifying salient geometry. That would be scientifically enormous. It could still be almost useless for deciding whether to raid a building.

Wars are not meta-analyses.

Operational intelligence has asymmetric costs. A false negative may leave a threat unaddressed. A false positive may redirect aircraft, expose sources, waste surveillance assets, or put people into the wrong compound. The value of a sensor depends not only on average accuracy but on calibration, specificity, latency, independence, and how its output interacts with other sources.

Remote viewing is especially difficult because free-response output is high-dimensional. A viewer can be correct about three features and wrong about seven. Which ones should the analyst trust? If the analyst already knows which details matter, the viewing may contribute little. If the analyst does not know, the false details can be more damaging than the true ones are helpful.

This is why operational anecdotes are so seductive. A story can select the useful fragment after reality arrives.

Imagine a session that produces twenty descriptors. Two later prove strikingly correct. The human memory system stores the two. The report itself, if preserved, stores all twenty. The story improves every time it is told because the useless material drops away while the correspondence remains.

The declassified archive sometimes lets us reverse that process. We can see raw transcripts, drawings, summaries, target cues, and later comments. The material is often messier than the anecdote. This does not mean every celebrated case dissolves. It means the unit of evidence should be the full session, not the remembered sentence.

The 1995 operational evaluation is crucial here. A summary report states that from 1986 through the first quarter of fiscal 1995 the program received more than 200 tasks from operational military organizations. In 1994 the STAR GATE office created a numerical method for customer evaluation; by May 1, 1995, three viewers had responded to forty tasks from five organizations, yielding scores for accuracy and value.

The existence of this scoring effort is important. It shows the program itself recognized that vivid examples were insufficient. A collection discipline needs customer utility.

The reported evaluations did not establish the kind of dependable actionable performance that would justify treating remote viewing as a stand-alone intelligence source. That conclusion is often experienced by enthusiasts as unfair because some sessions may have contained correct information. But a source can occasionally be correct and still be a poor collection system.

Human informants can also be unreliable, yet intelligence agencies use them. The difference is that human-source reporting comes with models of access and motivation. If a source works in a missile factory, the analyst can estimate what the source could know. Remote viewing lacks that access model. A correct statement cannot be easily distinguished from luck; an incorrect statement cannot be diagnosed by asking whether the viewer lacked access.

This makes calibration unusually hard.

A weak anomalous effect would therefore require a different operational design than the program often seemed to imagine. It should not be used to generate open-ended narratives. It should be converted into constrained discriminations where possible: among pre-specified alternatives, with confidence recorded before feedback and enough repeated trials to estimate each viewer's calibration.

Even then, the contribution should be fused with other intelligence only in ways that preserve source independence. If analysts use conventional information to shape the task, and then treat the remote-viewing result as independent confirmation of the same conventional information, the system counts the evidence twice.

The paradox is sharp.

If remote viewing is real but weak, scientific proof may arrive long before strategic usefulness. If it is strategically useful only when saturated with contextual cues, scientific proof may become harder.

The signal can be too small for a war and still be large enough to matter to science.

STAR GATE was never good at keeping those thresholds separate.
