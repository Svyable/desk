# Chapter 10 — AARO's Residual

The public argument often behaves as if every unresolved case belongs to one class.

It does not.

AARO's public statistics make that impossible to sustain. Its closed-case table is dominated by balloons and satellites, followed by UAS, birds, aircraft and smaller categories. Natural atmospherics occupy only a small fraction of resolved cases. At the same time, hundreds of cases remain in active archive because the data are insufficient for analysis. The current reporting-trends page is at https://www.aaro.mil/UAP-Cases/UAP-Reporting-Trends/ .

The unresolved set is therefore not a species.

It is a filing status.

This distinction is constantly lost. "Unresolved" gets promoted to "anomalous," then to "advanced," then to "non-human" without any new measurement entering the chain.

The opposite error occurs when a high proportion of resolved cases are prosaic and analysts infer that all remaining cases must be prosaic too.

Neither inference is valid.

Resolution has selection effects. Cases with enough information to match a satellite pass are easier to close. Cases with poor timing, no range and compressed imagery are harder. The residual pool may therefore be enriched for genuinely strange events, unusually poor data, or both.

AARO's 2024 report states that more than 900 reports lacked sufficient scientific data for analysis and were retained in active archive. That is a staggering number of non-results.

The problem is not simply secrecy.

It is collection design.

A report built after the event often lacks exactly the variables needed to adjudicate mechanism: precise geometry, raw sensor output, calibration, weather, ephemerides, independent views, spectrum, range.

The scientific answer is not better storytelling.

It is prospective capture.

AARO's public case releases increasingly demonstrate this discipline in miniature. Some cases are resolved. Some remain unresolved because the physical object is evident but attribution is not. Others cannot even establish whether a thermal contrast represents an object or a sensor effect.

That hierarchy should be formalized.

Level zero: insufficient evidence that a physical external event occurred.

Level one: physical event established, class unknown.

Level two: class constrained, attribution unknown.

Level three: known category, specific identity unknown.

Level four: specific identification.

Only then should performance claims be layered on top.

A bright point with no range cannot have a measured acceleration.

A track with no independent confirmation cannot establish transmedium behavior.

An unresolved physical object is not an unresolved civilization.

The residual deserves serious science because it is residual.

It does not deserve a mythology surcharge.
