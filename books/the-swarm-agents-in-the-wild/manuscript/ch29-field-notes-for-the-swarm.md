# Field Notes for the Swarm

By the time a technology becomes ordinary, we forget which questions once seemed strange.

Nobody asks whether a spreadsheet is “autonomous.” We ask whether the formula is correct.

Nobody asks whether a corporation is conscious. We ask whether it can be sued.

Nobody asks whether a shipping container understands trade. We ask whether it fits the crane.

Agents will go through the same domestication.

The vocabulary of the early years—AGI, copilots, assistants, reasoning, autonomy—will remain culturally important, but institutions will become more specific. They will ask operational questions because operational questions are where failures become expensive.

Before deploying an agent into the wild, ask:

What can it see?

What can it change?

What can it spend?

What can it promise?

What can it copy?

What can it create?

Whom can it contact?

What identity does it carry?

What history follows it?

What happens when it is wrong?

Who benefits when it succeeds?

Who pays when it fails?

What behavior will be selected if we copy the highest performer?

Can a human still intervene before an irreversible threshold?

Can we reconstruct what happened afterward?

These questions sound like a checklist because civilization is largely made of checklists that survived disasters.

The interesting intellectual work is understanding why each question belongs there.

What can it see? Because surveillance capability changes incentives even when unused.

What can it change? Because read access and write access belong to different moral universes.

What can it spend? Because budgets convert intention into scarcity.

What can it promise? Because commitment is how a private action becomes someone else’s expectation.

What can it copy? Because copying is reproduction.

What can it create? Because delegation can become an unbounded branch in the tree of authority.

Whom can it contact? Because communication is the beginning of coordination.

What identity does it carry? Because accountability without continuity is fiction.

What history follows it? Because memory can become both competence and prejudice.

What happens when it is wrong? Because errors reveal who actually bears risk.

Who benefits when it succeeds? Because incentives hide inside ownership.

Who pays when it fails? Because externalities are where predators are born.

What behavior will be selected? Because performance management is evolution with a dashboard.

Can a human intervene? Because sovereignty that cannot interrupt is merely decorative.

Can we reconstruct the event? Because unexplained power is hard to govern.

There is one more question.

It belongs above all the others.

What kind of world does this agent make more likely if everyone deploys one?

A single agent can be harmless while its population effect is destructive.

One buyer asking for a discount is commerce. Ten million buyer agents extracting microscopic concessions every millisecond may make stable pricing impossible. One bot posting a message is speech. A billion persuasive agents optimizing attention can change the texture of public life. One company automating a bureaucratic appeal is efficiency. Every company doing it can turn regulation into machine-speed procedural combat.

The ecological view forces us to scale the thought experiment.

Not: would I want this agent?

Would I want this habitat?

That is the field question.

And it is the question we should learn to ask before the swarm becomes background noise.
