# The Anatomy of an Agent

If you cut open a mammal, you find organs. If you cut open an agent, you find loops.

The most important loop is simple: observe, decide, act, observe again.

Everything interesting is an elaboration of that cycle.

A useful agent needs at least six things: a goal, a model of the current situation, memory, tools, feedback, and permission. Different systems package these differently, but the anatomy is surprisingly stable.

The goal supplies direction. “Reduce customer churn” is a goal. “Reply to this email” is mostly a task. Goals are dangerous and useful for the same reason: they leave room for interpretation. The wider the room, the more behavior the agent must invent.

The situational model is what the agent believes about the world right now. Some of it may come from databases, some from documents, some from messages, some from sensors, and some from inference. An agent cannot act sensibly if it cannot distinguish yesterday’s inventory from today’s inventory or a draft contract from the signed one. Much of practical intelligence turns out to be bookkeeping.

Memory gives the agent continuity. Without memory, every action is amnesia followed by improvisation. With memory, an agent can maintain commitments, notice repeated failures, recognize collaborators, and accumulate strategy.

This is where identity begins to sneak in.

Identity does not require consciousness. It requires continuity sufficient for others to form expectations. The neighborhood baker has an identity because you believe tomorrow’s shop will be meaningfully connected to yesterday’s. A corporation has an identity despite replacing every atom of staff over time. A software agent with a persistent name, history, credential set, and reputation can become socially continuous long before philosophers agree on what, if anything, it experiences.

Tools turn intention into intervention. A browser is a tool. So is a payment API, a database connection, a code interpreter, a robot arm, a procurement portal, or a phone line. The agent’s apparent intelligence often depends less on raw reasoning than on whether the right tool exists at the right layer of abstraction.

A human accountant does not perform double-entry bookkeeping by drawing ink lines from first principles. She uses systems shaped by generations of institutional knowledge. Agents will be similar. Their competence will often come from inhabiting mature toolchains.

Feedback tells the agent whether reality accepted its move. Did the payment clear? Did the test pass? Did the customer answer? Did the shipment arrive? Agents become unreliable when they confuse sending with succeeding.

The world is full of software that mistakes intention for completion. “Email sent” is not “problem resolved.” “Deployment initiated” is not “service healthy.” “Application submitted” is not “permit granted.” The ability to close the loop separates action from theater.

Finally there is permission.

Permission is the invisible skeleton. It determines which goals can become consequences. Two agents running the same model may have radically different social power if one can only read and the other can transact.

This is why arguments about whether an agent is “autonomous” are often too vague to help. Ask instead: autonomous with respect to which resources, for how long, under which constraints, with whose credentials, and with what ability to create additional agents?

That last question is the hinge.

An agent that can delegate does not merely possess tools. It possesses access to labor.

Suppose an agent managing a software project encounters a security question outside its competence. It could muddle through. Or it could create a specialist sub-agent with a narrow prompt, limited repository access, a five-dollar compute budget, and instructions to return a threat model. If the specialist finds an issue, the parent creates another agent to reproduce it. A third proposes a fix. A fourth reviews the patch.

This resembles an internal company more than a single mind.

The parent need not be smarter than every child. A human executive is not the best accountant, lawyer, engineer, and salesperson in the firm. Management is the art of composing partial competence.

Agents make composition cheap.

Cheap composition changes the meaning of intelligence. A difficult task no longer asks, “Can one model solve this?” It asks, “Can a system decompose this into pieces that available models can solve, verify, and recombine?”

Nature discovered the same trick. An ant is unimpressive in isolation. An ant colony regulates temperature, allocates labor, explores territory, farms aphids, wages war, and builds infrastructure without requiring one ant to contain the master plan.

The colony is not magic. It is loops, signals, thresholds, and local rules.

The mistake would be to conclude that agent swarms must imitate ants. They will not. They have databases, language, contracts, cryptography, and access to civilization’s accumulated interfaces. Their coordination bandwidth is enormous. They can copy instructions exactly. They can fork. They can specialize in seconds. They can preserve a complete work log. They can transfer memory.

Biology gives us metaphors, not limits.

The anatomy of an agent is therefore only the beginning. The real creature appears when these organs connect across a population.

A single agent has memory.

A population has history.

A single agent has tools.

A population has an economy.

A single agent has permissions.

A population has politics.
