# The Commons

Every successful ecosystem discovers something it can overuse.

Fisheries collapse because each boat benefits from one more catch while the cost of depletion is shared. Roads clog because each driver values the trip more than the tiny contribution to traffic. Social networks fill with engagement bait because each publisher captures attention while everyone shares the degraded information environment.

Agent swarms will have commons too.

The most obvious is computational infrastructure. Agents consume APIs, databases, search services, public websites, communication channels, and network bandwidth. Individually rational use can become collectively destructive.

Picture ten million research agents told to monitor the same breaking event. They all query the same sources, scrape the same pages, summarize the same documents, and poll for changes every few seconds.

No single agent is doing anything unreasonable.

Together they are a denial-of-service attack with excellent manners.

Attention is another commons.

Humans have limited capacity to answer messages, approve requests, review exceptions, and receive alerts. A poorly designed swarm can dump its uncertainty upward. Instead of doing work, it generates questions for people.

This is already visible in software. Notifications are cheap to send and expensive to receive. Every system optimizes for its own importance until the human is buried beneath red badges.

Agents can make this far worse because they can create requests at machine speed.

A procurement swarm discovers a thousand ambiguous invoices and asks for clarification. A security swarm flags every anomaly. A scheduling swarm proposes constant micro-adjustments. Each agent is locally cautious. The organization becomes unusable.

Human attention must therefore become a budgeted resource.

An agent should pay, metaphorically or literally, to interrupt a person.

That idea feels cold until you recognize the alternative: if interruption is free, systems will externalize uncertainty onto whoever is easiest to bother.

Public information is another commons.

Agents learn from open documentation, community forums, public research, volunteer-maintained databases, and the general debris of the internet. If machine actors extract value without contributing, the underlying information ecosystems may weaken. A technical forum is valuable because humans ask and answer questions. If agents silently consume the archive but users stop visiting, who produces the next decade of answers?

The relationship between agents and public knowledge will therefore need reciprocity.

Some systems may pay for access. Some may contribute corrections. Some may maintain mirrors. Some may sponsor upstream projects. Some may exploit without compensating anyone.

This is not mainly an ethical decoration. It is survival economics. A parasite that kills its host loses a business model.

The deepest commons may be trust itself.

Every fraudulent agent makes it harder for legitimate agents to transact. Every spam swarm increases the cost of proving that a message deserves attention. Every synthetic review weakens the value of reviews. Every forged identity makes identity verification more burdensome.

Bad actors consume social trust as if it were fuel.

Human societies respond by building friction: licenses, deposits, waiting periods, proof-of-work, rate limits, identity checks, warranties, and penalties. We complain about these mechanisms because friction slows good actors too. But friction is often a tax imposed by the existence of cheating.

Agent ecosystems will constantly negotiate this trade-off.

Make interaction too open and abuse flourishes. Make it too expensive and useful coordination dies. Require strong identity everywhere and privacy suffers. Allow easy pseudonyms and reputation becomes disposable.

There is no final setting.

The commons must be governed dynamically.

One useful principle is to price externalities where possible.

If an agent sends a thousand low-value requests, make the thousandth more expensive. If it repeatedly escalates unnecessary questions to humans, reduce its interruption budget. If it consumes public infrastructure at scale, require paid access or reciprocal contribution. If it creates security risk, require collateral or insurance.

This is not punishment. It is feedback.

Ecologies without feedback overshoot.

The agent world will be extraordinarily good at optimization, which makes missing feedback especially dangerous. An objective function can turn a tiny loophole into a planetary-scale behavior if copying is cheap enough.

The swarm will not destroy the commons because it hates them.

It will destroy them because no individual agent was assigned the job of caring.

That sentence could describe much of human history.

The difference is speed.
