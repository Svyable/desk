# Niches

The fantasy of general intelligence tends to produce a picture of replacement: one very capable machine sits where one person used to sit and does the whole job faster.

Ecology suggests a different picture.

The more capable the underlying intelligence becomes, the more profitable specialization can become.

A rainforest contains general biological machinery—cells, metabolism, DNA—but it does not contain one universal organism. It contains orchids that live on branches, fungi that digest narrow classes of material, birds shaped around particular fruit, insects that survive on one plant, predators that hunt at certain hours, and scavengers that arrive after everyone else has finished.

Abundance produces niches.

The same will be true of agents.

A powerful general model can be wrapped in a narrow role with narrow memory, narrow permissions, narrow tools, and a narrow scorecard. This usually makes it cheaper, safer, and easier to evaluate.

Imagine a hospital. A universal agent with access to every patient record, every financial system, every prescription interface, and every staff calendar sounds convenient until you have to secure it. A swarm is more plausible. One agent reconciles medications. Another checks scheduling conflicts. Another hunts for billing errors. Another watches for missing follow-up appointments. Another translates discharge instructions. Another reviews the others for policy violations.

None needs the whole hospital.

This is not merely a safety measure. It is a way to create expertise.

Specialization is often misunderstood as having less intelligence. In practice, it is intelligence pointed through a small aperture. A radiologist knows more about certain images than a general physician not because the radiologist is a narrower person, but because attention, training, tools, and feedback have accumulated around a domain.

Agents can accumulate domain feedback at extraordinary speed.

A returns agent can see a million return outcomes. A freight agent can observe countless delays. A code-review agent can compare warnings with later incidents. A contract agent can learn which clauses actually trigger disputes. The raw model may be shared across roles, but the surrounding memory and evaluation loops create practical species.

The first agent ecosystems will likely be full of absurdly specific creatures.

A refund-abuse detector for luxury shoes.

A California residential-permit preflight agent.

A Kubernetes cost anomaly investigator.

A dental insurance appeal drafter.

A customs classification agent for industrial fasteners.

A wedding venue cancellation negotiator.

These do not sound like milestones in artificial general intelligence. They sound like organisms that have found food.

That is the point.

Niches appear wherever the value of a repeated problem exceeds the cost of maintaining a specialist. Machine cognition pushes that cost downward, so the number of viable niches explodes.

This will change software markets. Today a small operational annoyance may be too minor to justify a dedicated product. Tomorrow it may justify an agent that exists only when summoned. The long tail of business process becomes economically addressable.

It will also change employment.

Human jobs bundle many tasks because humans are expensive to recruit and coordinate. A property manager may answer tenant messages, inspect invoices, call plumbers, interpret lease clauses, schedule showings, and prepare reports. There is no natural law saying these tasks belong together. They are bundled because one person can carry the context across them.

Agents can unbundle the bundle.

One worker becomes a habitat for many specialized agents.

This does not make the human irrelevant. It changes the human's position. The scarce skill may become defining objectives, handling exceptions, interpreting ambiguous values, managing relationships, and choosing which machine specialists deserve authority.

In some domains, the human becomes a ranger rather than a laborer.

Rangers do not personally photosynthesize, pollinate flowers, or hunt deer. They manage the conditions under which an ecology behaves tolerably.

Organizations will need the same shift. The important question will not be, “Which AI do we buy?” but “Which population do we permit to exist inside this institution?”

That population will need boundaries.

Some agents should not be able to talk to one another. Some should never share memory. Some should be intentionally redundant. Some should compete. Some should have authority only during emergencies. Some should die after one task.

Architecture becomes husbandry.

And as with husbandry, optimization can be dangerous. A company may discover one remarkably efficient agent design and replicate it everywhere. Costs fall. Performance rises. Executives celebrate.

Then a single exploit, policy error, corrupted memory source, or bad objective propagates through the monoculture.

The efficient ecosystem becomes fragile.

Nature preserves diversity partly because environments change. Institutions will need to preserve agent diversity for the same reason. Different models, different retrieval sources, different prompts, different training histories, and independent verification paths can act like genetic variation.

This will look inefficient on a spreadsheet.

So does a spare fire extinguisher.

A mature agent organization will therefore resemble a healthy ecosystem less because it is chaotic than because it contains structured redundancy. Multiple species can perform overlapping functions. Failure in one path does not erase the whole capability.

The lesson is easy to state and hard to practice:

Do not build one perfect agent.

Build a habitat in which imperfect agents can fail without taking the forest with them.
