# Point Loma

A secret animal program eventually becomes a place.

At Point Loma the abstractions acquire tanks, pens, boats, fish freezers, veterinary rooms, trainers, transport gear and schedules. The Navy says its Marine Mammal Program has been homeported there since the 1960s. That continuity matters. A sixty-year program is not a clever prototype preserved in a museum drawer. It is an institution with accumulated practice.

Institution is also where secrecy changes shape. The Navy says the program's true missions remained classified for decades and that this vacuum helped produce stories about offensive dolphin weapons. That claim should not be accepted as a universal solvent for every allegation. Classification can explain missing information; it cannot specify what the missing information says. Still, Point Loma offers a useful lesson in evidentiary ecology. When a visible facility contains animals doing acknowledged military work while the exact missions are concealed, speculation is not an external contaminant. It is one predictable product of the security design.

The place also makes costs visible. A robot can be mothballed. A dolphin cannot. It must be fed and cared for on the days no fleet commander needs it. It ages. It develops medical problems. It forms training relationships. The Navy's animal capability therefore depends on a standing biological institution, not merely on acquiring a sensor when war begins.

This is expensive in precisely the way mature capability is expensive: the readiness exists before the task.
