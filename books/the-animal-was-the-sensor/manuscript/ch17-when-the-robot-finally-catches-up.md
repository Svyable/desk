# When the Robot Finally Catches Up

Replacement is not a date. It is a matrix.

A modern autonomous underwater vehicle may exceed a dolphin in endurance, repeatability, data logging or tolerance for missions humans consider too risky for an animal. A dolphin may remain superior in a narrow discrimination task in clutter. Cost comparisons change depending on whether one counts development, standing crews, veterinary infrastructure, batteries, ships, maintenance and failure.

The Navy's current public description still says technology has not completely matched its animals for the missions they perform. That is a claim from the operator and should be tested against independent technical literature, especially as machine perception improves rapidly.

The humane objective is not to preserve an animal program because it has history. If machines can do the job at equivalent or better performance without recruiting animals into military risk, that is a real advantage. But declaring replacement before measuring the old system honestly is another kind of sentimentality—this time toward machines.

The right endpoint is boring: task by task, environment by environment, compare outcomes. The animal should not win because it is wondrous. The robot should not win because it is new.
