# The Ocean Had Better Sonar

Electronic sonar is an extraordinary technology. That does not mean it owns the category.

Dolphins evolved active echolocation in an ocean full of clutter, moving prey, irregular bottoms and reverberation. The Navy's public account is unusually plain about the operational consequence: objects that can be difficult for electronic sonar in coastal shallows or cluttered harbors can be found by dolphins. The important claim is comparative, and it deserves numbers before publication—false alarms, detection probability, target types, bottom composition, sea state, operator effects. But the existence of the mission is not folklore.

This is where the animal-program story stops being a cabinet of curiosities. The Navy did not keep dolphins because somebody in 1962 enjoyed the idea. It kept them because a trained animal could perform useful work. That work combines emission, reception, classification, navigation and search strategy. A transducer can emit a pulse. A classifier can score a return. A vehicle can run a lawnmower pattern. The dolphin can change what it is doing because the bottom has changed.

That does not make biology magical. It makes the comparison harder. Machines are normally evaluated component by component; organisms arrive as systems. If the machine wins on range but loses on clutter, if it wins on endurance but loses on reacquisition, if it produces better raw data but requires a larger interpretation chain, what exactly has replaced what?

The military answer is often inelegant: use both.
