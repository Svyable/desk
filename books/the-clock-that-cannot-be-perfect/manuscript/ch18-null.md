# Chapter 18 — What a Null Would Kill

A useful theory must tell us how to hurt it.

For the clock proposal, the immediate problem is that the predicted effect sits far below current sensitivity. A present-day null therefore does little. The experimental program becomes meaningful only when a measurement reaches a parameter region not already excluded—or reaches a region that distinguishes competing mappings between collapse noise and gravity.

This is why the book must eventually include a joint exclusion atlas rather than a parade of experiments. Plot the CSL localization rate and correlation length. Mark regions excluded by spontaneous radiation, cold atoms, mechanical resonators, gravitational-wave instruments, cosmological heating, and interference. Then overlay the clock sensitivity required to add genuinely new information.

For Diósi–Penrose-type models, state exactly which regularization or mass-density smearing is assumed and which stochastic implementation is tested. Do not write “DP” as though it were one immutable equation.

A clock null becomes interesting when it closes a region that other experiments leave open or tests a specifically gravitational identification that mechanical noise alone cannot.

The strongest possible null would be cross-channel: a parameter choice invoked to explain a mechanical anomaly predicts a timing spectrum, and the clock network does not see it. That would force the anomaly elsewhere or the model to change.

Falsification is rarely a guillotine. It is more often a vise.
