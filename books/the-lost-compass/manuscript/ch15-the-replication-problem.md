# The Replication Problem

Magnetoreception is unusually good at producing experiments that look decisive until someone changes the room.

That is not a reason to abandon the subject. It is a reason to make replication itself part of the biology.

A serious replication has to reproduce more than species, field strength and behavioral assay. It should characterize static magnetic gradients, alternating fields, radiofrequency noise, lighting spectrum, vibration, acoustic leakage, coil heating, cage asymmetry, current path and grounding. If the hypothesized receptor is physically sensitive to variables most laboratories ignore, then those variables belong in the method.

But there is a danger in expanding the method until every failure becomes explainable. A theory that says positive results require an unspecified electromagnetic purity can survive forever.

The solution is preregistration of nuisance thresholds.

Before running animals, investigators should map the field environment and define acceptable ranges. Competing laboratories should exchange hardware or build independently to the same performance specification. Analysis rules should be frozen. Sham fields should reproduce current, heat and switching without the intended magnetic rotation. Blinding should extend to the people scoring behavior.

Human experiments need even stricter controls because EEG itself is an electromagnetic measurement. Independent laboratories should reproduce the 2019 field geometries using different coil designs and EEG systems. A registered multi-site study could include Northern and Southern Hemisphere cohorts, active sham conditions, reversed inclination, slow and fast rotations, light manipulations, and artifact sensors mounted on head phantoms.

The strongest test would include a condition the original model predicts should fail.

Replication is not merely repeating the positive condition. It is reproducing the structure of the effect.

Bird studies should likewise test predicted spectral sensitivity rather than generic “EMF on/off.” If radical-pair chemistry is the mechanism, disruption should depend on frequency, amplitude and molecular dynamics in ways a magnetic-particle receptor does not share. If results move arbitrarily with equipment, the mechanism weakens.

The receptor hunt itself needs adversarial replication. Any iron-rich candidate should be examined by independent anatomists before functional stories harden. Any cryptochrome candidate should face in vivo perturbation, not only spectroscopy.

A controversial field earns trust by making its favorite explanations disposable.

The pigeon-beak macrophage correction was painful and useful. Magnetoreception needs more experiments capable of producing that kind of loss.
