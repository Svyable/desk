# The Experiment That Would End the Argument

A field that has argued for fifty years should be able to describe the experiment that would make the argument smaller.

Psi often cannot.

Believers point to an existing literature and say the evidence is already sufficient. Skeptics point to the same literature and say the methodological history makes the evidence untrustworthy. Another small study does almost nothing. If it is positive, skeptics call for replication. If it is null, proponents invoke low power, subject state or laboratory atmosphere. The disagreement survives because each new experiment enters a database whose meaning is already contested.

The way out is not a better argument about the old studies.

It is a new evidentiary object designed by both sides.

Start with remote viewing because the task is conceptually simple.

A participant produces information about a target they cannot ordinarily know.

The target pool should be large, perhaps thousands of high-resolution images and short videos. Each target should be characterized in advance using measurable visual and semantic properties: natural versus artificial, water presence, dominant geometry, motion, human presence, color distribution, scale, emotional valence and other features. Decoy sets should be generated algorithmically so that correct targets are not uniquely distinctive.

Target selection should occur through a cryptographically secure process controlled by infrastructure separate from the laboratory.

No local experimenter should know the target.

The target should not even be selected until after the participant has begun the trial, reducing opportunities for ordinary leakage.

The participant’s response should be recorded digitally and committed with an immutable timestamp before target reveal.

No editing afterward.

Judging should happen through at least two independent methods.

First, human judges blind to target identity rank target sets against transcripts.

Second, a frozen machine-scoring model computes similarity using a method specified before the study.

The human and machine outcomes should be analyzed separately, not combined opportunistically.

The primary endpoint should be fixed.

Suppose it is the mean rank of the correct target across all trials. Secondary analyses can explore semantic features, individual differences and phenomenology, but they cannot redefine whether the experiment “worked.”

The sample size should be large enough to detect the effect claimed by the strongest prior literature with high power.

Not fifty trials.

Thousands.

Across multiple laboratories.

At least half the sites should have no prior institutional commitment to parapsychology. Some should be openly skeptical. The protocol should be identical enough to support pooled analysis while allowing site-level effects to be estimated.

Every trial should count.

No “bad session” exclusions after outcome.

If a session is invalid because of technical failure, the invalidation must be triggered by rules applied without target knowledge.

Data should be mirrored in multiple repositories.

The analysis code should be public before unblinding.

An independent statistics team should verify the result.

The project should be repeated once if positive.

This sounds excessive only because psychology got used to much weaker standards.

For a claim that rewrites human information acquisition, it is cheap.

The same infrastructure can test precognition.

Participants make a forced choice or produce a target description before a future target is selected. The randomization occurs only after the response is sealed. Hardware and software are audited for predictability. The target is then generated and scored automatically.

No experimenter can leak information because the information does not yet exist in selected form.

This is a severe test.

If performance exceeds chance across independent sites, ordinary sensory explanations collapse.

Statistical or procedural explanations may remain, but the anomaly becomes sharper.

Presentiment requires different controls.

Physiological recording should be continuous. Stimulus classes should be balanced. Randomization should prevent local sequence dependencies. Signal-processing pipelines should be fixed before condition labels are revealed. Filters that can smear post-stimulus information backward must be avoided or explicitly validated using simulation. Data analysts should receive shuffled labels for pipeline development and only later run the locked analysis on held-out data.

Replication should use different physiological hardware.

If the same anticipatory effect appears in skin conductance, pupil response and cardiac measures under independent pipelines, confidence grows.

Psychokinesis is even simpler conceptually.

Build multiple physically distinct random systems: quantum photon paths, avalanche noise, radioactive decay, thermal noise. Include deterministic pseudo-random generators as controls. Generate data continuously whether participants are present or not. Randomly schedule intention periods in a way participants cannot predict until the period begins. Keep operators blind to live output.

Then ask whether intended direction correlates with physical outputs prospectively.

If only one hardware class responds, investigate that hardware.

If pseudo-random prerecorded data “respond,” the psychokinesis interpretation fails.

This kind of experimental decomposition is how the categories finally become distinct.

The project should also treat individual differences as a primary scientific question rather than a rescue analysis.

Before confirmatory trials, participants complete a standardized battery: previous psi performance if available, attention measures, absorption, meditation experience, personality, sleep, sensory thresholds and perhaps physiological markers. A training dataset can be used to build a preregistered predictor of high performance.

Then test the predictor on new people.

If no stable high performers emerge, the idea of a gifted psi phenotype weakens.

If they do, recruit them across laboratories.

This could be the moment the field changes.

A person who repeatedly performs above chance under hostile controls becomes more scientifically valuable than every famous anecdote combined.

Mechanism research should begin only after that phenotype is secure.

That ordering is important.

The field has often tried to explain before it can reliably predict.

The decisive experiment should also include a cultural design feature: all teams precommit to language.

If the primary result is null within a narrow confidence interval, proponents agree not to call that protocol supportive.

If the result is positive and replicates, skeptics agree to call it an anomalous information effect rather than dismiss it categorically.

Nobody is required to call it telepathy, precognition or nonlocal consciousness until mechanism distinguishes those categories.

This language contract prevents metaphysical escalation.

The project should be governed by an adversarial board.

Parapsychologists.

Experimental psychologists.

Statisticians.

Magicians.

Security engineers.

Neuroscientists.

Physicists.

Open-science specialists.

The board’s job is not to vote on whether psi exists. It is to make ordinary explanations expensive.

The funding model matters too.

No single donor whose identity is tied to a positive result should control the program. Government funding could work, but the history of national-security interest creates its own incentives. A consortium of foundations and scientific agencies with guaranteed publication rights would be better.

The budget would be modest by modern science standards.

A few million dollars could run more decisive psi research than decades of scattered small studies.

Why has this not already happened?

Because unresolved controversy can be institutionally stable.

Proponents have journals, conferences and accumulated literature. Skeptics have a reliable example of methodological credulity. Mainstream institutions avoid reputational risk. Funders see little career upside. A decisive result threatens existing identities on both sides.

This is not a conspiracy.

It is equilibrium.

Breaking the equilibrium requires making resolution more prestigious than position.

The experiment itself could become a model for other contested claims.

Take UAP sensor anomalies. Proponents and skeptics jointly define instrument calibration, metadata requirements and event classification before collection.

Take anomalous materials. Agree on chain-of-custody standards, blind laboratories and isotopic analyses before samples are tested.

Take unconventional bioeffects. Specify exposure, sham conditions and physiological endpoints in advance.

The method is general: adversaries share the apparatus.

There is a reason this feels politically difficult. Scientific disagreements are often also status disagreements.

If the experiment resolves the issue, somebody loses a story.

But reality does not owe us permanent stories.

A mature field should want a test capable of injuring it.

The final design feature is the most important: make failure informative.

A null remote-viewing result should not merely say “psi absent.” It should bound effect size under specific conditions.

A positive result should not merely say “psi present.” It should provide individual distributions, site effects, target-feature dependence and trial-level data.

Either outcome narrows the world.

This is what the historical program never fully achieved.

STARGATE accumulated enough evidence to remain arguable and not enough to become ordinary.

The next experiment should be designed so that repeating that outcome is the least likely result.

If psi is false, kill the strongest version.

If it is real, give it nowhere to hide.
