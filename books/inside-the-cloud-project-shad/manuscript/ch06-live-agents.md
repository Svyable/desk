# Live Agents

The history changes temperature when the material is no longer a stand-in.

VA’s current account of Project 112 and SHAD lists biological warfare agents including Coxiella burnetii, Francisella tularensis and staphylococcal enterotoxin B, and nerve agents including sarin, VX, tabun and soman across the larger testing program. That list should not be sprayed backward across every SHAD ship. Test-specific attribution is mandatory. But the existence of active-agent testing is documented, and it removes any excuse for treating the entire program as harmless smoke-and-mirrors exercises.

The military rationale was severe because the threat was severe. Defensive systems tested only against easy substitutes can fail when physical properties change. Yet the closer a defensive test moves toward realism, the more important consent, protection, monitoring and record retention become. Realism is not a moral solvent.

This chapter’s eventual full version needs the agent-by-agent test ledger: code name, date, platform, release, route, protective posture, monitoring and what the declassified record actually supports. Until that work is complete, broad statements about who received what dose are premature.

There is another asymmetry worth preserving. A classified planner can know that an active agent is present while a sailor may know only that an exercise is underway. Decades later the sailor may know he was in SHAD but still not know enough to reconstruct a clinically useful exposure. Secrecy can therefore outlive the operational reason for secrecy even after the program name becomes public.

The strongest version of this story does not need to exaggerate the chemistry. It needs to follow the information.
