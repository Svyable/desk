# Research — The Compass That Radio Broke

This directory is the working evidentiary layer for the manuscript.

The manuscript uses four classes throughout: **D1 documented/verified**, **D2 credible but incomplete/model-dependent**, **D3 disputed or insufficiently confirmed**, and **D4 speculative synthesis/open conjecture**. A source can support a D1 observation while an interpretation built from it remains D2 or D3.

Start with `source-log.md`, `evidence-matrix.md`, `chronology.md`, `contradictions-and-incentives.md`, and `decisive-experiment.md`.

No non-public classified material was used. Defense relevance is based only on public acknowledgments, public grant information and openly published research.
