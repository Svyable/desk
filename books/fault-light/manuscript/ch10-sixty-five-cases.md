# Sixty-Five Cases

In 2014 Robert Thériault, France St-Laurent, Friedemann Freund and John Derr published an analysis of 65 reported earthquake-light cases. Their striking result was geological: the cases appeared disproportionately associated with rift environments and subvertical faults.

This is where the subject becomes scientifically sharp enough to be uncomfortable. If luminous reports were merely generic storytelling around earthquakes, why should tectonic setting matter? A geological clustering, if robust, suggests mechanism rather than folklore.

But a set of 65 historical cases is not 65 controlled trials. Inclusion criteria matter enormously. Reporting cultures differ. Population density changes what gets seen. Electrification changes both confounds and documentation. Famous cases attract archival effort. Geological classification itself can contain judgment.

The rift result should therefore be treated as a generator of prospective predictions. Future well-instrumented rift-zone earthquakes should produce a different rate or character of luminous/electrical anomalies than matched non-rift events if the association is causal. The model should specify how much different.

A retrospective pattern earns its keep by risking the future.
