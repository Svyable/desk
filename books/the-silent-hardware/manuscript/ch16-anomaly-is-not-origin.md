# 16. Anomaly Is Not Origin

Anomaly is a relationship between an observation and a model.

Origin is a claim about history.

Confusing the two is the fastest way to ruin this subject.

A radar return can be anomalous because the target is unusual, the propagation is unusual, or the radar model is wrong. A spectrum can be anomalous because the material is novel, the calibration failed, the background subtraction failed, or the library is incomplete. An orbit can be anomalous because nongravitational physics matter more than assumed. A microscopic particle can be anomalous because it came from another star and is perfectly natural.

The word “unexplained” is particularly dangerous. It describes the state of the analyst, not the state of the universe.

A disciplined artifact program needs an escalation ladder with explicit evidence classes.

Class 1 contains established observations and documented context. Class 2 contains credible anomalies that survive basic controls but remain incompletely explained. Class 3 contains origin claims without independent confirmation. Class 4 is open synthesis.

No amount of repetition of a Class 3 claim upgrades it to Class 1.

This sounds obvious until testimony enters. A respected astronaut, intelligence official, scientist or contractor can report something sincerely and accurately as experienced. Their status can raise the credibility of the report. It cannot substitute for the missing material chain.

The same rule protects positive evidence. If a sample with impeccable custody shows an engineered multilayer structure in three laboratories, the fact that the conclusion is extraordinary does not permit endless moving of the goalposts. Skepticism must also be operationalized.

A good anomaly framework therefore pre-registers both upgrade and downgrade conditions.

What measurement would make artificiality more likely? What result would make it less likely? What natural analog would defeat the claim? What independent instrument could arbitrate?

Without those questions, anomaly hunting becomes belief with expensive sensors.
