## Premise

Generative systems can produce contracts, code, analysis, reports, messages, and options faster than the people named on that work can inspect it. This book follows what happens when creation becomes cheap but comprehension does not: summaries replace documents, automated reviewers inspect automated drafts, and a human signature still supplies authority even when no human holds a working model of the whole. The problem is not simply false output. Much of the unread world will be accurate. The deeper risk is consequential work that nobody had enough time to understand before accepting it.
