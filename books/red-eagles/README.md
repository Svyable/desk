# Red Eagles

**Working subtitle:** How America Learned to Fly the Enemy's Airplanes

## Thesis

Cold War foreign-aircraft exploitation offers a unusually concrete answer to a question that hangs over every modern allegation of secret reverse engineering: what does a real exploitation program leave behind? HAVE DOUGHNUT, HAVE DRILL and CONSTANT PEG show that acquiring adversary technology is only the beginning. The useful product comes from maintenance, instrumented testing, pilot conversion, tactical comparison, accident risk, logistics, compartmentation, training doctrine and eventual institutional diffusion.

This book reconstructs that machinery without using documented Soviet-aircraft exploitation as proof of any modern crash-retrieval allegation. Its wager is narrower and more useful: historical exploitation programs give us a documentary comparator against which extraordinary contemporary claims can be tested.
