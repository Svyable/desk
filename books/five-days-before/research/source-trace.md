# Five Days Before — source trace and research plan

## Reader promise

By the end, the reader should be able to look at a claim that “an anomaly occurred before an earthquake” and ask the next six questions automatically: compared with what background, at what effect size, under how many search choices, with what physical mechanism, with what prospective false-alarm/miss rate, and compared with which forecast baseline?

The book is not a referendum on earthquake prediction. It is an anatomy of the evidentiary distance between a pre-event correlation and a warning.

## Freshness against current Desk work

Recent Author-agent books concentrate on behavior-control archives, developmental biohybrids, living military sensors, foreign-materiel exploitation, remote viewing and operational utility, animal sensing, anomalous-gravity replication, microbial conduction, quantum-anesthesia isotope effects and atmospheric technosignatures. A default-branch search for seismic/electromagnetic/ionospheric earthquake material returned no matching manuscript.

The nearest conceptual neighbor is *Conditions Not Met*, which studies replication fidelity in an extraordinary laboratory gravity claim. This book instead studies observational geophysics where the target event is uncontrolled, the background is nonstationary, and the decisive transition is retrospective anomaly → prospective forecast. Its governing mathematics is base rates and out-of-sample alarm performance rather than apparatus matching.

## Quantitative backbone

Every candidate precursor chapter should, where source data permit, extract the same fields:

| Field | Why it matters |
|---|---|
| observable | what was actually measured |
| effect size | prevents p-value-only narration |
| uncertainty | distinguishes precision from magnitude |
| frequency/band | limits mechanism claims |
| spatial radius | defines alarm area |
| lead-time window | defines prospective test |
| magnitude/depth threshold | defines target population |
| local time/season | reveals conditionality |
| event count | exposes small-N claims |
| quiet-time denominator | required for false-alarm rate |
| background construction | major artifact pathway |
| search degrees of freedom | multiple-testing burden |
| held-out data | distinguishes discovery from validation |
| prospective status | removes hindsight privilege |
| sensitivity / miss rate | how many target events were detected |
| specificity / false-alarm rate | how often quiet periods trigger |
| incremental skill | comparison against seismic baseline |

## A deliberately simple base-rate example

Do not publish a numerical example until the event rate is sourced for a defined region/magnitude/time window. The chapter should nevertheless teach the arithmetic transparently.

If an alarm system has sensitivity S and false-positive probability F over a fixed space-time cell, and the prior probability of the target earthquake in that cell is P, then the probability of an earthquake given an alarm is:

P(E|A) = S P / [S P + F (1-P)].

When P is small, even apparently good S and F can yield mostly false alarms. Use sourced empirical rates rather than invented dramatic numbers in manuscript prose.

## Prospective experiment specification

A serious test should be registered before the evaluation interval begins and should freeze:

- geographic cells or a continuous spatial scoring rule;
- target magnitude/depth class;
- forecast horizon;
- input channels and preprocessing;
- geomagnetic/solar/meteorological exclusions or covariates;
- anomaly thresholds;
- treatment of aftershocks and earthquake clustering;
- baseline forecast model;
- scoring rule;
- policy for missing satellite passes/data gaps;
- public timestamping of every forecast or probability field.

The strongest version separates a discovery archive from a chronologically later holdout and then repeats on an independent sensor/platform. A model tuned after seeing target-event times goes back to discovery status.

## Narrative progression check

1. Open on the five-day result without promoting it.
2. Build the instrument before the mechanism.
3. Build candidate crustal physics before the atmospheric bridge.
4. Make the ionosphere noisy before calling anything anomalous.
5. Reconstruct the strongest DEMETER statistical positives.
6. Remove retrospective privilege and introduce prospective scoring.
7. Follow a real anomaly that becomes cultural noise.
8. Follow an analysis choice that can manufacture a pre-event feature.
9. Use Parkfield as a high-value negative case.
10. Allow earthquake lights to remain interesting without becoming predictive.
11. Use volcanoes to attack specificity.
12. Examine continued state investment without argument from authority.
13. Price false alarms in actual decisions.
14. Specify the experiment capable of ending the argument.
15. Give both camps defeat conditions.
16. Return to five days with no knowledge of Saturday.

## Anti-slop notes

Avoid the phrase “Earth is trying to tell us.” It anthropomorphizes noise and writes the conclusion before the mechanism.

Avoid “science dismissed” narratives. Mainstream agencies investigated these claims, sometimes aggressively; skepticism itself generated useful experiments and reanalyses.

Avoid making DEMETER a heroic suppressed mission. It was a public scientific satellite whose results are in ordinary journals.

Avoid calling every ionospheric change an “electromagnetic precursor.” Name the measured variable.

Avoid the easy skeptical ending that prediction is impossible in principle. The evidentiary record supports “not demonstrated reliably,” which is stronger because it is accurate and remains falsifiable.

Avoid ending every chapter with the anomaly/predictor distinction. Each recurrence must change: mechanism, background, statistics, prospective scoring, specificity, decision cost.
