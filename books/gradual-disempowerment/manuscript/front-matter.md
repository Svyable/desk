# Gradual Disempowerment

**Sven Hardy Benson**

© 2026 Sven Hardy Benson. All Rights Reserved.

---

The phrase *gradual disempowerment* comes from a 2025 paper by Jan Kulveit, Raymond Douglas, Nora Ammann, Deger Turan, David Krueger, and David Duvenaud. Their argument is stranger than the usual artificial-intelligence catastrophe because it does not require a catastrophe in the ordinary sense.

No machine has to escape.

No system has to hate us.

No company has to decide that humans are obsolete.

No government has to sign away control.

Things can keep working.

That is the problem worth following.

A firm automates a task because the software is cheaper. A manager delegates a judgment because the model is more accurate. A customer lets an agent choose because comparison is tedious. A public institution adds an automated decision because the queue is too long. A person asks a machine for advice because the machine is available at 2:13 in the morning and another person is not.

Each transaction can be useful.

Some can be empowering.

The difficult question is what happens to human power when enough systems no longer need human participation in order to function.

This book is not an attempt to repackage the original paper as mine. It takes that paper’s question into places where the word *power* becomes concrete: work, management, ownership, consumer choice, culture, companionship, bureaucracy, competition, and the cost of putting a human back into a loop after the loop has learned to run without one.

The strongest objection will stay in the book with the argument.

Delegation is not automatically disempowerment.

Sometimes it is exactly the opposite.
