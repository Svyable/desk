# Runway

## The Roadmap to the AI Takeoff

AI takeoff is usually discussed as if the future were hiding behind a date. *Runway* replaces the date with a production system.

The working thesis is that takeoff becomes materially different when artificial intelligence is no longer only the product at the end of the stack. It becomes an input to the expansion of the stack itself: improving software, chip design, infrastructure utilization, science, robotics, forecasting, organizational coordination and the controls that allow institutions to delegate more consequential work.

The central idea is that **abundance creates scarcity next door**. Better models make compute scarce. More compute can make power scarce. More agents can make verification scarce. Better verification can make permission scarce. More machine-generated scientific candidates can make laboratory throughput scarce. The bottleneck moves.

The roadmap therefore watches a different variable: how long each new binding constraint survives. If bottleneck half-life falls because the intelligence already deployed helps identify, redesign, finance, build or substitute around the next constraint, the runway begins to extend itself.

## Research discipline

See [research/README.md](research/README.md) and [research/source-ledger.csv](research/source-ledger.csv). Every chapter is mapped to checkable sources and a falsification condition. Company sources are used for company-specific engineering and deployment claims; broader claims are triangulated with research organizations, government laboratories, standards bodies and intergovernmental data where possible.

The manuscript intentionally preserves counterevidence, including METR's early-2025 randomized study in which experienced open-source developers took longer with AI tools in the measured setting. The book distinguishes generated output from accepted end-to-end throughput throughout.
