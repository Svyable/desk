# 17. The Experiment That Would Matter Now

If remote viewing deserves another serious test, the test should be designed by people who are tired of the argument.

Not a television challenge. Not a charismatic subject in a room with believers. Not a demonstration whose target set is chosen after the viewer arrives.

A hostile collaboration.

The participating teams should include researchers sympathetic to anomalous cognition, methodologists who expect conventional explanations, statisticians who commit the analysis before data collection, and independent data custodians who prevent anyone from quietly changing the protocol.

Targets should come from a large standardized corpus with balanced perceptual features. Selection should be cryptographically randomized. The target identity should remain inaccessible to viewer, interviewer, local experimenter and first-stage judge until the response is frozen.

Responses should include raw speech, drawings, timestamps and confidence judgments. No cleanup. No narrative reconstruction.

Scoring should occur three ways.

First, traditional blinded human judges using pre-registered rank-order procedures.

Second, feature-level coding by independent teams unaware of target identity.

Third, automated similarity systems frozen before the study—not because machine scoring is inherently objective, but because disagreement between human and machine scoring would reveal how much the effect depends on interpretive flexibility.

The study should be multi-site and large enough to estimate individual differences without turning post hoc star performers into a rescue device. A replication set should be held out. Participants who appear exceptional in the discovery phase should have to reproduce performance prospectively in the holdout.

Then add the intelligence test.

For each response, ask blinded analysts to make a forced decision among operationally meaningful alternatives. Does the session improve their accuracy over baseline intelligence? Does viewer confidence predict value? Can bad sessions be identified before target reveal?

This last question is the one the old program never conquered.

A channel that is right above chance but cannot tell you when it is right is scientifically interesting.

A channel whose high-confidence trials are reliably more accurate is potentially useful.

The experiment should also contain explicit kill conditions. If the aggregate effect fails across sites, stop calling the historical statistics a basis for present confidence. If an effect appears only under one judge or one scoring method, treat interpretation as the leading suspect. If a laboratory effect replicates but does not improve decisions, separate the scientific discovery from the intelligence failure.

And if a robust, blinded, independently replicated effect survives all of that?

Then the scientific establishment should have the courage to be surprised.

Skepticism is a method, not a destination.
