# Chapter 16 — Build the Null Before the Earthquake

Most anomaly science begins by finding something strange and then asking what else could have caused it.

Reverse the order.

Before deploying a precursor network, write the null-generating catalog. Magnetometers: geomagnetic storms, cultural noise, trains, power systems, lightning, temperature, sensor drift. TEC: solar EUV, traveling ionospheric disturbances, geomagnetic activity, receiver bias, multipath, detrending artefacts. Radon: rainfall, pressure, ventilation, groundwater, soil moisture, detector calibration. Gas chemistry: traffic, industry, wind, boundary-layer dynamics. Animal behavior: feeding, predators, husbandry, weather, social contagion.

Then instrument those nulls directly.

This is more than good housekeeping. It changes the design. A station intended to detect ULF magnetic anomalies should sit beside engineering diagnostics and have remote reference stations. A radon station needs meteorology. A livestock study needs farm-operation logs. A satellite analysis needs global space-weather context.

A strong experiment makes alternative explanations generate distinct predictions.

If a magnetic anomaly is crustal and local, amplitude should vary spatially around the source differently from a magnetospheric disturbance. If radon is driven by regional preseismic permeability changes, nearby stations with related geology should exhibit a coherent pattern not predicted by local ventilation. If an ionospheric signal is earthquake-linked, its localization relative to magnetic conjugacy and local time should differ from solar-driven structure.

The null is not one distribution called noise.

It is a zoo of mechanisms.

The field has spent decades adding candidate precursor mechanisms. It now needs a comparable investment in candidate false-precursor mechanisms.
