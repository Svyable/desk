# The Wave Machine

## Project Seal, Weaponized Water, and the Physics Between an Explosion and a Tsunami

Status: Drafting

A Sven Hardy Benson book about the documented U.S.–New Zealand Project Seal experiments of 1944–45, the hard physics of explosion-generated waves, and the much larger folklore of tsunami and geophysical weapons that grew around a real classified program.
