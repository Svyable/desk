# The Wave Machine

There really was a tsunami-bomb project. This is an inconvenient fact because it gives bad stories a good ancestor.

During the Second World War, American and New Zealand personnel investigated whether arrays of underwater explosive charges could produce militarily useful inundation. The work had a code name, Project Seal. It had engineers, instruments, thousands of experimental detonations, memoranda, military sponsors, and a final technical report. It was secret. It was strange. It was also bounded by physics.

That last sentence is the reason for this book.

The existence of a classified experiment does not validate every later claim about earthquake weapons, artificial tsunamis, ionospheric machines, or disasters attributed to invisible states. But neither does the later folklore make the original project imaginary. The useful territory is between those errors: reconstruct what was actually attempted, ask why apparently encouraging small-scale experiments did not become a practical strategic weapon, and then use that record as a calibration object for modern claims.

The ocean is not a metaphor here. It keeps the accounts.
