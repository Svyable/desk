# The Experiment We Should Run

Project Seal deserves a modern replication, but not as a weapon-development exercise. The useful experiment is a bounded hydrodynamics and inference study designed to answer why the original scaling intuition did or did not survive.

Use non-destructive wave generation or safely controlled small energetic sources in instrumented basins and numerical models. Pre-register source geometries. Blind the analysis team to selected configurations. Measure the complete energy budget: local shock or turbulence, surface-wave spectrum, long-wave fraction, bottom interaction, breaking, and run-up in scaled bathymetries.

The key output is not the tallest wave in a favorable tank. It is a validated transfer function with uncertainty.

Then perform the adversarial step. Give one team only downstream observations and ask it to infer the source. Introduce natural and ordinary anthropogenic controls. This converts the old weapon problem into a modern detection problem: if somebody did try to create an artificial inundation, what observables would distinguish it from natural sources?

The experiment should have defeat conditions. If plausible source arrays cannot couple enough energy into long waves without absurd mass or deployment requirements, say so. If a narrow geometry performs unexpectedly well, reproduce it independently before extrapolation.

The old project asked how to make a wave. The modern project should ask how to know what made one.
