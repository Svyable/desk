# The Experiment We Actually Need

The field does not need another demonstration that stressed cells emit more photons.

It needs a channel experiment.

Start with a source and a receiver whose alleged distant interaction has been reproduced enough times to be worth attacking. Put them in separate environmental chambers. Control temperature, gas composition, vibration and electrical coupling independently. Route the optical path through a calibrated fiber or optical system with known transmission. Measure the source's photon output continuously at the same wavelengths delivered to the receiver.

Then break the link without changing anything else.

A fast shutter can open or close the optical path under computer control. The person handling the cells should not know the condition. The analysis should be specified before the condition labels are revealed. The receiver endpoint should be objective and preferably continuous rather than a subjective morphological score.

If the biological effect follows the shutter, the case becomes interesting.

Next, replace the biological source with a calibrated artificial source that replays the measured photon stream. Match the count rate, spectrum and temporal structure. If replay reproduces the receiver effect, the optical channel has been isolated from whatever chemistry occurred in the source chamber.

Then scramble one feature at a time. Preserve photon number but randomize timing. Preserve timing but shift wavelength outside the candidate receptor band. Preserve spectrum but reduce intensity. Map a dose-response curve down through the endogenous range.

Now introduce genetics or pharmacology at the receiver. Remove the candidate photoreceptor or chromophore pathway. If the response disappears and can be rescued, the experiment has moved from phenomenology toward mechanism.

The crucial phrase is endogenous range.

A lamp can make almost any photobiology paper look impressive if it is bright enough. The question here is whether the naturally emitted stream has sufficient power. Artificial replay should begin at measured biological intensity, not at a convenient level that produces a response.

The source side deserves equal attention. If the receiver responds to photons, can the source regulate them independently of total oxidative damage? A true evolved signal may show controlled modulation, not merely more light when the cell is injured. This is not required for a cue, but it matters for the stronger signaling claim.

A second class of experiments should work at microscopic distance. Place source and receiver cells in microfabricated chambers where only a narrow optical path connects them. Vary distance and geometry. If the effect is photonic, attenuation should follow an optical model rather than an arbitrary biological distance. The shape of that decay could identify scattering, absorption or guided transport.

A third class should use null organisms or tissues. Choose systems with comparable metabolism but different photoreceptor repertoires. If a proposed receptor matters, susceptibility should track its presence more strongly than taxonomic storytelling.

None of this is exotic technology. The difficult part is restraint.

The field must accept experiments designed to make the effect vanish. It must publish clean failures. It must stop treating every positive distant-interaction result as cumulative if the apparatus leaves different confounds open each time.

The experiment we actually need is not the one with the most sensitive detector. It is the one that makes the photons the only remaining road.
