# Evolution Reuses Trash

Waste is a temporary category in biology.

Oxygen was poisonous waste before aerobic metabolism turned it into an extraordinary energetic opportunity. Urea is excreted, but nitrogenous waste can become ecological currency. Bacterial metabolites become signals when another organism evolves receptors for them. Electrical fields produced by muscle activity become sensory information to animals that can detect them.

This is the strongest conceptual argument for taking endogenous photons seriously without pretending the signaling case is proven.

Ultraweak emission does not need to have evolved for communication in order to become communicative later. If oxidative chemistry has leaked photons since early aerobic life, then selection has had immense time to encounter those photons as predictable correlates of metabolism, stress and damage.

The first evolutionary step could occur entirely on the receiver side. A photosensitive molecule that already serves another function might gain a regulatory effect when illuminated by a neighboring cell's emission. If the effect improves survival, sensitivity can increase. Only later might the emitter evolve control over timing or intensity.

This route turns a by-product into a cue before it becomes a signal.

The idea has analogues. Animals exploit carbon dioxide gradients produced unintentionally by hosts. Predators exploit electrical fields produced by prey. Plants and microbes respond to volatile compounds that may begin as metabolic leakage. Communication systems often have messy ancestry.

But analogy is not evidence. The specific photon economy has to work.

Selection cannot rescue a channel that delivers effectively zero photons to the relevant receptor. It can improve sensitivity, alter geometry, create reflective structures, position receptors near sources or shift spectral absorption. Those are empirical predictions. If endogenous optical communication evolved, anatomy should show some adaptation to the physics.

This gives comparative biology a role. Transparent organisms, dense microbial colonies, dark internal tissues and light-exposed surfaces should face different constraints. If the same claimed mechanism appears everywhere with no adjustment for optical environment, suspicion is warranted. If specific tissues exhibit structures that increase photon capture or guide relevant wavelengths, the case becomes stronger.

Evolution also changes how we should think about “noise.” A physicist may call spontaneous emission noise because it is not intentionally modulated. A receiver can still extract a useful statistical cue from it. Heart-rate variability, odor concentration and ambient vibration are noisy in exactly this sense. Biological decisions often use distributions rather than clean symbols.

So an ultraweak optical channel might not look like telecommunications. It might look like one cell changing a probability in another.

That lower bar should not become a loophole. The effect still has to be causal. If blocking photons has no consequence, there is no optical function. If receptor mutants behave normally, the hypothesis narrows. If the only effects require intensities far above endogenous emission, evolution has not been shown to solve the photon budget.

The value of the evolutionary framing is that it produces tests rather than wonder.

It also prevents an unnecessary false choice. The photons can be oxidative waste in chemistry and useful information in ecology at the same time. A molecule does not stop being a by-product when another organism learns to exploit it.

That possibility is modest enough to be plausible and interesting enough to justify the hard experiments.
