# 18. The Search That Earns Its Null

The decisive thylacine experiment is not another expedition with a television crew.

It is a detection program designed so that failure means something.

Begin by defining the survival hypothesis. Not 'a thylacine might be somewhere', but a minimum viable remnant with explicit abundance, range and reproduction. Use historical habitat and the 2023 spatial model to identify high-priority regions without letting recent rumors alone choose sites.

Deploy multiple independent detection systems: standardized camera arrays, passive acoustic systems only where validated vocal signatures exist, track and scat collection, and environmental DNA with independent laboratories. Calibrate each modality on extant Tasmanian carnivores and dog controls. Publish camera-days, downtime, trigger performance and sample failures.

Freeze the identification pipeline before opening the target data. Human reviewers should score images blinded to location and rumor history. Machine classifiers should be tested on known negatives, including dogs photographed under poor illumination.

Every positive should trigger a second protocol that does not depend on the first sensor. Every null should update a population model using measured detectability.

Then keep going long enough to say what the null excludes. Perhaps it rules out a breeding population larger than twenty animals in sampled habitat with ninety-nine percent probability. Perhaps the terrain and DNA persistence are worse than expected and the result is weaker. Either answer is more useful than 'nothing found.'

The project should be designed to benefit extant species by default. Camera and eDNA data should map devils, quolls, invasive predators and prey. That makes the search rational even if the thylacine posterior begins near zero.

What would defeat the book's synthesis? A verified modern specimen would defeat any strong claim that current persistence is negligible. A calibrated survey showing high detection probability over nearly all plausible habitat would push late-survival models sharply earlier. Demonstration that witness-quality scoring is irreproducible would weaken sighting-based dating. A demographic model showing that the reported late sightings cannot be reconciled with any viable hidden population would narrow the corridor further.

There is no shame in ending with a null if the null has earned its weight.

The animal probably died decades ago. The scientific opportunity did not. The thylacine can still teach us how to stop confusing the last thing we saw with the last thing that lived—and how to know when searching has finally become evidence of absence.
