# 16. Cryptozoology's Control Animal

The thylacine sits awkwardly between zoology and cryptozoology because nobody disputes that it existed.

That makes it unusually useful. There is no argument over whether the historical animal is a myth, no need to infer anatomy from folklore, no missing type specimen. We have skins, skeletons, photographs, film and DNA. The uncertainty concerns only terminal persistence.

In effect, the thylacine is a control experiment for cryptid methodology. If a community cannot reliably distinguish real post-extinction signal from false sightings for an animal whose appearance is well documented, confidence should fall for claims about animals with no authenticated specimen at all.

But the control cuts both ways. Rediscoveries happen. Species can remain undetected in remote habitat. The correct skeptical standard cannot be 'absence of recent specimen equals impossibility.' It must depend on search effort and biological plausibility.

This is where ridicule performs badly as a method. Laughter has no false-positive rate, no sensitivity and no stopping rule. Credulity performs just as badly.

The useful cryptozoological question is always convertible into field science: what traces must this proposed animal generate, where, at what frequency, and what known species or artefacts generate the same traces?

For the thylacine we can go further because the historical ecology constrains size, diet, locomotion, range and reproduction. A surviving population should leave more than sightings. It should consume prey, produce scat, die, reproduce, carry parasites, cross roads and shed DNA.

A hypothesis becomes scientific when its invisibility budget can be calculated.
