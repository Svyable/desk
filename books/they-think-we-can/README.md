## Thesis

An intelligence service does not need to believe an anomalous capability is real in order to fund it. It only needs to believe that an adversary believes it might be real. That asymmetry can produce a recursive arms race in which Soviet parapsychology reporting helps justify American psychoenergetics work, American work becomes evidence of seriousness abroad, and the existence of both programs is later mistaken for independent evidence that the underlying phenomenon worked.

The book is not an argument that psi is false. It is an argument that **state interest is not independent evidence of efficacy**. The historical question is whether Cold War anomalous-research programs sometimes formed a threat-perception feedback loop, and how to tell genuine convergent discovery from bureaucratic mirror amplification.

## Governing test

For every claimed foreign capability, reconstruct the provenance chain:

`observation → source → translation → intelligence assessment → threat claim → domestic funding/action → foreign observation of that action → second-order threat claim`

A foreign program counts as independent evidence only to the extent that its motivating observations and positive results are independent of the rival program's claims, publications, rumors, and responses.
