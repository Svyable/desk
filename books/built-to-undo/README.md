# Built to Undo

| **Status**     | Drafting |

The working thesis is that civilization advances not only by learning how to do more, but by learning how to take consequential actions back. Appeals, bankruptcy, cooling-off periods, brakes, abort systems, backups, version control, clinical staging, escrow, refunds, rollback, and revocable authority all reduce the cost of being wrong in different ways. The book asks whether reversibility is an overlooked form of infrastructure: the thing that lets people move faster precisely because not every move has to become permanent.
