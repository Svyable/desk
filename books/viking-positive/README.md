This book is not a claim that Viking discovered Martian life. It is an investigation of a stranger epistemic event: a purpose-built life-detection experiment produced the response its designers had defined as interesting, while another instrument's apparent failure to find organics helped demote that response; decades later, perchlorate chemistry and confirmed Martian organics weakened part of that negative argument without converting the original signal into proof of biology. The subject is what happens when the control experiment for a scientific consensus changes after the consensus has hardened.
