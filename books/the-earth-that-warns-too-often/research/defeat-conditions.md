# Defeat conditions and research priorities

## Defeat conditions

### Operational electromagnetic precursor claim
Treat short-term electromagnetic earthquake prediction as unsupported if adequately powered, multi-region prospective networks repeatedly fail to obtain reproducible probability gain beyond conventional seismicity / geodetic baselines under frozen algorithms and honest false-alarm accounting.

### Google / QuakeFinder-style magnetic association
The 2022 result should lose substantial weight if the exact frozen feature family fails on later qualifying earthquakes or independent comparable networks, or if the association is explained by a documented regional nuisance source that reproduces the observed timing / frequency structure.

It gains substantial weight if comparable effect size reproduces prospectively across new earthquakes, preferably in another region / network, without parameter retuning.

### Positive-hole / rock-battery mechanism
The mechanism loses earthquake-level explanatory force if field signals do not show preregistered dependencies on lithology, distance, frequency, source scale, or intermediate atmospheric effects that the model predicts. Laboratory charge generation alone cannot rescue field failures.

### Lithosphere-atmosphere-ionosphere coupling
A satellite precursor model should lose weight if frozen prospective scores do not outperform matched null catalogs and conventional forecasts, or if apparent anomalies track geomagnetic / seasonal / orbital variables under more complete nuisance models.

A causal LAIC chain gains weight only if intermediate ground / atmosphere / ionosphere changes appear in predicted temporal and spatial order across independent events.

### Animal behavior
The historical-anecdote version should not be treated as predictive evidence. Modern biologging claims gain weight only with preregistered multi-site replication controlling daily cycles, weather, husbandry, earthquake clustering, and false alarms.

## Highest-value next research

1. Run the exact 2022 Google/QuakeFinder pipeline forward on post-publication qualifying events without retuning.
2. Reconstruct VAN's complete prospective alarm denominator and freeze one historically faithful scoring rule before re-evaluation.
3. Build a machine-readable Loma Prieta / Parkfield instrument-health and detection-threshold comparison.
4. Create a paper-by-paper DEMETER / Swarm / CSES data-lineage matrix so overlapping earthquakes and mission intervals are not mistaken for independent replications.
5. Quantify signal amplitude / frequency predictions for electrokinetic, piezomagnetic, and positive-hole mechanisms under realistic crustal conductivity.
6. Build a prospective multi-region sensor registry using append-only probability forecasts rather than post hoc anomaly labels.
7. Compare every candidate feature against strong conventional baselines: earthquake clustering, aftershock models, geodesy, and tectonic setting.
8. Keep public-warning thresholds outside the scientific detector until calibration and decision-value analyses exist.
