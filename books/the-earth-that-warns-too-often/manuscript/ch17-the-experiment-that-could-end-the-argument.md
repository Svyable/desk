# The Experiment That Could End the Argument

A mature scientific dispute should eventually become boring enough to automate.

Earthquake precursors are not there yet.

The field still depends too heavily on retrospective cases, bespoke analysis and argument over which null model is fair. The technology now exists to build an experiment that would not settle every mechanism but could answer the central existential question much more cleanly: do defined electromagnetic and allied features add prospective information about future earthquakes?

The experiment needs to be designed so both enthusiasts and skeptics can lose.

That is the first requirement.

If only the precursor advocates can be embarrassed, they will reasonably suspect the test was built by critics. If only skeptics can be embarrassed, the detector has been protected from failure. An adversarial collaboration should therefore begin with teams representing the strongest versions of both positions.

The second requirement is geographic diversity.

California alone is not enough. Greece alone is not enough. Japan alone is not enough. A real effect may depend on tectonic setting, lithology, crustal conductivity and earthquake magnitude. The network should span at least several active regions: California, Japan, Greece or the eastern Mediterranean, Taiwan, perhaps parts of Italy, Chile and a suitable subduction setting. Not every region needs identical instruments, but a core suite should be standardized.

The third requirement is redundancy.

At each target region, deploy clusters rather than isolated stations. Three-component induction magnetometers. Stable DC/low-frequency electric dipoles with careful electrode monitoring. Broadband seismometers. GNSS. Meteorology. Atmospheric electric-field sensors. Where feasible, radon and groundwater measurements. Remote magnetic reference stations outside the expected source region. If animal behavior is included, treat it as a separate preregistered channel rather than an anecdotal add-on.

The goal is not to create a Christmas tree of sensors.

It is to identify nuisance sources.

A magnetic anomaly seen at one station is weak. Seen coherently at three local stations but not the remote reference, it is stronger. Seen simultaneously with a power-grid disturbance, it may be cultural. Seen during a geomagnetic storm, it belongs in a different null class. Accompanied by electric and hydrologic changes in the spatial order predicted by a mechanism, it becomes mechanistically interesting.

The fourth requirement is data blindness.

Raw sensor data should stream into an archive with cryptographic timestamps. The earthquake catalog should be maintained separately. Model-development teams receive only a training epoch. They can explore it as aggressively as they like. They can invent wavelet features, cross-power measures, positive-hole-inspired spatial patterns or machine-learning models. They can fail a thousand times.

Then they stop.

Each team submits a frozen container or executable pipeline. Inputs and outputs are specified. The code is hashed. The exact target definition—magnitude threshold, depth, spatial radius and forecast horizon—is registered. No one on the model team sees the hidden prospective sensor data after the test begins.

A neutral evaluation service runs the models continuously.

Every hour or day, depending on design, each model outputs calibrated probabilities for predefined geographic cells and magnitude bins. Not anomaly labels. Probabilities.

These forecasts are written to an append-only public or escrowed ledger before future earthquakes occur.

This is the modern telegram.

The fifth requirement is enough time.

This is where most proposals become expensive. Large earthquakes are rare. A three-year project may collect enormous sensor data and too few independent target events. The experiment should be designed for at least a decade, with institutional funding that assumes long quiet intervals are part of the science.

There should be no expectation of a positive result within a grant cycle.

The sixth requirement is a hierarchy of targets.

If the primary target is only magnitude 7 or larger earthquakes, the sample will be too small. If it includes every magnitude 3 event, any precursor associated only with large preparation volumes may be diluted. The protocol should predefine nested thresholds—perhaps M4.5+, M5.5+, M6.5+—with different geographic and tectonic contexts. Primary and secondary hypotheses need to be distinguished before testing.

The seventh requirement is declustering.

Earthquake sequences create leakage. Aftershocks are predictable in the broad sense that earthquakes trigger earthquakes. A precursor model could appear skillful simply because it detects changes after a mainshock and 'predicts' aftershocks. That may still have operational value, but it is not the same claim as detecting preparation before an independent mainshock.

The evaluation should therefore report both all-event skill and declustered-mainshock skill.

The eighth requirement is nuisance forecasting.

The system should predict not only earthquakes but common false-positive generators. Geomagnetic storms, lightning, heavy rainfall, local power anomalies, sensor maintenance and major cultural disturbances should be labeled. A model that fires primarily during geomagnetic storms can be diagnosed rather than merely scored as bad.

This turns false alarms into mechanism clues.

The ninth requirement is synthetic negative events.

At intervals unknown to the analysis teams, the evaluator can assign pseudoevents matched to the real earthquake distribution in location, season and data coverage. The pipeline must not distinguish real from pseudo windows except through the sensor relationship. This tests how easily the analysis manufactures 'precursors' from ordinary variability.

The tenth requirement is satellite integration without satellite privilege.

Swarm, CSES, GNSS TEC and future missions should contribute features through separate preregistered pipelines. Space data should not be allowed a wider post hoc search simply because orbital coverage is complex. The same forecast ledger applies.

A satellite model predicts probabilities for ground cells. It is scored like everything else.

The eleventh requirement is mechanism challenges.

Statistical skill alone answers the existential question but leaves physics open. Teams proposing specific mechanisms should register additional predictions: frequency bands, sign, spatial decay, lithologic dependence, local-time effects, sequencing among ground and ionospheric channels.

These predictions can fail even if the forecast feature works.

That is scientifically valuable. It separates detection from explanation.

The twelfth requirement is explicit defeat conditions.

For the broad claim that a useful short-term electromagnetic precursor exists, a decade-scale null with sufficient statistical power should count heavily against it. If multiple networks produce likelihood ratios indistinguishable from one after locked prospective testing, the field should stop treating older retrospective anomalies as a basis for public prediction.

Not forever. New mechanisms can justify new tests. But the burden resets.

For the narrower claim that *some* pre-earthquake electromagnetic physics exists, the defeat condition can be weaker. A small aggregate effect may survive while remaining useless for forecasts. The experiment should estimate effect sizes and confidence intervals, not force a yes/no answer.

This distinction prevents the project from declaring victory over a scientifically interesting weak signal just because it cannot evacuate a city.

The thirteenth requirement is replication ownership.

No team should be allowed to validate itself alone. If Group A develops a feature in California, Group B runs the replication in Japan under translation rules agreed in advance. If a Chinese CSES group proposes a plasma feature, an external group scores it. If skeptics propose a nuisance explanation, precursor advocates get to test that explanation on hidden data too.

Adversarial collaboration works only when power is symmetric.

The fourteenth requirement is radical source tracing.

Every claimed input needs a provenance record: instrument model, calibration history, firmware version, station relocation, missing-data periods, processing code, earthquake catalog version. The Corralitos lesson is embedded in the infrastructure.

A spectacular signal with a broken sensor flag dies before it becomes folklore.

The fifteenth requirement is public negative reporting.

All registered pipelines get results, including failures. A model cannot disappear because the test was unflattering. This is crucial in a field where publication bias can create an archive of apparent successes from a large universe of unreported searches.

The registry should make failure citable.

The sixteenth requirement is decision analysis after, not before, detection.

During the initial scientific phase, no model triggers public earthquake warnings. The experiment estimates calibration and likelihood ratios. Only after a detector demonstrates prospective skill does a separate policy process evaluate whether any probability threshold justifies operational action.

This firewall protects the science from pressure to be useful prematurely.

The seventeenth requirement is a stopping rule.

If a model achieves predefined prospective information gain with replicated performance in at least two independent regions, the study moves to a mechanism-and-operations phase. If it fails predefined futility bounds after sufficient events, it is retired. Models can be improved, but improvements become new registered versions with new future test periods.

No retroactive rescue.

The eighteenth requirement is patience with ambiguity.

The likely outcome is not a clean yes or no. A feature may show modest skill for shallow continental M5–6 events and fail elsewhere. An ionospheric effect may appear only at night under quiet geomagnetic conditions. A magnetic signal may replicate with an effect too small to support warnings. The experiment should be built to map conditionality rather than punish nature for refusing universality.

What would count as a remarkable positive result?

Not one successful prediction.

A remarkable result would be a frozen model, developed in one epoch, producing calibrated probability gains in later earthquakes across more than one region, with low false-alarm burden and a physical signature that scales with distance or magnitude as predicted.

What would count as a remarkable negative result?

A network sensitive enough to detect known coseismic electromagnetic effects, operating for years across major earthquakes, showing no reproducible prospective difference under any preregistered primary feature while synthetic controls demonstrate adequate statistical power.

Both outcomes advance science.

The cost would be substantial but not absurd by geophysical standards. Governments already spend heavily on seismic, GNSS and satellite monitoring because those systems have broad hazard and Earth-science value. Magnetometers and electric-field stations are comparatively cheap. The expensive component is sustained operation and curation.

The experiment is mostly an institutional design problem.

That fact should embarrass us slightly.

We have spent decades arguing over whether the Earth sends warning signals before rupture. We now possess global timing, cheap sensors, cloud storage, open-source statistics and mature preregistration practices. The missing technology is a commitment not to reinterpret the future after it arrives.

VAN used telegrams.

We can do better.

The decisive instrument is a locked door around tomorrow's data.
