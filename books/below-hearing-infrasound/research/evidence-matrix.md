# Evidence matrix

| Claim | Class | Best current evidence | Boundary / falsifier |
|---|---|---|---|
| CTBT verification uses seismic, hydroacoustic, infrasound and radionuclide technologies | Verified/documented | Treaty Protocol and CTBTO IMS documentation | Would change only with treaty/network architecture |
| The completed IMS infrasound component is designed for 60 array stations in 35 countries | Verified/documented | CTBTO infrasound monitoring documentation | Track certifications, relocations and operating status separately |
| Long-range detection depends on atmospheric structure, source directivity and station noise, not distance alone | Verified/documented | Infrasound propagation literature; Pilger et al. 2015 | A global dataset showing distance alone predicts detections comparably well would weaken the emphasis |
| Chelyabinsk was globally detected by the CTBT infrasound network and is useful for performance analysis | Verified/documented | CTBTO 2013; Brown et al. 2013; Pilger et al. 2015 | Keep exact station counts tied to the date/source because CTBTO early releases differed as processing matured |
| Remote infrasound can detect volcanic explosions hidden from some satellite analyses by weather | Verified/documented for specific cases | De Angelis et al. 2012, Mt. Cleveland | Does not imply infrasound is generally superior to satellite monitoring |
| IMS data can support automated global volcano detection | Verified as demonstrated method | Matoza et al. 2017 | Study found only 3 of 7 VEI 4 eruptions in its period; do not imply completeness |
| Hunga produced global atmospheric waves and was recorded across the operating IMS infrasound network | Verified/documented | Wright et al. 2022; CTBTO workshop/SnT records | Separate Lamb, acoustic-gravity and infrasound bands; avoid treating all as one wave |
| Known chemical explosions can calibrate source/location/propagation methods | Credible/model-dependent as generalization | Public technical studies and CTBTO event reporting | Event-specific source energy and geometry must be independently constrained |
| Natural events materially improve treaty verification performance | Credible but incompletely quantified | Event-performance papers; CTBTO science program | Stronger causal claim requires tracing specific algorithm/model changes into operational verification |
| Infrasound alone can uniquely identify every nuclear explosion | Disputed/not established | No source supports universal uniqueness | Multi-technology architecture itself is counterevidence to a one-sensor claim |
| A nondetection proves no energetic event occurred | Disputed/not established | Chelyabinsk station nondetections despite known event | Could be informative only under a quantified high-probability detection model |
| Unusual infrasound is evidence of non-human technology | Disputed/not established | No independent evidentiary chain | Requires event-level source exclusion, multi-station association and independent corroboration |
| Treaty verification functions as an accidental planetary observatory | Speculative synthesis grounded in documented uses | CTBTO scientific applications plus peer-reviewed event studies | Narrow if comparable global civilian networks provided the same continuous geometry independently of treaty infrastructure |
| Nuisance signals can improve the detector because they populate the negative class | Speculative synthesis | Meteors, volcanoes, microbaroms and chemical explosions in verification research | Requires evidence that such source studies influence calibration/modeling; do not claim every background source does |

## Evidence discipline

The matrix deliberately refuses to promote institutional descriptions of capability into universal performance claims. CTBTO is authoritative for what the treaty network is, but peer-reviewed event studies are preferred for what a particular waveform or nondetection means. Patents, marketing language, press releases, and one-off anomaly reports are not used as evidence of capabilities they do not independently demonstrate.
