# Rockets, Aircraft, Auroras

A global infrasound network is an unusually poor place to maintain a clean taxonomy of human and natural activity.

Aircraft produce pressure disturbances. Supersonic flight produces sonic booms whose low-frequency components can propagate beyond the audible footprint. Rockets produce powerful acoustic energy at launch and along flight paths. Reentries and atmospheric fragmentation can generate shocks. Mining blasts repeat on schedules. Large industrial explosions happen unexpectedly. Ocean waves create persistent microbaroms. Auroral and upper-atmospheric processes can contribute low-frequency signals. Storms and mountain-wave systems add more structure.

The detector does not receive categories. It receives pressure.

This is one reason infrasound deserves a place in conversations about anomalous aerospace observations, though not for the reason enthusiasts often hope. The network is potentially useful because energetic atmospheric motion can leave an acoustic trace. It is epistemically useful because the trace is radically nonunique.

A rocket launch, for example, is a gift to an atmospheric acoustician. The trajectory and launch time are usually known. The source moves through altitude regimes, generating noise and shocks along the way. Arrays at distance can observe arrivals that test atmospheric propagation. Reentries offer another controlled geometry. Supersonic aircraft can produce known moving sources. These events help teach the network how engineered aerospace activity appears without requiring speculation about unknown craft.

That baseline is indispensable before anomaly claims begin.

Imagine an unusual visual event accompanied by an infrasonic detection. The temptation is to fuse the observations immediately: the object made the sound. Perhaps. But the atmosphere may contain multiple sources, and timing windows can be broad because long-range acoustic travel is slow compared with light. A distant explosion hours earlier may arrive near the observation time. A launch hundreds or thousands of kilometres away may produce a path not obvious from a surface map. A bolide may go unseen locally while producing a strong remote signal. Without propagation modeling and independent bearings, coincidence is weak evidence.

This is where the long institutional memory of a verification network helps. Known rockets, aircraft and meteors populate the feature space. Analysts can ask whether the anomalous case actually lies outside it.

The same logic applies to auroral and geophysical sources that have historically accumulated mystery because they are hard to reproduce in a laboratory. Infrasound associated with auroral activity has been reported and investigated for decades, with candidate mechanisms involving upper-atmospheric energy deposition and coupling. The details are not settled in every case. That uncertainty should not be converted into permission to assign extraordinary causes. It should become a research question with explicit alternatives.

A good anomaly program is one that knows its ordinary sky.

The treaty network is valuable here because it was designed under adversarial assumptions. It cannot afford to treat “unidentified” as a stable source class. An unidentified event is a temporary state of analysis. The system should continue asking whether the observation is consistent with a known source under an unusual atmosphere, a known source with unusual geometry, an instrumental artifact, a cataloguing gap, or genuinely unexplained propagation.

This is a useful contrast with public UAP discourse, where “unidentified” often hardens into an identity. Once a case enters a famous archive, its persistence can be taken as evidence that the object itself resists explanation. Sometimes the persistence reflects the opposite: missing raw data, poor geometry, uncertain timing, classified context, or insufficient instrumentation make resolution impossible.

Infrasound cannot repair missing evidence after the fact. But it can model what a serious auxiliary sensor would contribute.

First, arrays provide direction rather than only detection. Second, multiple arrays can associate a source. Third, propagation can be predicted probabilistically from atmospheric models. Fourth, known-source catalogs can eliminate scheduled or independently observed events. Fifth, the signal can be compared with seismic and other channels. Only after those steps does an unexplained residue become interesting.

Even then, “interesting” is not “non-human.”

The military history of anomalous aerospace has repeatedly collided with secret conventional programs. U-2 and OXCART flights, reconnaissance balloons, missile tests and other classified activities generated observations that could not be publicly explained at the time. The lesson is not that every UAP is a black program. It is that the sky contains actors with asymmetric information, and sensor interpretation inherits that asymmetry.

A treaty network adds a different institutional structure. Its purpose is international confidence, so authenticated data and standardized processing matter. Yet not all analytical products are public, and states retain their own national technical means and classified information. The existence of an IMS arrival therefore does not guarantee that every relevant contextual source can be openly discussed.

That limitation deserves to remain visible. Secrecy can create a false evidentiary ecology in which ordinary but undisclosed sources survive as anomalies. It can also create the opposite problem: real unexplained events can be waved away as presumed secret programs without evidence. Both moves substitute sociology for measurement.

The better question is narrower: what source classes are physically compatible with the observed acoustic evidence?

Rockets and aircraft make that question harder, not easier. They are moving, directional, altitude-dependent sources. Their signatures depend on trajectory and atmospheric structure. A hypersonic object can generate shocks over an extended path. A breakup event can create multiple impulses. A launch may be observed acoustically far outside the region where anyone heard a boom.

This means that source motion, which Chelyabinsk exposed dramatically, is not an exotic edge case. It is part of the engineered atmosphere.

A global verification network must therefore understand aerospace activity even though aerospace monitoring is not its central treaty purpose. The same pressure data can support studies of launches, reentries and meteors because the physics overlaps.

The overlap is where epistemic discipline matters most. When a detector can see many things, the value of a detection decreases unless classification quality rises with sensitivity.

A sensor that hears rockets, aircraft, auroras and bombs has not failed to specialize. It has discovered the actual problem.

The atmosphere is a shared medium. Everything energetic enough to disturb it competes for the same evidence channel. The only honest response is to learn the competition.
