## Reader promise

A weapons-verification network built to identify one forbidden event became a planetary observatory because the atmosphere would not carry only the signal its designers wanted. *Below Hearing* follows that collision from treaty text and remote microbarometers through nuclear tests, meteors, volcanoes, industrial explosions, rockets, auroras, ocean noise, and the 2022 Hunga eruption. The book argues that the deepest technical problem is not sensitivity but discrimination: deciding what made a signal when propagation itself changes by hour, season, direction, altitude, and weather.

## Strongest competing explanation

There is a simpler story: infrasound is merely a mature branch of atmospheric acoustics, and the scientific uses of the International Monitoring System are predictable side benefits of a large sensor network. This book takes that explanation seriously. Its narrower claim is that the verification mission created unusual global continuity, geometry, authentication, and institutional persistence, while the non-treaty events repeatedly became calibration opportunities that improved understanding of the verification instrument itself. The relationship runs both ways.

## Evidence classes

1. **Verified / documented:** CTBT verification architecture; IMS station design; documented nuclear-test detections; recorded Chelyabinsk, volcanic, Beirut, and Hunga signals; published propagation and detection studies.
2. **Credible but incomplete / model-dependent:** source-energy inversions, atmospheric duct reconstructions, directionality corrections, and event-classification performance outside well-characterized cases.
3. **Disputed / not established:** claims that infrasound alone can identify every explosion type uniquely, that a nondetection proves no event occurred, or that every unusual array arrival implies a secret test or anomalous aerospace event.
4. **Speculative synthesis / open conjecture:** treaty verification as a generator of planetary science; nuisance signals as an epistemic asset; and the possibility that the best adversarial sensors become useful precisely because the world supplies richer calibration than the adversary does.
