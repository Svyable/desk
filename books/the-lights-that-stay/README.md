Working thesis: Hessdalen is valuable not because it proves an exotic explanation, but because recurrence converts an anomaly from a story into an experimental opportunity. A phenomenon that comes back can be instrumented prospectively. That changes the epistemology of UAP: the central scientific question becomes not `what was that?` but `what measurement would force us to change categories next time?`
